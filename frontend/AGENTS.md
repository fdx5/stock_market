# 3D 드론뷰 개발·검증 원칙

사용자가 2026-10-10에 지정한 지속 적용 원칙이다. 상위 AGENTS.md의 데이터 보호 지침도 함께 적용한다.

최우선 품질 원칙: 사용자의 명시적 허락 없이 출력 해상도를 절대 낮추지 않는다. FPS·GPU 시간·로딩 지연·메모리 압력을 이유로 동적 해상도 하향이나 저해상도 우회로 성능 기준을 충족하지 않는다. 출력 해상도/픽셀 비율과 품질 프리셋을 FPS 결과에 함께 기록한다. 해상도를 유지한 조건에서 50fps에 미달하면 미달 사실을 보고하고 계산·로딩·렌더링·자원 재사용을 개선한다.

1. 전 구간에서 최소 50fps 이상, 목표 60fps를 유지한다. Chrome에서 실제 비행 중 렌더 프레임을 측정한다. 평균만으로 합격 처리하지 않고 구간별 최저 1초 FPS, p95/p99 프레임 시간과 최대 멈춤도 기록한다. 미달 구간이 있으면 전체 목표 달성으로 보고하지 않는다.
2. 카메라 시점에 진입한 건물은 가까운 순서로 상세 렌더링한다. 기본 건물을 상세 모델이 GPU에 준비되기 전에 감추지 않는다. 실패와 무응답은 완료로 처리하지 않고 취소·기한·재시도를 검증한다.
3. 메모리를 계속 관리한다. 작업자와 다운로드 동시 실행, 보유 타일·모델·텍스처 캐시를 제한하고 시야에서 멀어진 자원 및 종료된 장면의 GPU/CPU 자원을 회수한다. 반복 이동·복귀 시 잔류 자원을 확인한다. 영구 저장 데이터 삭제는 메모리 관리 대상이 아니다.
4. 추가 개발·수정에도 위 세 원칙을 적용한다. 최근 추가 기능의 성능 회귀를 Chrome에서 확인하고 장비·해상도·렌더러·측정 조건을 기록한다. 일부 지역 측정으로 전국/모든 장비에서 달성했다고 주장하지 않는다.

테스트 음소거: 사용자가 2026-10-11에 요청했으므로 모든 Chrome 검증은 `--mute-audio`로 실행한다. 사용자의 브라우저 음량 설정을 변경하지 않는다.

건물 재질: 일반 건물 외벽에 원본 사진이나 가공 사진을 씌우지 않는다. 실측 구조를 보존하고 건물별 재질·색상·창문 표현을 구성한다. 근거 없는 녹색 옥상 색상을 공통 기본값으로 사용하지 않는다.

선행 상세 로딩: 드론이 가까이 접근하기 전 보이는 방향의 지역을 먼저 상세화한다. 특정 지역 예외로 보정하지 않고 최초 영역·이동 영역이 같은 실패/재시도·GPU 준비 대기열을 사용하도록 검증한다. 일부 지역·일부 건물의 성공 비율을 전체 지역 해결로 보고하지 않는다.

옥상 설비실: 등록·실측 형상을 보존하고 엘리베이터 기계실·계단실 등 옥상 돌출부에는 본체의 반복 창문을 그리지 않는다. 일반 거주층의 창문을 함께 없애는 방식으로 처리하지 않는다.
