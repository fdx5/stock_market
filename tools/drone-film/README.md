# 사이트 드론뷰 영상 제작 도구

실제 KOSPIMAP 3D 장면을 프레임별로 렌더링하고 MP4로 출력한다. 화면을 30fps로 녹화한 뒤 60fps로 늘리는 방식은 사용하지 않는다. 기본값은 3840×2160, 60fps이며 출력 해상도를 자동으로 낮추지 않는다.

## 다음 지역 제작

1. `profiles/haeundae-zenith.json`을 새 이름으로 복사한다.
2. `center`의 좌표·이름·주소, `radius`, 고도·속도 범위, `video.seconds`, `shots`를 수정한다. 각 `points`는 중심에서 동쪽 x, 지면 위 고도 y, 남쪽 z의 미터 단위다. `target`은 같은 좌표계의 시선 대상이다. `shotScale`은 수평 경로에만 적용된다.
3. 사용 가능한 음원을 `music.file`에 지정한다. 음악 파일은 소스 저장소에 포함하지 않는다. `music.bpm`은 컷 전환 배치 기준이며 실제 박자는 별도로 확인한다.
4. 프로젝트의 frontend 의존성을 준비하고 Python의 `imageio-ffmpeg`를 설치한다. 기존 FFmpeg가 있으면 `--ffmpeg`로 지정할 수 있다.
5. 저장소 루트에서 다음 명령을 실행한다.

```powershell
python tools/drone-film/prepare.py --profile tools/drone-film/profiles/haeundae-zenith.json
```

출력된 `start.ps1`을 실행하고 안내된 로컬 URL을 Chrome에서 연다. 테스트 브라우저는 `--mute-audio`로 시작한다. 기존 Chrome 프로세스가 실행 중이면 새 실행 인수가 적용되지 않을 수 있으므로 독립 프로필을 사용한다. 사용자 브라우저의 음량 설정은 변경하지 않는다.

6. `장면 준비` → `전체 구도 미리보기` → 이미지 확인 → `4K 본편 출력` 순서로 진행한다. 미리보기는 전체 경로를 빠르게 훑는 구도 검사용으로, 본편의 비행 속도를 나타내지 않는다.
7. 완료된 실행 ID의 MP4와 JSON을 함께 보관한다. 실행 ID가 들어간 PNG는 대표 원본 프레임이다. `*-encode.log`는 FFmpeg 로그다. 생성 파일을 자동 삭제하거나 기존 결과를 덮어쓰지 않는다.
8. `verify_mp4.py <결과.mp4> <실행ID.json>`으로 실제 해상도·프레임 수·시간·오디오 트랙을 검사한다. 대표 프레임을 MP4에서 추출하여 원본 PNG와 비교하고 전체 영상을 디코딩해 오류를 확인한다. 최종적으로 시작·중간·끝을 재생해 음악과 컷 전환을 확인한다.

## 구현과 기록

- 지도 API는 읽기 전용으로 연결한다. 로컬 DB를 시작하거나 기존 저장 정보를 변경하지 않는다.
- 수면 데이터가 확인되지 않은 장소에 임의 수목을 만들지 않는 운영 수정: `251525d5`, 지연 WebGL 재부착 차단: `09bc45e0`.
- 건물 경계를 이용한 A* 우회 경로와 호 길이 기준 이동을 사용한다. 반경·고도·속도 또는 충돌 조건 위반 시 출력을 중단한다. 등록 도형의 정확성까지 보장하는 것은 아니므로 미리보기 검수가 필요하다.
- 건물·장소 푯말은 사이트의 `DroneSigns`를 동일 카메라로 투영한다. 4K 픽셀 밀도와 영상 시계를 명시해 글자 선명도와 애니메이션 속도를 유지한다. 조작 UI는 녹화하지 않는다.
- 프레임은 4K JPEG 품질 1.0으로 메모리에서 전달한다. 대량 중간 이미지를 디스크에 쌓지 않는다. 수신 순서를 검사하고 FFmpeg 입력으로 직접 연결한다.
- 영상: NVIDIA NVENC H.264 High 5.2, p7/HQ, CQ15, VBR 85Mbps·최대120Mbps, spatial/temporal AQ. 오디오: AAC 320kbps. MP4 faststart.
- Windows 브라우저의 WebCodecs 하드웨어 모드에서는 4K/60fps 지원 판정과 실제 출력 화질에 제약이 발견됐다. 기본 제작 경로는 위의 FFmpeg 직접 인코딩이다. 해상도를 낮추거나 프레임을 복제해 우회하지 않는다.
- 실시간 사이트 FPS와 오프라인 MP4의 FPS는 별개다. 60fps MP4 완성만으로 사이트가 모든 장비에서 실시간 60fps라고 보고하지 않는다.

## 보관할 자료

요청 조건, 음원 사용 확인, 좌표 확인 근거, 프로필 JSON, 소스 커밋, 브라우저·GPU·해상도, 시작/종료 시각, 구도 미리보기, 원본/인코딩 프레임 비교, 인코더 로그, 경로·속도·고도·최소 여유 높이, MP4 검증 JSON, 최종 MP4를 함께 남긴다. API 키·토큰·쿠키·회원 데이터는 기록하지 않는다.

이번 제작의 경과와 시행착오는 `PRODUCTION-20261024.md`에 기록한다. 템플릿의 준비 완료 조건은 상세 모델과 수목 로딩을 기다리므로, API 장애가 있으면 먼저 해당 상태를 해결한다.
