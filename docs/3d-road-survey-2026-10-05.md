# 도로·하천 원자료 연동 및 입체 도로 오류 수정

2026-10-05. 재현 위치: 서울 강남구 대치동 65, 쌍용대치2, 84㎡ 3D 화면.

## 변경 내용

- 국가 도로중심선의 좌표·도로 폭·차로 수를 유지하고, 교통링크의 일반도로·교량·고가도로·지하차도·터널 속성을 방향과 거리로 연결한다. 인접한 도로의 구조 속성이 충돌하면 미확인으로 남긴다. 좌표를 인접 링크로 이동시키지 않는다.
- 높이가 다른 도로의 평면 교차를 교차로로 연결하지 않는다. 차선, 노면, 보도, 가로등, 차량은 각 도로의 높이와 링크를 사용한다. 서로 다른 교량의 차선이 상부 노면으로 끌려 올라가는 문제를 방지한다.
- 물과 가까운 도로를 자동으로 교량으로 만드는 추론과 고정 15m 높이, 임의 진입 램프·교각 생성을 제거했다. 공식 구조 속성이 확인된 도로만 교량 대상으로 사용한다.
- 하천망 폴리곤을 같은 좌표계로 연결하고 화면 범위에서 경계를 절단한다. 내부 구멍은 유지하며 섬을 물로 채우지 않는다. 쌍용대치2 주변에서 양재천·탄천 원자료가 조회되었다.
- 신호 위치의 OSM 식별자·층·방향을 보존한다. 외부 위치가 확인된 교차로에만 신호등 모델을 만든다. 차량 흐름을 위한 내부 신호 제어는 유지한다. 별도의 화면 안내 문구는 추가하지 않았다.
- 차량 충돌 판정은 교량 진입·진출 시 앞으로 이동할 높이까지 계산한다. 같은 높이에서는 충돌을 방지하고 충분한 수직 간격이 있는 차량을 평면 겹침만으로 정지시키지 않는다.

## 정확도와 남은 범위

이번 변경은 공식 평면 경계와 구조 속성의 연동 및 도로별 연결·표시 오류 수정이다. 모든 3D 요소가 실측으로 전환된 것은 아니다. 조회한 API는 교량 상판·교각의 실측 3차원 좌표, 실시간 하천 수위, 신호등 현시(SPaT)를 제공하지 않는다. 교량 높이는 기존 DEM의 양 끝 지형 높이로 보간하며 지하차도·터널의 실제 종단 높이는 확보되지 않았다. 실측 높이가 없는 곳에 임의의 높이 차이를 만들어 정확하다고 간주하지 않는다. 신호 색은 내부 시뮬레이션이며 실시간 현시가 아니다.

쌍용대치2 도로 구조 매칭은 일부 미확인 구간이 있어 내부 상태에 `partial`로 기록한다. 외부 자료가 실패하면 원래 도로 좌표를 유지하고 확인되지 않은 구조를 생성하지 않는다. 이번 검증은 기능 검증이며 메모리·GPU·로딩·프레임 드랍의 추가 개선률을 측정한 성능 실험은 아니다. 앞선 WASM 전환 성능 결과는 `3d-geometry-instance-2026-10-05.md`와 해당 PDF를 참조한다.
