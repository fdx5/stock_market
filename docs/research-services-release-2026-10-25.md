# 신규 서비스 36개 및 어드민 추적 배포

최근 NEO GENESIS 개편본 작업트리 `I:/ai_root/sm-deploy`를 기준으로 구현했다. 초기 신문형 작업트리 대신 기존 NeoShell·메뉴·검색·시계·BGM을 사용한다. 기존 메뉴 6개 순서와 208px 폭을 유지하고 신규 목적지는 같은 레벨의 기존 분류 안에 추가했다. 추가 항목은 ‘더 보기’로 펼친다.

## 추가 개선

- 종목 분석 10개와 ETF 3개에 이름·코드 자동완성. 선택 즉시 코드·시장 적용, 키보드·빈 결과·실패·직접 코드 입력 지원.
- 종목 선택의 대가·회복 실험실·종목 비교에도 현재 표본의 이름·코드 검색 적용. TOP 100 밖 종목을 다른 종목의 값으로 대체하지 않는다.
- 검색 아이콘은 별도 열로 분리하고 입력·선택·버튼은 44px, 라벨·안내 문구는 별도 행으로 정렬.
- 배당 금액은 각 값 옆에 원(KRW)·달러(USD)를 명시한다. CSV는 각 행의 currency를 요구하고 환산하지 않는다. 국내 ETF와 원천 통화가 다르면 금액 표시를 보류한다.
- 추정 접속 지역은 한글 지역명 가나다순으로 표시한다.

## 어드민

`/admin/dashboard#traffic`의 ‘신규 서비스 · 페이지별 분석’에서 36개 전체 또는 개별 페이지와 최근 1·7·30일을 선택한다. 조회·페이지별 중복 제외 세션·주요 기능 동작·한국시간 일별 추이·최근 기능 로그를 제공한다. 기존 페이지 추이·실시간 로그에서도 신규 페이지명을 표시한다.

기존 인증을 적용한 읽기 전용 집계 API는 `/api/admin/research/stats`다. 기존 page_views의 이벤트를 SELECT로 집계하며 새 테이블·정리 작업을 만들지 않는다. 봇은 제외하고, 기록 없는 페이지는 0으로 표시한다. 기능 사용은 배포 후부터 기록하며 과거 값을 합성하지 않는다.

동작 키는 `research:` 접두사의 닫힌 목록이다. 검색·선택·직접 적용·조건 변경·원문·관련 페이지·가정 변경·CSV·인쇄·공개 기록 등을 구분한다. 선택 완료된 공개 종목 코드·이름 외 검색 입력문, 가정 금액, 자유 메모, 파일 이름·내용은 새 기능 로그에 넣지 않는다. 페이지별 세션 합계를 전체 고유 방문자 수로 표시하지 않는다.

## 검증

- TypeScript와 운영용 Vite 번들 통과. 기존 큰 청크 경고는 유지.
- 프런트 계산 테스트 22개, 서버 파서·원천 통화·보존·읽기 전용 집계·관리자 인증 검사 8개 통과.
- 36개 경로 데스크톱·모바일·기존 메뉴 회귀 검사 83개 통과.
- 1440·1024·390·360px 전체 36개 페이지 입력·아이콘·버튼 정렬과 통화 검사 147개 통과.
- 종목·ETF 검색, 키보드, 시장 전환, 직접 코드, 표본 범위, 모바일 검사 22개 통과.
- 어드민 페이지 필터·기간·최근 로그와 실제 클라이언트 이벤트 형식·민감 입력 제외를 모의 응답으로 검증.

서버 테스트는 새 임시 SQLite와 순수 파서만 사용했고 운영·기존 로컬 DB를 실행 대상으로 사용하지 않았다. 운영 확인은 배포 상태, `/api/health` 커밋, 공개 신규 API·페이지·정적 번들, 관리자 API의 비인증 차단을 읽기 전용으로 확인한다. 운영 통계에 합성 방문을 넣지 않는다.

기존 공개 원천 및 페이지별 자료 범위는 `research-services-local-review-2026-10-25.md`의 36개 목록을 따른다. 모든 주식·국가·일정이 확보되었다고 주장하지 않는다.
