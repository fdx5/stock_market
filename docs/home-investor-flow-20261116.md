# 관제 홈 한 줄 수급

관제 홈 시장 스캐너에서 코스피·코스닥 선택 시 `주요 종목` 바로 위에 개인·외국인·기관의 순매수/순매도 금액을 한 줄로 표시한다. 나스닥 선택 시 국내 수급 영역은 표시하지 않는다.

기존 전광판의 `PulseInvestorFlow`에 한 줄 표시 옵션만 추가했다. 첫 진입 즉시 시작, 투자자별 불규칙한 움직임, 60초 롤링과 매분 기준값 교체, 일시정지, 장 마감·지연·탭 숨김·동작 줄이기 처리는 모두 같은 구현을 사용한다. 기존 공유 시세 요청을 재사용하며 새 API·DB·서버 작업을 추가하지 않는다.

PC에서는 개인·외국인·기관을 같은 줄에 표시한다. 좁은 화면에서는 줄 높이를 유지하고 금액 영역 안에서 가로로 스크롤할 수 있다. 원 단위 금액을 생략하거나 압축하지 않는다. 기존 전광판의 광고·바다·배 배치는 변경하지 않는다.

검증: 프런트엔드 빌드, 기존 수급 모델·공유 폴링 14개 테스트, 메모리 API 응답을 사용하는 관제 홈 브라우저 검증을 수행했다. 음소거한 Chrome, DPR 1, 1600/1280/768/390/320px에서 즉시 롤링·한 줄 배치·주요 종목 위의 위치·시장 전환·가로 스크롤·일시정지·동작 줄이기를 확인했다. 테스트는 기존 저장소나 DB를 사용하지 않는다.

Chrome 1600×1000 / DPR 1, 기존 balanced 효과를 유지한 비교에서는 일시정지 8초 평균 58.58fps·최저 1초 55fps, 롤링 8초 평균 59.35fps·최저 1초 57fps였다. 롤링 p95/p99는 16.8/16.9ms, 최대 프레임 66.9ms였다. 별도 최초 진입 10초 구간은 평균 49.38fps·최저 1초 40fps로 50fps에 미달했다. 해당 구간 결과를 숨기거나 전체 상황에서 50fps가 보장된다고 해석하지 않는다. 표시 해상도와 품질은 변경하지 않았다.
