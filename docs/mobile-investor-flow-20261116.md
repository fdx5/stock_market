# 모바일 수급 숫자 잘림 수정

관제 홈과 증시 전광판의 공통 수급 컴포넌트에 적용한다. 원 단위 전체 금액과 기존 1분 롤링·기준값 교체 동작은 유지한다.

- 관제 홈의 금액 열에 있던 고정 최소 폭과 가로 스크롤을 제거한다.
- 영역 폭 520px 이하에서는 개인·외국인·기관을 세 행으로 배치한다. 헤더 폭은 52px로 줄이고 숫자 크기는 실제 영역 폭에 맞춘다.
- 520~1100px 영역은 세 열을 유지하되 투자자 이름을 숫자 위로 올린다. 가로로 회전한 휴대폰에서도 세 금액 전체가 같은 화면에 들어간다.
- 숫자 칸은 폭 1.06ch, 높이 1.45em으로 늘려 글꼴의 좌우·상하 여유를 확보한다. 롤링 띠도 같은 비율로 유지한다.
- 모바일 하단 고정 메뉴 높이를 루트 스크롤의 하단 여유에 반영하여 숫자를 보려고 스크롤했을 때 메뉴가 금액을 가리지 않도록 한다.
- 전광판 광고의 실제 높이와 바다·배 카메라 연결은 기존 ResizeObserver가 새 높이를 그대로 반영한다. 출력 해상도는 변경하지 않는다.

검증은 메모리 API 응답과 음소거한 Chrome에서 수행한다. 320×740, 740×320, 360×800, 800×360, 390×844, 844×390, 430×932, 932×430, 768×1024, 1024×768의 터치 화면/DPR 2를 사용한다. 두 페이지·두 시장 총 40개 조합에서 큰 15자리 금액, 전체 자릿수, 행·숫자 영역의 가로 넘침, 숫자 칸 상하 여유, 하단 메뉴에 의한 가림을 검사했다. Arial 대체 글꼴에서도 검사했다. 기존 수급 모델·공유 폴링 14개 테스트 및 관제 홈 통합 검증도 통과했다.

실행: `python frontend/scripts/test-mobile-investor-flow.py` (Vite 기본 포트 5188, `MOBILE_FLOW_URL`로 변경 가능).
