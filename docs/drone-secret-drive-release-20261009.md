# 드론 뷰 시크릿 드라이브 진입 — 2026-10-09

사용자가 현재 URL에 직접 `devgame=1`을 넣었을 때만 드론/착륙 버튼 오른쪽에 드라이브 버튼을 표시한다.
파라미터가 없거나 값이 `0`, `true`, `2`, 빈 문자열이면 표시하지 않는다.
브라우저 저장소를 활성화 조건으로 사용하지 않으며, 기존 방문 기록의 시크릿 파라미터도 일반 지도 메뉴 진입 시 복원하지 않는다.
이때 저장된 방문 기록은 변경하지 않고 반환하는 탐색 주소에서만 파라미터를 제외한다.
공통 메뉴에는 시크릿 진입 링크를 추가하지 않으며, 카카오톡 공유 주소에서도 파라미터를 제외한다.

두 버튼을 하나의 flex 그룹에 넣어 모바일에서 줄이 바뀌어도 드라이브가 드론 버튼 오른쪽에 붙도록 했다.
기존 `/drive` 페이지를 재사용하며, 버튼을 눌렀을 때 현재 단지와 드론 위치, 시간대를 전달한다.
드론 뷰에서는 게임을 미리 실행하거나 게임 자산을 추가로 불러오지 않는다.

크롬에서 파라미터 없음/0/true/1의 표시 조건, PC와 모바일 가로·세로 배치,
클릭 시 기존 게임 메뉴와 현재 좌표 전달, 일반 메뉴로 다시 들어오면 버튼이 숨겨지는 동작을 검증했다.
순수 함수 검증 4개와 잠실 야구장 식재 검증 4개, TypeScript 검사 및 Vite 빌드를 통과했다.
스크린샷, 게임 점수 등록, DB 도구 및 저장 데이터 삭제는 실행하지 않았다.
잠실 야구장 내부 나무 제외 수정도 이 배포에 포함한다.

이 변경으로 60fps 달성 여부를 새로 주장하지 않으며, 게임 플레이의 성능 검증은 이번 UI 진입 확인 범위에 포함하지 않는다.
