# 탐색·분석 서비스 개선 (2026-10-08)

사용자가 승인한 네 기능을 기존 화면과 연결한다. 활동 분석의 표본이 작았으므로 수요가 입증됐다고 주장하지 않으며, 배포 후 기능별 이용 흐름을 기존 관제에서 확인한다.

1. **1면·지도 탐색 복원**: 탭의 `sessionStorage`와 브라우저 방문 기록에 페이지별 스크롤, 지도 업종·기간·표 보기·선택 종목, 1면 순위의 시장·정렬을 기억한다. 1면의 기존 종목 쿼리도 복원한다. 1면은 계속 `/desk`에 표시된다. 비동기 화면의 높이가 변하는 동안 위치를 맞추고, 사용자가 스크롤하거나 조작하면 복원을 멈춘다. 새 지도 진입의 모바일 자동 정렬은 복원과 충돌하지 않는다.
2. **모바일 최근 종목**: 브라우저의 기존 최근 10개 종목을 모든 주식 탐색 화면에서 연다. 상세·한 장 보고서 링크를 제공하고, 새로 방문한 ETF의 유형도 유지한다. 기본 다이얼로그의 포커스 제한, Escape 닫기, 이동 시 닫기를 적용한다. 메뉴를 여는 동작은 시세 폴링을 추가하지 않는다.
3. **종목 상세 핵심 요약**: 전일 대비, 21거래일 수익률, 거래량/20일 평균, RSI, 최근 종가 그림, 이동평균 대비 거리, 업종 비교군의 평균을 먼저 제시한다. 상세 원표·차트로 이동할 수 있다. 수신 시세, 일별 지표 날짜, 업종 조회 기준을 구분한다. 업종 비교는 같은 응답 묶음과 거래 세션의 유효 종목에서 본 종목을 제외한 단순 평균이다. 기존 지수 수익률도 종목과 같은 시작·종료 날짜로만 비교한다.
4. **종목 한 장 보고서**: `/stock/{code}/report`에서 국내·미국 주식과 ETF를 지원한다. 상세 화면과 같은 분석 계산을 사용한다. 가격, 핵심 지표, 비교 근거, 기간별 수익률, 접을 수 있는 기업 개요를 표시하고 A4 인쇄·PDF 저장을 제공한다. 요청은 독립적으로 표시하며 25초 제한, 이탈 시 취소, 시세 요청 중복 방지를 적용한다. 실패한 갱신은 마지막 수신 시세를 유지하고 갱신 대기 상태를 표시한다.

미제공 값은 `—`로 표시한다. 공개된 종가·시세로 계산하며 가격 변동의 원인이나 미래 수익을 만들어내지 않는다. 보고서 경로는 별도 SEO 제목·정규 URL·관제 페이지 분류를 갖는다.

로그인·회원가입은 중지 상태를 유지한다. 계정 DB·OAuth·회원 정보 수집·DB 마이그레이션을 추가하지 않는다. 기존 저장 데이터와 테이블을 삭제하지 않는다.

## 검증

- TypeScript 검사와 프로덕션 빌드.
- 날짜 정렬·중복/누락·불일치 지수 날짜·결측 지표·거래 세션 비교 및 테마 단위 검증.
- 독립 카탈로그로 보고서 SEO·정규 URL·기존 상세 메타데이터·잘못된 국내 종목 처리를 검증한다. DB 모듈을 불러오지 않는다.
- 브라우저 검증: 탐색 복원, 네이티브 뒤로가기, 모바일 최근 종목·키보드·ETF, 네 주식 지도 야간 팔레트, 국내/해외/ETF 보고서의 5개 화면 폭과 두 테마, 실패·지연 응답, A4 한 장 인쇄.
- 브라우저 테스트의 모든 API는 독립 픽스처로 응답한다. 테스트가 운영 방문·활동·회원 데이터를 기록하지 않는다.

자동 검증: `frontend/scripts/test-stock-brief.mjs`, `frontend/scripts/test-reading-services.py`, `backend/tests/test_stock_report_seo.py`.
