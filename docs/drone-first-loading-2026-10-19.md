# PC Chrome 최초 차선 및 전방 스트리밍 지연 수정

작업 브랜치: `fix/drone-first-lanes-20261019`. 기준 운영 커밋: `8addbcc1`.
다른 세션의 교통흐름 작업과 기존 미완료 GPU 실험은 변경하지 않았다.

## 원인과 수정

- 우선 도로 작업이 계속 대기하면 일반 스트리밍 작업의 100ms 강제 실행 보장이 사라졌다. 신도6→의정부 신세계 경로에서 자료가 이미 도착한 지형의 화면 반영 작업이 16초 이상 기다렸다. 일반 작업의 실행 보장을 독립적으로 유지한다.
- 도로/차선 배열 변환과 법선 계산이 일반 대기열로 돌아갔다. 내부 계산까지 우선권을 전달한다. 한 번의 계산은 계속 짧게 나누며, 우선 작업의 기한을 16ms, 일반 작업은 100ms로 분리한다. 도로/차선에만 12ms의 프레임 진입 예산을 사용한다.
- 차선 계산이 도로 바탕의 작업자 처리와 GPU 업로드까지 모두 기다린 뒤 시작했다. 동일한 도로·지형 입력의 차선을 먼저 준비하고, 도로 바탕이 준비되면 완성된 차선을 연결한다. 장면 이탈/실패 때 먼저 완성된 결과와 늦게 도착한 결과를 모두 회수한다.
- 모든 횡단보도를 모든 도로의 표본 선분과 비교하던 계산에 경계 상자 검사를 추가했다. 점선 구간은 이진 탐색으로 찾고 같은 도로의 반복 높이는 재사용한다. 도로·교차로·차선 형상과 높이 보정 규칙은 보존한다.

## 재현 및 검증

설치 PC Chrome, RTX 3070, 음소거, high, Tidewater WebGPU, 뷰포트 1200×800, 실제 캔버스 **2400×1600 / 2.00**. 브라우저는 한 번에 하나씩 실행했다. 운영 API는 조회만 허용하고 방문·활동 기록과 모든 쓰기 요청은 브라우저/로컬 프록시에서 응답했다. 새 브라우저 컨텍스트를 사용했으며 기존 저장소를 삭제하거나 초기화하지 않았다.

- 기본 진입 지역인 래미안길음센터피스의 전체 차선 표시: 운영 기준 **79.009초**, 최종 후보 **42.679초**. 지형·차선 전체의 GPU 준비 및 319,287개 차선 정점을 확인했다. 출력 해상도와 품질을 낮추지 않았다. 단일 비교 측정이며 모든 지역·기기의 동일한 개선율을 보증하지 않는다.
- 신도6(`41150:호원동:401-1:신도6`)에서 의정부 신세계백화점까지 약 1.33km, 고도 100m, 35m/s 이동을 재현했다. 최종 후보의 35초 지점 전방 준비 거리는 운영 기준 0m에서 **424m**로 개선됐다. 5초 간격 표본 중 전방 준비 거리의 최저값은 **374m**였으며, 준비된 타일은 같은 지점에서 25개→33개였다. 실행 오류는 없었다. 중간 수정본에서 대표 타일의 지형 반영 대기도 16.151초에서 0.914초로 줄었다.
- 어제 추가한 상업시설 기능을 비활성화한 별도 운영 비교에서도 전방 준비 거리가 0m로 떨어졌다. 기능을 켠 경로에서 상업시설 갱신의 전체 CPU 비용은 약 148ms였다. 추가 시설만의 문제로 단정하지 않고 공통 대기열의 실행 기아를 수정했다.
- 회귀 검사 **58개**, TypeScript, 전체 Vite 빌드, `git diff --check` 통과. 정적 지형·복잡한 도로·횡단보도·교량을 포함한 비교에서 기존 차선의 position/normal/roadLevel/roadProfile 배열이 바이트 단위로 같다. 겹친 차선 작업의 정상 연결·이탈·지형 실패·차선 실패도 검사했다.

최종 후보 첫 진입 후 짧은 전진 12초: 평균 37.12 / 최저 1초 30fps, p95 50ms / p99 50.1ms / 최대 67.2ms. **전 구간 최소 50fps는 미달이다.** 이번 수정의 로딩 개선을 FPS 목표 달성으로 보고하지 않는다. 출발 장면의 준비 정도에 따른 편차가 있어 FPS 개선율도 주장하지 않는다.

최종 신도6→신세계 경로는 같은 2400×1600 high에서 평균 46.99 / 최저 1초 23fps, p95 33.5ms / p99 50.1ms / 최대 117.2ms였다. 로딩 중 프레임 저하도 남아 있다. 원본 표본 요약은 `drone-first-loading-qa-20261019.json`에 포함했다.
