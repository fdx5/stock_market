# 커뮤니티 읽기 개선

- 한글 HTML은 UTF-8을 우선 엄격 디코딩하고 CP949/EUC-KR을 지원한다. 손실성 물음표 치환을 하지 않는다. 원문에 이미 들어 있는 물음표를 임의의 한글로 추정하지 않는다.
- 원문 식별값/정규화 제목을 비교하여 반복 등록을 목록에서 묶는다. 대표 글은 최신 글이며 묶인 원문 링크는 읽기 화면에서 열 수 있다. 일반적인 짧은 제목은 다른 글일 수 있으므로 제목만으로 합치지 않는다. 저장 데이터 삭제 없음.
- 본문 320자 제한과 공백 일괄 합치기를 없앴다. 전체 본문을 문단/줄바꿈/첨부 이미지 순서의 구조화된 블록으로 전달한다. 외부 HTML은 직접 삽입하지 않는다.
- 공유/SNS/스크랩/입력 버튼 요소와 복사된 공유 메뉴 문구는 본문에서 제외한다. URL과 텍스트 링크의 목적지는 유지하며 새 탭으로 연결한다. 일반 문장의 '공유 경제', '페이스북 실적' 같은 표현은 보존한다.
- 허용된 원천/CDN의 안전한 이미지 URL을 추출하고 원문 순서로 표시한다. 큰 이미지 보기, 지연 로딩, 이미지 전환 시 이전 글 이미지 초기화, 실패 시 원문 연결을 제공한다. 로컬/스크립트 URL과 추적용 1px 이미지는 제외한다.
- 글 제목만 먼저 노출하던 방식을 없애고 본문/첨부 이미지 수집 성공을 검증한 뒤 목록에 반영한다. 실패 글은 노출 대상에서 제외하고 일시적인 네트워크 오류는 한 번 재시도한다. 검증한 본문을 읽기 스냅샷에 함께 유지하므로 목록에서 선택할 때 원천 재요청 실패로 빈 본문이 되지 않는다.
- 상단 이미지 카드 3종 추가. 자산과 프롬프트는 `community-icon-prompts-2026-11-05.md` 참조.
- 요청한 빈 읽기 패널 안내 문장을 삭제하고 미리보기 제한 안내도 제거했다.

## 확인 결과

- DB 없는 단위 테스트 9개 통과: 한글 인코딩, 원문/제목 중복, 안정적 페이징, 실패 수집의 노출 차단, 전체 글과 줄바꿈, 첨부 이미지 순서, 위험 URL 제외, 버튼 제거와 기사 링크 보존, 검증 본문 재사용.
- 실수집 확인: 국내 164건(이미지 포함 69건), 해외 90건, 부동산 71건(이미지 포함 2건). 전 항목 본문/첨부 블록 확보, 정규화된 긴 제목 중복 0건. 숫자는 확인 시점의 원천 응답 기준.
- Chromium 음소거 검증: 데스크톱 1440×1000, 모바일 390×844, 844×390, 375×667, 667×375. 전체 본문 마지막 문단, 줄바꿈, 새 탭 URL, 첨부 이미지, 카드 이미지 로딩, 50개 페이징 및 재진입 갱신 확인. 고정 UI 데이터와 실원천 검증은 별도 수행.
- TypeScript 검사 통과. 기존 DB 및 저장 데이터 접근/변경 없음.
