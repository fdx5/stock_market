# 의정부역센트럴자이앤위브캐슬 철거 건물 재유입 수정

대상: `41150:의정부동:724:의정부역센트럴자이앤위브캐슬`, 2022년 준공.

2026-09-28의 `e9af88d` 수정은 현재 운영에도 남아 있었다. 초기 단지 건물만 필터링하고, 주변 건물 목록과 나중에 추가된 `ringBuildings`의 별도 원자료 조회에는 철거 기준이 전달되지 않았다. 주변 워커는 이미 표시한 건물의 중심점만 중복 제외하므로, 초기 목록에서 삭제한 건물은 새 건물로 취급해 다시 표시했다. 주변 워커는 `4805458`에서 도입되었다. 이번 재현에서 초기 주변 목록에 과거 주택 2개, 주변 워커 결과에 단지 내부 경계 315개가 남았다.

수정은 현재 고층 동이 실제로 남아 있을 때만 작동한다. 기존 사용승인 연도·단독주택 기준을 단지 내부의 초기 주변 목록에도 적용하고, 필지 경계와 준공 연도를 주변 워커로 전달한다. 이미 정리된 캐시에서도 이 정보가 다시 계산된다. 단지 밖의 실제 오래된 건물과 현재 동·부대시설은 유지한다. 단지 안에서 현재 건물과 연결되지 않은 추가 3D 모델도 다시 생성하지 않는다.

실제 VWorld 자료를 이용한 브라우저 프리뷰 비교:

| --- | ---: | ---: |
| 현재 10층 이상 동 | 12 | 12 |
| 현재 동·부대시설 합계 | 17 | 17 |
| 단지 내부 초기 주변 건물 | 2 | 0 |
| 단지 내부 주변 워커 경계 | 315 | 0 |
| 브라우저 실행 오류 | 0 | 0 |

주변 워커의 실제 코드로 단지 내부 과거 주택 제외·단지 밖 과거 주택 유지·현재 동과 부대시설 유지 검사를 추가했다. 기존 철거 필터 검사에도 이미 정리된 캐시의 보호 정보 전달 및 단지 밖 건물 유지 검사를 추가했다. 관련 화면 검사 12개와 워커 회귀 검사, TypeScript 및 배포 빌드가 통과했다.
