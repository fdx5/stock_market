# 1차 통합 배포와 후속 최적화 검증

## 배포 완료

2026-10-03 사용자 요청에 따라 다른 세션의 완료된 tracked 3D 수정 7개 파일을 기존 성능 복구 버전에 통합했다. 커밋 `2893fa464837891134c241305cfe840ba474a861`을 main에 push했고 운영 `/api/health`의 동일 커밋 및 `status:ok`를 확인했다.

운영 실제 단지에서 WebGPU high, 원본 2x sharp, 쿠팡트럭·사이버트럭·스코어 관련 버튼 숨김, 마우스 조작 및 닫기/재진입을 확인했다. 페이지 오류와 콘솔 오류가 없었다. 기능 검증은 성능 목표 달성을 의미하지 않는다. 원래 작업 폴더의 다른 세션 미커밋 변경은 그대로 보존했다.

## 별도 브랜치의 후보 코드 — 미배포

`fix/loading-quality-after-integration`에서 원본 512px brushed-steel roughness를 47,312바이트 무손실 PNG로 준비해 2,606개 canvas 명령을 생략할 수 있게 했다. 차량 필수 준비가 끝날 때 파일이 아직 준비되지 않았다면 원래 painter를 즉시 사용한다. 추가 요청을 필수 로딩 경로에 넣지 않았다. 늦은 bitmap, 준비 실패, 화면 종료 뒤 완료된 자원을 폐기하며 오래된 kit의 실패가 새 kit 캐시를 지우지 않는다.

동일 immutable roughness의 녹색 채널 R8 GPU 텍스처는 뷰 사이에 공유한다. 마지막 소유자가 해제하면 할당을 즉시 파기한다. 공유 텍스처는 첫 뷰를 붙잡는 repack 클로저를 보관하지 않는다. 화질·해상도·차량 수·geometry·조명을 줄이지 않았다.

실제 Edge/WebGPU 검사에서 원본 RGBA 픽셀, GPU 업로드 픽셀, R8 녹색 채널 모두 최대 차이 0이었다. 두 소유자의 동일 GPU 할당 공유, 첫 소유자 종료 후 생존, 마지막 소유자 종료 후 파기, bitmap.close 및 파일 실패 시 원본 복구도 통과했다.

제품 빌드, 기존 Node 회귀 27개, 부동산 테스트 12개, 실제 kit loader의 지연/실패/종료 수명 검사 4개가 통과했다.
