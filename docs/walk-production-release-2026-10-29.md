# 직접 걷기 전체 개발본 운영 배포

사용자 요청: 2026-10-29 전체 개발 내용을 운영에 배포.

## 범위

- `/walk` 독립 걷기, 실내 탐험과 평형 조회, TV 검색 API.
- 동별 자전거 배치, 승하차, 최고 60km/h, 자전거 효과음.
- 차량 40종, 주행과 차종별 녹음 사운드, 내부/외부 재질, 모든 차축 바퀴 회전.
- 낮은 후방 고정 / 정면 고정 시점, 반복 승하차 복원, 완화한 차체 충돌 판정.
- 야간 전후등과 가로등, 도로변 주차 배치.
- 현재 개발본에 포함된 공용 월드·지형·물·교량·외관·군중 변경.
- 모델·텍스처·소리 159파일(92,014,785 bytes) 포함.
- 새 걷기 자산은 운영의 오래된 CDN pin 대신 같은 배포 서버에서 제공.

원래 드론의 걷기 진입 버튼은 `?devwalk=1` 조건을 유지한다. `/walk?id=…` 직접 주소는
운영에서도 사용할 수 있다. 기존 로그인·저장 기능·DB 스키마는 변경하지 않는다.
DB를 테스트하거나 저장 데이터 삭제 명령을 실행하지 않았다.

## 배포 전 검사

- `npx tsc -b`: 통과.
- Vite 운영 빌드: 통과 (31.38s), 로컬 CDN override 없음.
- 독립 응답으로 검사한 백엔드 API 테스트: 7개 통과, DB·외부 요청 없음.
- 자전거/차량 물리·주차·카메라·충돌: 24개 통과.
- 앞선 실제 Chrome 검사: 40차종 구조·지붕·정면 시야, 바퀴 셰이더 및 그림자,
  9사운드 계열 36조건, 은마 주행과 반복 승하차. 상세 결과는
  `walk-vehicle-fixes-2026-10-29.md` 참조.
- 성능 한계: RTX3070/ANGLE, 1440×900, DPR1에서 평균53.07FPS, 최저1초46FPS,
  p95 33.3ms, p99 50ms, 최대216.9ms. 최소50FPS 목표는 미달이며 전체 보장을 주장하지 않는다.

기존 Render 서비스 `srv-d95okvtckfvc73bjfu3g`의 main 자동 배포 경로를 사용한다.
배포 완료는 `/api/health`의 커밋 일치와 실제 운영 장면 검증 후 별도로 기록한다.
