# 산림 군집과 나무 형태 다양화

산림을 혼합림, 소나무 군락, 활엽수 군락, 어린 숲, 성긴 숲의 다섯 패턴으로 구성한다.
패턴마다 수종 비율, 높이, 수관의 폭과 밀도를 다르게 하고 개별 나무의 깊이, 방향과
작은 기울기를 섞는다. 기존처럼 높은 나무가 같은 비율로 반복되는 모습을 줄인다.

근거리 임야와 DEM 산림, 드론 원거리 타일 모두 같은 세계 좌표 해시로 군집을 정한다.
후보 위치의 흔들림을 넓혀 격자 줄 배치를 완화하고 도로, 건물, 궁궐 정원 등의 기존
식재 가능 영역 확인 이후에만 나무를 추가한다. 카메라 움직임이나 매 프레임의 랜덤은
사용하지 않는다. 기존 공원과 가로수의 위치·크기·형태는 유지한다.

다섯 수종의 기존 3D 잎과 줄기 모델, 인스턴싱, 원거리 단계별 상세도, 메모리 예산을
공유한다. 새로운 텍스처나 모델 파일은 필요하지 않다. 모든 변경은 렌더링 코드와 검증
파일에 한정하며 DB와 저장 데이터 작업은 수행하지 않는다.

검증: 산림 패턴·지형 부착·공유 모델·근거리/원거리 메모리 검사 23개, TypeScript 검사와
Vite 운영 빌드 통과. PC와 모바일 실제 WebGPU 장면에서 다섯 군집의 나무 인스턴스와
전체화면 및 닫기 동작을 확인한다. 스크린샷은 촬영하지 않는다.
