# 아파트 평형 선택 누락과 대기 상태 수정

## 재현된 공통 원인

드론 건물 카드의 내부 탐험 이벤트는 좌표만 넘겼고 `DroneSession.openInside`는
이름을 빈 문자열, 층수를 0으로 저장했다. 아파트 분류·동·PNU·단지 ID도 사라졌다.
WalkPage는 대장의 공동주택 용도와 4층 이상 조건을 만족해야만 아파트로 분류했다.
대장 조회 실패·용도/층수 누락은 일반 건물 경로로 이어져 평형 선택 전에 1층을 생성했다.
이전 검증은 대장이 공동주택이라고 응답하는 조건을 사용해 이 진입 오류를 놓쳤다.

선택 화면의 `원본 도면 검증 대기`는 실제 상태와 관계없는 고정 문자열이었다.
단지 검색·주택형 선택·통신 실패·판독 실패를 구분하지 못했고, 단지 조회 예외는
상태를 종료하지 못할 수 있었다. 매매 단지 목록이나 네이버 도면에 없는 공공임대도
같은 안내로 남았다.

## 공통 수정

- 카드 이벤트 → 드론 진입 → 세션 복원 → 평형 선택까지 이름·아파트 분류·동·PNU·
  단지 ID를 보존한다. 새 브라우저의 좌표 링크도 GIS 용도/PNU를 보존한다.
- 아파트 표지판·공동주택 코드·공동주택 대장 정보는 층수 누락과 무관하게 평형 선택으로
  연결한다. 이전의 빈 정보 링크는 PNU와 단지 목록으로 복원한다. 미분류 대상은 일반
  건물 1층을 자동 생성하지 않는다. 병원·상가·관리시설의 별도 경로는 검사했다.
- 같은 필지의 단지 ID라도 클릭한 단지명/차수와 다르면 사용하지 않는다. 동 번호가
  `114`처럼 접미사 없이 들어와도 알려진 동 필드와 분리해 대표 단지명으로 검색한다.
- 조회 기한과 실패 상태를 명시한다. 고정 검증 대기 문구는 실제 상태별 안내로 대체했다.
  검색 실패 응답의 HTTP 저장을 막고 부정 검색의 메모리 캐시를 15초로 줄였다.
- 원본에 근거한 참조 목록을 공급자와 독립된 공통 자료로 추가했다. 특정 단지명에 따라
  렌더러를 바꾸는 분기는 없다. 새 참조는 자료와 좌표 구획으로 추가할 수 있다.
- 좁은 주방은 기본 중앙 통행선 때문에 설비가 거부될 때, 실제 가전 배치 후 0.48m
  보행 연결을 다시 검사해 통로를 배치한다. 벽·방을 늘리지 않는다.

## SH빌 참조의 범위와 출처

공식 [마이홈 단지 정보](https://www.myhome.go.kr/hws/portal/sch/selectRentalHouseInfoDetail.do?hsmpSn=30582264&suplyTy=01&rthousSe=C)의
수서1단지SH빌(일원동 711, PNU 1168011400107110000) 면적 자료와
[공개 도면 사본](https://spec.toesoon.com/entry/수서1단지-영구임대-모집공고)을 연결했다.
25.62㎡·33.93㎡의 흐린 사본에서 세대 구획을 검토 보정한 근사 모델이다.
이미지 원본 파일은 변경하지 않았고 인식 구획을 별도 좌표로 보관한다.
공식 SH 서버에서 원본 이미지를 직접 받은 자료가 아니며, 114동의 모든 세부 타입을
확정한 도면으로 표시하지 않는다. 이 한계와 근사 보정은 선택 화면에 표시한다.
수동 검토 자료에 OCR 정확도·F1을 만들어 붙이지 않는다.

원본 자료는 `backend/app/data/floorplan_references/`, 공통 해석기는
`backend/app/services/floorplan_references.py`이다. 평균 구조 템플릿은 사용하지 않는다.
모든 아파트 원본을 확보했다는 의미가 아니며, 연결된 도면이 없는 경우는 명시한다.

## 검증

- 독립 백엔드 검사 46개. DB·네트워크 없는 면적/구조/공급자 참조 검사.
- 분류·단지명·원본 변환·벽·보행 회귀 검사와 TypeScript 검사.
- 기존 OCR 원본 17종의 필수 주방 설비와 벽 광선 2,695개 검사 통과.
- 검토 보정 사본 2종의 필수 주방 설비와 벽 광선 91개 검사 통과.
- 실제 Chrome의 로컬 카드 버튼과 실제 `DroneSession` 진입 메서드를 실행했다.
  외부 월드 형상과 지도/대장 응답은 fixture로 격리했다. 전체 지도를 비행한 검증과
  구분한다. 대장 503, 용도·층수 누락, 빈 이전 링크, 새 브라우저 GIS 링크,
  같은 필지의 잘못된 단지 ID를 각각 검사했다.
- 수서 삼익과 SH빌 114 입력 조건에서 평형 선택 → 주택형 적용 → 가구가 있는
  아파트 실내 진입을 확인했다. 일반 건물 내부 API로 넘어가지 않는지 검사했다.

재현: `frontend/scripts/test-entry-kind.ts`, `frontend/scripts/check-apartment-entry.py`,
`frontend/scripts/fixtures/apartment-entry-handoff.html`, `backend/tests/test_floorplan_references.py`.
브라우저 자료: `tmp/floorplan-entry-20261101/`.

## 데이터와 배포

DB·회원 데이터·기존 백업 변경, 삭제, 초기화, 마이그레이션은 없다.
공개 이미지와 출처·보정 좌표만 추가했다. 별도 작업 중인 inventory 변경은 포함하지 않는다.
운영 배포·health·실제 운영 API 및 화면의 결과는 배포 후 추가한다.
