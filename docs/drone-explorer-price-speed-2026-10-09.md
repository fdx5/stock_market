# 드론 탐험 진입, 평균 시세와 항속 속도

공통 상단 링크의 부동산 지도 다음에 `/drone-explore` 드론 탐험을 추가한다.
링크를 누르면 별도 소개 화면 없이 전체화면 드론뷰로 바로 진입한다. 드론 탐험은
서울 성북구 래미안길음센터피스에서 실제 3D 화면이 그려진 뒤 자동으로 드론 모드로
진입한다. 오른쪽 위 X 버튼은 로딩 중에도 사용할 수 있으며 닫으면 부동산 지도로
이동한다. Esc도 건물 정보가 열렸을 때는 정보를 먼저 닫고, 그 외에는 지도로 이동한다.
무지개 발광은 드론 탐험 화면의 헬기 아이콘 테두리에만 적용하며 상단 링크에는 적용하지
않는다. 동작 줄이기 설정에서는 움직임 없이 무지개 테두리를 유지한다. 기존 부동산
지도에서 수동으로 드론에 타는 방식도 유지한다.

오토 파일럿을 켜면 해당 순간의 수평 속도를 항속 속도로 저장한다. 정지 상태에서는
기본 100km/h를 사용한다. 100km/h보다 느린 이동 속도도 그대로 유지하며 기존 최고
200km/h 제한을 따른다. 고도 100~250m 유지, 장애물과 미로딩 타일에서 감속·대기 후
저장된 속도로 복귀한다. 켤 때 잡고 있던 키나 스틱은 놓을 때까지 무시하고, 이후 새
이동·고도 조작으로 수동 비행에 복귀한다.

드론에서 건물 팻말을 누르면 정보 패널에 평균 시세를 표시한다. 연속지적도 PNU와
지번을 기존 `/realestate/nearby` API로 매칭하고 `/realestate/complex?period=1y`의
평형별 거래를 사용한다. 여러 단지가 같은 지번에 있는 경우 이름·동으로 확정할 수
없는 매칭은 표시하지 않는다. 같은 평형의 최근 365일 중개거래 평균을 사용하며
중개거래가 없으면 직거래 평균임을 표시한다. 평형은 변경할 수 있다.

시세는 천만원 미만을 버려 `21억 5천`, `11억 3천`처럼 표시한다. 색상은 API의 1년
변동률 기준으로 상승 빨강, 하락 파랑이며 보합과 비교자료 부족은 중립색이다.
최근 거래가 없거나 API에서 매칭되지 않은 건물에 임의의 시세를 만들지 않는다.

변경은 프런트엔드와 검증·설명 파일에 한정한다. DB 작업이나 저장 데이터 삭제를
실행하지 않으며 검증 브라우저의 통계 기록 요청은 차단한다. 스크린샷은 촬영하지 않는다.

검증: 항속·고도·수동 전환·장애물·로딩 복귀 11개, 시세 계산·표기·색상·매칭 5개,
기존 궁궐·랜드마크 회귀 12개 검사 통과. TypeScript 검사와 운영 Vite 빌드 통과.
