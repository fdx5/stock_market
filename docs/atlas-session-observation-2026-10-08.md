# 거미 관제의 사용자 행동·세션 관찰

- 기본 관찰 대상은 **사용자 행동**이다. 모든 관측 세션을 시간순 도표에 표시한다.
- 세션 이름이나 행동 지점을 클릭하면 해당 세션의 도표·거미 경로·실시간 로그에 집중한다.
  `전체 세션`이나 선택된 세션 이름을 다시 클릭하면 전체 관찰로 돌아간다.
- 페이지 이동, 클릭·선택, 종목 조회, 메인 화면의 관심 대상·조작을 표시한다.
  방문 집계 API, 일반 DB 접속, 체류 시간 전송 패킷, 거미의 이동·도착은 기본 행동 로그에 포함하지 않는다.
  기존 API·HTTP 관측은 `시스템 진단`과 별도 분석 화면에서 계속 확인한다.
- 접속 유지(최근 120초 heartbeat)와 최근 행동(90초)을 구분한다. 행동이 없는 접속도 표시하며,
  실제 관측이 없을 때 경로나 행동을 만들어내지 않는다. 식별된 User-Agent 봇과 관리자 행동은 제외한다.
- 로그인 개발은 중지 상태다. 현재 관찰 단위는 계정이 아닌 **브라우저 탭 세션**이다.
  관제 응답에는 원본 세션 키 대신 프로세스별 임의 비밀키로 생성한 HMAC 가명을 사용한다.
  IP, User-Agent, referrer, URL query, 토큰 등은 이 관찰 응답에 포함하지 않는다.
- 기본 도표 시간 범위는 5분이며 1/5/15분 선택이 가능하다. 현재 서버 메모리의 최근 15분,
  최대 2,000개 행동을 사용하고 세션별 최근 80개를 표시한다. 초과 표본은 화면에 표시한다.
  도표에 모든 관측 세션을 유지하며 세션 개수에 별도 100명 제한은 두지 않는다.
  서버 재시작 시 관측 메모리와 가명이 새로 시작된다. 선택 세션이 사라져도 다른 세션으로 자동 전환하지 않는다.
- 거미는 최근 60초의 행동 경로를 압축해 재생한다. 실제 행동의 순서를 보여주는 도표이며 미래 예측값을 만들지 않는다.
  브라우저 발생 시각은 서버 시각의 최근 120초 범위에서 검증해 지연 수신된 페이지 이동의 순서를 보존한다.
- Atlas 조회는 DB를 조회하거나 저장 데이터를 수정·삭제하지 않는다. 기존 저장 로그·DB 스키마는 보존한다.
  로그인·회원가입 구현은 추가하지 않는다.

검증: 별도 메모리 fixture 기반 pytest, 흐름 모델 Node 테스트, API fixture를 사용하는 실제 Edge 브라우저 QA.
전체/개별 세션, 시간순 표시, 실시간 추가, 시간 범위, 조용한 접속, 표본 범위, 진단 전환,
자동 따라가기, 모바일, 키보드, 모션 감소, 기존 거미의 WebGL 복구를 확인한다.
