# 배경 무작위 선택 · Liquidity Silk · 나노튜브 네온 리액터 (2026-11-09)

## 동작
- `NeoBackdrop`이 페이지 진입(새로고침·첫 로드) 때 한 번 50:50으로 배경을 고른다.
  앱 안에서 이동해도 배경은 바뀌지 않는다. `?bg=silk` / `?bg=nanotube`로 고정 확인 가능.
- 선택 결과는 `html[data-backdrop]`에 표시한다. 저장소·쿠키에 기록하지 않는다.
- Silk가 WebGL2 + `EXT_color_buffer_float`를 쓰지 못하면 기존 나노튜브로 전환한다.

## Liquidity Silk (신규)
- GPU 입자 65,536개(full 98,304개)가 발산 없는 흐름장을 따라 이동하고, half-float 장노출 버퍼에 궤적이 쌓인다.
- 네온 강 4줄기(골드·바이올렛·마젠타·시안), 소용돌이, 커서 와류, 7~13초 간격 유동성 급증, 스크롤 시 실 상승.
- 매 프레임 업로드는 uniform뿐이다. 데스크톱 1920×1080·폰 412×915@3x 모두 60fps(스크롤 중 포함, 로컬 Chrome).

## 나노튜브 재해석 (기존 형태·지오메트리 유지)
- 색을 사이트 네온 톤으로: 민트/시안, 골드/앰버, 바이올렛/마젠타, 일렉트릭 블루/아이스.
- 넓은 오라(블룸) 패스 추가, 기본 밝기 상향, 신호 펄스 간격 단축.
- 스크롤 속도에 따라 오버드라이브 발광, 스크롤 반대 방향으로 4겹 빛 잔상, 스프링 관성 밀림. 멈추면 2~3초 내 복귀.
- 스크롤 중에만 잔상 패스를 그린다. 1920×1080 연속 스크롤 60fps 측정.

저장 데이터·DB는 변경하지 않는다.
