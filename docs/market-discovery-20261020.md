# 국내·글로벌 시장 첫 화면 개편

## 지면과 탐색

- `/desk`: 짧은 시장 요약 → 거물 포트폴리오 → 국내 주식 한국어 영상 → 기존 상세 시장 섹션.
- `/global`: 짧은 미국 시장 요약 → 같은 포트폴리오 → 나스닥·미국 주식 한국어 영상 → 기존 시간외·순위 등.
- 기존 첫 화면과 01·02 섹션을 시장 요약 한 장으로 합쳤다. 반복 지수 레일은 두 페이지에서 제외한다. 요청에 따라 시세 티커바는 복원하고, 요약 카드 안에 WTI 유가·금 선물·은 선물·비트코인·리플의 달러 시세와 등락률을 함께 표시한다. 티커바와 요약은 기존 공유 시세 폴러를 사용한다. 미국 섹터·빅테크 상세는 기본 접힘이며, 펼칠 때 차트 데이터를 요청한다.
- `/investment-videos?market=kr|us`: 시장 선택, 최대 20개 영상, 주제·검색·정렬, 클릭 재생. 재생 시 켜져 있던 배경음악을 일시 정지한다.
- `/investors`: 투자 성향, 검색, 같은 공시분기 공통 보유 종목 필터.
- `/investors/{id}`: 원형 비중 차트와 보유 내역, 신규·확대·축소 필터, 현재 시세 재평가. 차트 항목을 누르면 해당 표 행으로 이동한다.
- 모바일 미리보기의 투자자 카드는 가로로 넘기며, 긴 보유 내역 표는 첫 열을 고정하고 좌우 스크롤한다. 큰 움직임은 reduced-motion 설정을 존중한다.

## 영상 수집 기준

최신 한국 시각 08:00 회차를 기준으로 전일 00:00부터 당일 08:00 직전까지 공개된 영상을 선정한다. 오전 08:00 이전에는 직전 회차를 사용한다. 서버가 30초마다 회차를 확인하며 방문자가 없어도 갱신한다. 결과의 조회수는 실제 수집 시각 값으로, 정확히 08:00 당시의 과거 조회수라고 주장하지 않는다.

`YOUTUBE_DATA_API_KEY`가 서버에 있으면 공식 YouTube Data API의 검색·영상 통계를 우선 사용한다. 없거나 응답하지 않으면 공개 검색 결과와 공개 영상 페이지의 게시 시각·조회수를 확인한다. 인증·내부 비공개 API는 사용하지 않는다. 국내와 미국은 검색 주제와 제목 관련성 조건을 각각 적용한다. 한국어 제목, 정확한 게시 시각, 조회수가 확인된 후보만 남기고 중복을 제거한다. 확인한 후보 중 조회수 상위 20개이며 YouTube 전체의 공식 순위는 아니다. 20개 미만이면 확인된 수만 표시한다.

공개 페이지의 형식이나 제공 정책이 바뀌면 수집이 실패할 수 있다. 실패 시 기존 회차를 유지하고 15분 후 재시도한다. 화면에는 이전 회차 여부와 수집 시각을 표시한다.

출처: [YouTube search.list](https://developers.google.com/youtube/v3/docs/search/list), [videos.list](https://developers.google.com/youtube/v3/docs/videos/list).

## 포트폴리오와 가격

공시 주식 보유분은 DATAROMA의 공개 운용사 보유 내역에서 수집한다. 워런 버핏, 빌 애크먼, 마이클 버리, 캐시 우드, 데이비드 테퍼, 댄 로브, 세스 클라먼, 하워드 막스, 리 루, 크리스 혼 10명을 제공한다. 인물의 이름은 운용사의 투자 철학을 탐색하는 출발점이며 개인 계좌 또는 현재 운용 책임을 의미하지 않는다.

마이클 버리와 캐시 우드는 SEC 13F 원문의 전체 포지션과 이전 분기를 직접 비교한다. SEC가 공개한 발행사·CUSIP·수량·신고금액을 사용하고, 공개 13f.info 표는 CUSIP의 티커 매핑에만 사용한다. 티커가 없더라도 공식 포지션을 버리지 않는다. 캐시 우드는 ARKK 단일 펀드의 일일 자료를 사용하지 않으며 ARK Investment Management의 분기 공시 전체를 제공한다. 버리는 운용 종료 전 마지막 공시임을 명시한다.

현재 확인된 버리 자료는 2025년 3분기 8개 포지션(주식·우선주 4, 옵션 4)과 직전 분기 대비 전량 매도 14개다. 캐시 우드는 2026년 2분기 190개 포지션과 전량 매도 7개다. 공시 비중은 전체 신고금액을 분모로 사용한다. 옵션의 신고금액은 기초자산 명목금액이므로 투입 자금 비중이나 옵션 가격으로 설명하지 않는다. 주식과 옵션을 독립된 포지션으로 식별하고 옵션을 일반주식 공통 보유 통계에 섞지 않는다.

상세 표는 종목 로고·증권 종류·공시 비중·이전 분기 비중·비중 변화(%p)·수량·보유 변화·현재 시세·당일 등락으로 구성한다. 전량 매도 종목도 별도 상태로 제공하며 전체/보유/매수·확대/매도·축소/전량 매도/옵션 필터를 지원한다. 의미 없는 ‘공개 기준가’와 ‘기준가 대비 수익률’은 화면에서 제외한다. 실제 매입단가·투자자 수익률은 추정해 만들지 않는다.

현재가는 기존 미국 시세 공유 큐에 연결하여 갱신한다. SEC 자료의 분기 평가단가를 현재가로 재사용하지 않으며 별도 시세 미확인 시 가격·등락률을 null로 제공한다. 화면에는 ‘확인 중’ 또는 —로 표시하고 0%로 채우지 않는다. 옵션은 기초자산 시세임을 구분하며 이를 옵션 가격·옵션 수익률로 계산하지 않는다. 공통 보유 계산에는 같은 분기말 자료만 사용한다. 기존에 저장한 일일 펀드·축약 범위 자료는 삭제하지 않지만 새로운 분기 전체 자료로 오인되도록 노출하지 않는다.

공시 보유 주식은 현금·채권·비상장 자산 등을 포함한 전체 자산배분이 아니다. 현재까지 확인한 분기를 그대로 표시한다. [SEC 13F 안내](https://www.sec.gov/answers/form13f.htm), [DATAROMA 공개 보유 내역](https://www.dataroma.com/m/holdings.php?m=BRK).

사진은 `editorial_portraits.json`에 인물, 고해상도 원본, 출처와 저작권 표기를 둔다. 검색·리디렉션으로 동명이인이나 배우의 사진을 자동 교체하지 않는다. 원본 컬러를 그대로 표시하고 미리보기 사진은 120px, 목록은 160px, 상세는 224px로 확대했다. 모바일은 각각 108·128·152px이다. 사진 원문과 제공된 라이선스 링크, 원형 크롭 표시를 목록·상세 화면에 제공한다. 제목은 기존 `.d2-sec-titles h2`의 공통 CSS에 `.d2-title`을 연결하여 같은 서체·굵기·자간 체계를 사용한다. 보유 표의 종목명 왼쪽에는 기존 `StockLogo` 공통 컴포넌트를 사용한다.

## 저장과 운영

새 회차마다 별도의 JSON 파일을 exclusive-create로 추가한다. 기존 파일 덮어쓰기, 삭제, 보존 기간 정리, SQL, 기존 DB 접근은 없다. 파일 경로는 서버 설정만 사용한다. 수집 실패로 기존 회차를 비우지 않는다.

`EDITORIAL_DATA_DIR`를 영속 디스크 디렉터리로 지정하면 재시작 후에도 회차를 복구한다. 기본값은 `backend/app/data/store/editorial`이다. **Render의 임시 파일시스템만 사용하면 재배포 시 회차 파일을 유지할 수 없으므로**, 운영에서 이전 회차 보존이 필요하면 이 설정을 영속 디스크에 연결해야 한다. API 키는 서버 비밀 설정에서만 사용하며 URL·예외 내용에 출력하지 않는다. 운영 설정과 배포는 이 개발 작업에서 변경하지 않았다.

## 확인 결과

- 실제 공개 데이터로 국내·미국 영상 각각 20개 및 선정 운용사 보유 내역 확인.
- 서버 편집·SEC 공시 테스트 34개, 기존 미국 시세 관련 회귀 테스트 42개 통과.
- 프런트엔드 지면·독립 페이지 렌더링 테스트 6개, 기존 공유 시세 갱신 테스트 4개, 방문자 응답 회귀 테스트 1개 통과.
- TypeScript 및 Vite 프로덕션 빌드 통과.
- 로컬 전용 미리보기에서 신규 페이지와 API HTTP 200, 두 영상 API 20개, 투자자 10명, 버핏 보유 내역 29개, 버리 보유 8개·전량 매도 14개, 캐시 우드 보유 190개·전량 매도 7개 응답 확인. 캐시 우드의 독립 시세 189개와 실제 당일 등락이 갱신되는 것을 API로 확인했다.
- 연결 가능한 브라우저가 없어 실제 화면 크기·클릭 동작·영상 재생의 브라우저 검증은 완료하지 못했다. 렌더링 검사는 실제 브라우저 검증을 대체한다고 주장하지 않는다.

로컬 미리보기는 실제 수집한 공개 자료를 메모리에 주입하고 기존 앱 초기화·DB·스케줄러를 실행하지 않는다. 쓰기 요청은 저장하지 않는다. 포트폴리오 현재가는 메모리의 공유 시세 큐를 사용해 별도로 수집한다.
