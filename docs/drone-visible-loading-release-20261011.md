# 드론 화면 로딩 1차 개선

이동 중 현재 카메라 앞의 가까운 타일을 먼저 준비한다. 지형은 기존 65×65 DEM 보간 결과를 그대로 유지하면서 최대 2개 작업자에서 계산하고, 도로와 건물의 공간 검색을 제한된 격자 인덱스로 처리한다. 짧은 건물 응답은 불필요한 추가 페이지 요청을 생략하며, 재방문 시 최대 8개·5분의 메모리 캐시를 사용한다. 프레임 작업 대기열은 실제 3D 프레임 시작 시각과 작업별 예산을 기준으로 실행한다. 출력 해상도, DPR, 품질, 도로·지형 형상 및 기존 작업 예산을 낮추지 않는다.

지도 → 3D 건물뷰 → 드론플레이에서는 탐험 경로를 미리 다운로드한다. 경로 다운로드가 느려도 워프의 최소 5초는 실제 워프 화면이 마운트된 시점부터 계산한다. 다색 워프, 공통 장소·주소 자동완성, 속도 200km/h, 자동 고도 10–1000m, 수동 상승 1000m 초과 기능을 유지한다.

## 측정 범위와 한계

Ryzen 7 3700X / RTX 3070, 음소거 Chrome 154.0.8037.98, tidewater-webgpu, 1440×1000 화면, 실제 3D canvas 2520×1750, DPR 1.75, high 품질에서 읽기 전용 공개 GIS 데이터를 사용했다. 동일 카메라를 12초 정지한 뒤 200km/h로 북쪽·동쪽·남쪽 각 1km 이동하는 66초 재현이다. 지표는 화면에 보이는 미준비 타일 수 × 대기 시간의 합이며, 끝까지 준비되지 않은 타일도 포함한다. 모든 건물이 상세화되는 시간이나 첫 화면 표시 시간과는 구분한다.

성능 코어가 같은 V3 후보와 기존 368fd8f의 비교:

| 위치 | 이동 구간 타일 대기 합(기존 → 개선) | 개선 배수 | 처음 12초 타일 대기 개선 |
| --- | --- | --- | --- |
| 망미동 한성기린 | 382,705 → 56,039 tile·ms | 6.83배 | 1.63배 |
| 해운대 두산위브더제니스 | 298,804 → 59,889 tile·ms | 4.99배 | 2.01배 |

V4는 위 코어에 경로 사전 다운로드와 워프 최소 표시 시간 보완을 추가한 배포 대상이다. V4 첫 화면 표시를 다시 순차 비교하면 망미동 5,065 → 4,597ms(1.10배), 해운대 4,195 → 3,656ms(1.15배)였다. 외부 GIS 응답에 따라 변동한다. **전체 로딩 또는 첫 화면 3배 목표는 달성하지 못했다.** 최초 상세 건물 준비도 3배 달성을 주장하지 않는다.

66초 고속 이동 V3의 최저 1초 FPS는 망미동 27.86, 해운대 33.75였고 p95는 모두 33.4/33.3ms, p99는 50.1/33.6ms, 최대 프레임 간격은 233.4/266.6ms였다. 준비된 V4 해안 구간에서는 최저 52.79–56.98fps였으나 초기·고속 로딩 구간까지 50fps를 달성한 것으로 보고하지 않는다. 전국·다른 장비에 대한 달성도 주장하지 않는다.

## 검증

- TypeScript, 안전한 별도 production build 및 순수 Node 검증 75개 통과. 기존 DB를 사용하거나 저장 데이터를 삭제하는 테스트는 실행하지 않았다.
- 실제 지도 출발 검색: PC·touch 모바일에서 강남데시앙 IME 입력(스페이스 없음), 이동, 정확한 목적지 좌표, 속도·고도 패널, 이전 canvas/세션 종료 및 오류 0 확인. 경로를 6.5초 보류한 경우에도 실제 워프가 5.65초 표시됐다.
- 아파트·지역·학교·도로명·지번 검색 6종, 취소·재시도·기한·뒤로/앞으로 이동 검증 통과. 종료한 지형 작업자는 pending 0 / liveWorkers 0이었다.
- 실제 키보드 전진 약 890m, 가까워지기 전 앞쪽 상세 건물 준비 및 오류 0 확인. 모든 보이는 건물의 상세 완료를 의미하지 않는다.
- 해안 4개 시점과 교량 수치 검사에서 확인된 수면 위 지형 및 침수 도로 정점은 0이었다. 다만 망미동 교량 화면에 수면이 도로를 가리는 부분이 남아 있다. 수치 검사로 시각 문제가 해결됐다고 판단하지 않는다. 효과가 없던 수면 shader 보정은 배포에서 제외했다. 이 시각 문제는 후속 수정 대상이다.

로컬 근거는 작업 공간의 tmp/drone-visible-loading-20261011, tmp/drone-map-search/loading-stage2-v4, tmp/drone-place-search/loading-stage2-v4, tmp/drone-warp/loading-stage2-v4-recovery, tmp/coast-review-20261010/loading-stage2-v4-coast 및 tmp/drone-bridge-water/loading-stage2-v4-river-asphalt에 보존한다. 이번 배포에는 frontend 로딩·표시 코드와 검증 도구만 포함하고 DB 스키마·회원 정보·저장 정보는 변경하지 않는다.
