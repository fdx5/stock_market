# 재방문·지역 통계와 관리자 레이아웃

## 코드 변경

- 기존 방문 카운터는 그대로 두고, 별도 `audience_observations` 테이블을 추가한다.
- 브라우저의 무작위 UUID는 localStorage에 유지한다. 인증 토큰이나 회원 ID가 아니다.
  DB에는 브라우저·탭 ID를 도메인 분리한 HMAC-SHA256 값으로만 저장한다.
- IP는 원문을 저장하지 않는다. 한국시간 날짜별 HMAC으로 일별 접속망만 비교한다.
  같은 IP에 여러 사람이 있고 한 사람이 여러 IP를 쓸 수 있어 방문자 판별의 기준으로 사용하지 않는다.
- 기간 내 서로 다른 2일 이상 방문한 브라우저를 재방문, 3일 이상을 꾸준한 방문으로 표시한다.
  실제 사람 수가 아니며 쿠키/저장소 차단, 기기 변경, 자동화 탐지 누락에 따른 오차가 있다.
- 봇, 관리자 페이지, 클릭 이벤트, DNT/GPC 요청은 새 통계에서 제외한다.
- 지역은 신뢰 프록시에서 전달한 국가/시도/도시를 읽는다. 임의 X-Forwarded-For나
  단순 CF 헤더 존재만으로 IP·지역을 신뢰하지 않는다. 미확인은 그대로 남긴다.
- 정확도를 보완하는 브라우저 위치 참여는 사이트 하단 안내에서 사용자가 버튼을 누른 경우에만
  브라우저 권한을 요청한다. 자동 위치 요청, 위치 추적 반복, watchPosition을 사용하지 않는다.
  원 좌표를 약 100m 단위로 반올림하고, 오차 5km 초과 응답은 지역 확정에 사용하지 않는다.
  국가·시도·도시만 저장하며 좌표·도로명·지번·상세 주소는 통계에 저장하지 않는다.
  브라우저 위치도 기기·환경에 따라 오차가 있으며 방문자가 값을 조작할 수 있다.
- 같은 브라우저/같은 날에 브라우저 위치 기록이 있으면 지역 통계에서 IP 추정보다 우선한다.
  원래 기록을 삭제·수정하지 않고 조회 단계에서 선택한다.
- 원문 ID/IP/좌표/비밀키는 관리자 응답과 새 코드의 로그에 포함하지 않는다.
- `/admin` 전반은 상단 공통 메뉴로 통일한다. 콘솔의 섹션은 가로 탭으로 옮기고
  아틀라스의 중복 세로 메뉴는 제거한다. DB 테이블 탐색기는 작업 패널로 유지한다.
  관리자 화면은 주어진 부모 너비를 사용하며, 실시간 로그의 화면 높이는 공통 헤더를 뺀다.

## 기존 자료 보존

기존 방문·페이지뷰 테이블을 수정하거나 초기화하지 않는다. 과거 자료에는 지속적인
브라우저 ID와 지역이 없어 정확한 소급 집계를 만들 수 없다. 새 기능 활성화 이후의
자료만 제공한다. 새 저장 함수는 INSERT OR IGNORE만 사용하며 UPDATE/DELETE/REPLACE,
자동 정리 작업이나 보존기한 만료 삭제를 추가하지 않는다.

## 운영자가 설정할 항목

코드 변경만으로 실서버 수집이 켜지지 않는다. 다음 준비가 없으면 관리자에 '수집 준비 중'을 표시한다.
운영 DB나 비밀 설정을 이 작업에서 조회하거나 변경하지 않았다.

1. 소유자가 `backend/schema/audience_observations.sql`의 추가 전용 스키마를 적용한다.
   기존 DB를 재생성하거나 교체하지 않는다. 앱은 DDL을 실행하지 않는다.
2. 별도 통계 저장소에 해당 테이블 SELECT/INSERT만 허용하는 제한된 게이트웨이/자격 증명을
   준비한다. 사용하는 DB 서비스가 테이블별 권한을 지원하지 않으면 검증 게이트웨이를 둔다.
   AI 작업 환경에는 운영 쓰기 자격 증명을 제공하지 않는다. 권한 설정은 실제로 검증해야 하며
   코드만으로 AI의 삭제가 기술적으로 불가능하다고 주장할 수 없다.
3. 서버 비밀 설정에 `AUDIENCE_DATABASE_URL`, `AUDIENCE_DATABASE_TOKEN`,
   32자 이상의 독립 난수 `AUDIENCE_HMAC_KEY`를 등록한다. 기존 DB 토큰이나 관리자
   암호에서 키를 유도하지 않는다. 키를 바꾸면 이전 브라우저와 연결되지 않는다.
4. 32자 이상의 별도 `AUDIENCE_EDGE_SECRET`을 서버와 Cloudflare 요청 헤더 변환에 등록한다.
   자기 도메인에서 원본으로 보내는 `X-Audience-Edge-Key`를 고정 비밀 값으로 **덮어쓴다**.
   응답 헤더나 브라우저 코드에 넣지 않는다. 원본/중간 프록시의 헤더 로그에도 남기지 않는다.
5. Cloudflare의 IP Geolocation과 **Add visitor location headers**를 활성화한다.
   `CF-Connecting-IP`, `CF-IPCountry`, `CF-Region`, `CF-IPCity`가 원본까지 전달되는지 검증한다.
   비밀 헤더가 없거나 불일치하는 직접 원본 요청은 접속망·지역 미확인으로 처리한다.
6. 선택적인 정확도 보완을 켜려면 `AUDIENCE_GEOCODER_URL`에 자체 운영 또는 계약한
   HTTPS Nominatim 호환 reverse endpoint를 등록한다. URL을 브라우저에 노출하지 않으며
   공개 `nominatim.openstreetmap.org`는 사용하지 않는다. 설정하지 않으면 위치 참여 버튼도 없다.
   해당 서비스에서 좌표 쿼리·요청/응답 원문을 로그/추적/APM에 저장하지 않도록 설정하고,
   적용 지역 경계 데이터와 서비스 가용성·접근 제한을 검증한다. 호출은 동시 1개와
   프로세스당 초당 1개 미만으로 제한하며 과부하 시 실패로 응답한다. 여러 인스턴스를
   쓰면 게이트웨이에서 전체 제한을 적용한다.
7. 공개 하단 통계 안내가 실제 수집 범위·지역 조회 서비스·운영 정책과 일치하는지 확인한다.
   새 코드의 보호 범위는 통계 저장이다. Cloudflare/Render/외부 서비스의 기존 접근 로그나
   과거 `/api/geo/country` 언어 선택 기능까지 바뀐 것으로 간주하지 않는다.

IP만으로 실제 위치, 집 주소, 건물, GPS 정확도를 보장할 수 없다. 도시 추정은 통신사망과
VPN의 영향을 받는다. 브라우저 위치 참여는 선택이며 거부해도 사이트를 계속 이용할 수 있다.

## 검증

- 새 임시 SQLite DB에서 가명화·삭제 SQL 미사용·중복 방지·날짜 경계·재방문·봇/관리자 제외·인증을 검증한다.
- 브라우저 검증은 로컬 Vite와 합성 응답만 사용하며 운영 API/DB로 요청하지 않는다.
