# 걷기 차량·시점·야간 조명 (2026-10-29)

작업 소스는 `I:/ai_root/sm-deploy/frontend/src/walkmode`이다. 로컬 검토 서버는
`http://127.0.0.1:5206/walk`이며, 실내 진입용 단지 ID가 있는 URL로 연다.
운영 배포·커밋은 수행하지 않았다. 다른 세션이 담당하는 건물 외관과 나무 디자인은
이 변경의 작업 범위에서 제외했다. 기존 저장 데이터나 DB의 삭제·변경은 수행하지 않았다.

## 차량과 시점

- 기존 17종에 23종을 추가해 총 40종. 승용·SUV·밴·픽업 34종은 별도 근거리 모델,
  나머지 트럭·버스 6종은 창문 개구부와 속이 빈 운전실을 새로 생성했다.
  실제 브랜드의 실차 스캔 모델은 아니며 최고속도도 게임용 설정이다.
- F 탑승·하차, W/S 가속·제동/후진, A/D 조향, Space 핸드브레이크, V 1·3인칭.
  차종별 최고속도·가속·제동·조향·운전석 치수와 6개 계기판 계열을 적용한다.
  120Hz 이하 간격으로 이동과 충돌을 검사한다.
- 1인칭에서 외장을 통째로 숨기던 처리를 제거했다. 외장·천장·기둥을 유지하며,
  같은 차체 메시의 안쪽 면을 별도로 렌더링한다. 전면 유리와 전면 장식만
  운전 시야에서 분리한다. 운전자 위치와 계기판·핸들은 해당 메시의 앞유리 좌표에 맞춘다.
- 하차 시 이전 보행 시점, world-up, FOV, 시선 각도와 아바타 서기 자세를 복원한다.
  보행 3인칭 카메라에도 주차 차량 높이를 포함한 충돌 검사를 적용한다.
- 근거리 38m까지 상세 모델, 100m까지 중간 모델, 이후 원거리 모델을 사용한다.
  동일 차종·재질은 전역 인스턴싱으로 묶고 중복 주차 레코드를 한 번만 그린다.
  출력 해상도와 DPR은 낮추지 않는다.

## 사운드

- 실제 녹음에서 편집한 WAV 22개, 9개 엔진 계열(small/sedan/V8/sport/race/van/truck/heavy/EV).
  공회전·부하·타력 주행·노면·타이어 소리를 혼합하고 실내에서 저역 통과/음량을 조절한다.
  차량 엔진에 기존 오실레이터 합성음을 사용하지 않는다. 충돌의 짧은 충격음은
  차체 녹음에서 편집한 효과이며 실제 사고 녹음이라는 뜻은 아니다.
- 소스와 편집 구간·이용 조건은 `frontend/public/3d/walk/cars/audio/manifest.json`에 기록했다.
  Performance Cars / muted.io, BigSoundBank/LaSonotheque, evsecrets의 CC0 녹음을 사용한다.
- 기존 Sound의 AudioContext·효과음 토글을 함께 사용한다. 일반 플레이의 기본 상태는
  효과음 켜짐이다. 자동 Chrome 검증만 저장소 지침에 따라 `--mute-audio`로 실행한다.
  오프라인 신호 검사는 스피커로 실제 들었다는 검증을 대신하지 않는다.

## 조명과 배치

- 도로 LED 외팔등, 대로 양팔등, 곡선형 LED등, 단지 보행등, 볼라드등 5종을
  스트리밍된 도로 등 위치와 동별 현관 주변에 배치한다. 전국의 실제 등기구를
  조사한 위치 자료는 아니며 도로·건물 좌표를 이용한 게임 배치다.
- 건물·차량·출입구와 겹치는 위치는 옮기거나 비운다. 차량은 도로 가까이에서
  도로 방향과 간격에 맞추고 차도·보행 띠·교차로 접근부를 비운다. 도로에서 먼
  항공사진 주차 후보는 전체 주차 면이 포장되고 장애물이 없을 때만 유지한다.
- 등기구는 5개 공용 인스턴스 계열, 최대 768개. 주변 표면은 가까운 8개 광원만
  계산한다. 차량의 부드러운 흰색 전조등/붉은 후미등과 지면 빛은 인스턴싱하고,
  운전 차량만 그림자 없는 SpotLight 2개로 실제 앞쪽 지면·벽을 비춘다.
  모든 등기구에 개별 그림자 맵을 만들지 않는다.
- 새 지면은 기존 표면을 유지하는 동안 셰이더와 텍스처를 준비한 후 공개한다.
  자원은 종료 시 해제한다. 조명은 차량·자전거·보행 충돌에 포함한다.

## 검증과 남은 성능 문제

- TypeScript 검사와 Vite 빌드 통과.
- `test-walk-bicycle.mjs` 12개, `test-walk-parking.mjs` 4개 통과.
- `test-walk-driving-physics.mjs` 4개 통과: 40종의 서로 다른 속도 제한,
  30/60/144FPS 조향·이동 일관성, 최고속 얇은 벽 충돌, 차량 충돌·제동.
  고속 차량은 추가 분할로 물리 검사 간 이동을 14cm 이하로 제한한다.
- `check-walk-car-structure.py`: 40종 모두 실제 차체 유지, 위쪽 천장 교차,
  정면 시야와 화면 안 계기판 검사 통과. 대표 6종의 앞·옆·위·외부 PNG를 보관했다.
- `check-car-recordings.py`: 9계열 × 4조건, 36개 오프라인 렌더에서 신호,
  클리핑·종료 후 잔류음·소스 수를 검사했다. 차량 오실레이터 0개.
- 신도6 실제 장면: 반복 승하차 5회, 1인칭에서 직접 하차한 뒤 보행 시점 복구,
  조명 5종 163개, 검사 시점의 주차 차량/가로등 겹침 0건. 한 지역의 결과다.
- 야간 1440×900, DPR1, RTX3070/ANGLE: GPU 준비 추가 후 평균 51.42FPS,
  최저 1초 38FPS, p95 18.6ms, p99 53.6ms, 최대 333.2ms.
  **최저 50FPS 요구는 아직 미달이다. 성능 보장 또는 모든 문제 해결로 보고하면 안 된다.**
  같은 반복 승하차 구간의 GPU 메모리 집계는 geometries414/textures80으로 유지됐다.
  상세 결과·스크린샷은 `tmp/walk-driving-night-prepared`와
  `tmp/walk-car-structure-final`에 있다. 이후 결과가 나오면 추가 기록한다.
- 모바일 에뮬레이션(같은 RTX3070, CSS390×844, 실제 출력780×1688, DPR2):
  평균52.43FPS, 최저1초47FPS, p95 18.6ms, p99 52.8ms, 최대179.8ms.
  실제 휴대폰 측정이 아니며 이 조건도 최저50FPS 미달이다.
  승하차 5회의 집계는 geometries307/textures68로 유지됐다.
  결과는 `tmp/walk-driving-mobile-final`에 있다.

검증 브라우저는 새로운 임시 컨텍스트이며 기존 DB를 테스트 대상으로 사용하지 않았다.
