# 전광판 투자자 수급 롤링

`origin/main`의 `9164e3b9`에서 분리한 `feat/investor-rolling-20261116` 작업이다. 네온 테마와 기존 전광판·광고·시세·검색·차트 경로를 재사용한다.

## 동작

- 전광판에서 KOSPI/KOSDAQ 선택 시 광고 왼쪽에 개인·외국인·기관 순매수/순매도 금액을 표시한다. 좁은 화면에서는 광고 위로 배치한다. NASDAQ 100에는 국내 수급 패널을 표시하지 않는다.
- 기존 `/api/investor/indices?fresh=true`의 공유 10초 폴링으로 시세와 연결 상태를 확인하되, **수급 패널의 기준값은 1분마다** 최신 수신값으로 교체한다. 숫자 연출 때문에 서버 요청을 추가하지 않는다.
- 네이버 지수 통합 API의 원본은 **억원 단위 순매수·순매도**다. 각 행의 툴팁에 실제 기준 금액을 제공하고, 재생/일시정지 아이콘 툴팁으로 연출 상태를 구분한다. 사용자가 요청한 수신 시각·안내문·상태 텍스트는 화면에서 제거했다.
- 장중 첫 응답부터 120ms 간격으로 바로 움직이며, 바뀐 자리만 115ms 동안 세로로 굴린다. 최초 움직임은 지수 등락 방향을 따르고 이후에는 최근 실제 수급 차이를 사용한다. 매분 시작한 60초 구간 동안 보간과 미세 변화를 이어간다. 원본이 같은 경우에도 작은 원 단위 연출은 계속된다.
- 미세 변화는 짧은 가속·감속, 느린 흐름, 작은 흔들림의 서로 다른 시간 축을 혼합한다. 투자자별·분별 시드가 달라 고정 사인 파형을 반복하지 않는다. 변화폭은 최대 1,800만원으로 원본 반올림 정밀도보다 작게 제한하며, 누적해서 불어나거나 순매수·순매도 부호를 바꾸지 않는다. 0인 값은 그대로 유지한다.
- 최초 연결·거래일 변경은 실제 값에서 시작한다. 장 마감·수신 지연·일시정지·효과 최소화·동작 줄이기에서는 수신값을 그대로 표시한다. 다른 탭에서는 연출을 중지하고 복귀 시 지나간 움직임을 재생하지 않는다.
- 백엔드 응답에 수집 시각(`fetched_at`, 체결 시각 아님)과 거래일(`business_date`)만 추가한다. 수집 30초, 지수 시세 90초를 넘기거나 당일 자료가 아니면 보간하지 않는다. 백엔드와 프런트엔드 변경을 함께 배포해야 한다.
- 시장 선택 탭에 `눌러서 시장 전환`, `보기 →`, `✓ 선택됨`, 테두리와 호버/포커스 상태를 추가했다. 기존 방향키 전환도 유지한다.
- 수급 패널의 헤더·간격을 축소하고 조작은 아이콘 하나로 정리했다. PC에서는 광고와 같은 줄을 사용하여 패널과 광고 높이를 합산하지 않는다. 좁은 화면에서만 위아래로 놓는다.
- 실제 광고 채움·해제와 반응형 변화에 따른 상단 높이를 ResizeObserver로 측정한다. 실제 높이와 32px 여유만큼 수면을 내려서 시작하며, 배가 공유하는 카메라의 시점 높이도 같이 보정한다. GPU 장면을 다시 만들거나 출력 해상도를 낮추지 않는다.

## 검증

- `npm run build`
- `node --test tests/investor-flow-motion.test.mjs tests/us-market-refresh.test.mjs`
- 백엔드에서 `python -m pytest -q tests/test_investor_flow_metadata.py tests/test_overview_refresh.py`
- Vite를 `127.0.0.1:5186`에 실행한 후 `python frontend/scripts/test-investor-flow-browser.py`

브라우저 검증은 음소거한 headless Chrome, DPR 1, 1600×1000 및 1280/768/390/320px 화면에서 수행했다. 모든 API는 메모리 응답으로 대체하고 외부 광고·분석 요청은 차단한다. 배너 대체 요소로 광고 왼쪽 배치를 검사한다. UI 검증은 WebGL 미지원 폴백에서 진행하며, 기존 바다·선박의 GPU 성능 측정 결과를 의미하지 않는다. 해상도를 낮추는 변경은 없다. 캡처는 작업 트리 `tmp/investor-flow-review/`에 남긴다.

별도 실제 바다·배 검증: Chrome, NVIDIA RTX 3070 / ANGLE D3D11, balanced, 1600×1000 / DPR 1에서 10초 구간 평균 59.81fps, 최저 1초 58fps, p95/p99 16.8ms, 최대 프레임 33.4ms를 기록했다. 바다 출력도 1600×1000을 유지했고 배 상태는 ready였다. 광고가 없는 PC 수급 패널은 약 51px였다. 이 결과는 해당 장비·구간에 한정하며 모든 기기·전체 항로의 성능을 의미하지 않는다.

로컬 검증은 애플리케이션 서버 시작, DB 접근·마이그레이션·저장 데이터 수정 없이 수행한다. 운영 배포는 사용자의 2026-11-16 배포 지시 범위에서 기존 `stock_market` 워크스페이스의 `kospi-predictor` 서비스에 수행한다.
