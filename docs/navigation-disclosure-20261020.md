# 상단 메뉴 한 줄 구성

- 공통 Masthead의 가로 스크롤 링크 목록을 한 줄 메뉴와 ‘전체 보기’ 패널로 변경했다.
- 1면, 해외증시, 코스피·코스닥·S&P500·나스닥 맵 6개는 항상 직접 노출한다.
- 증시버블, 증시궤도, 시총대결, 글로벌시총, VOLTARIS는 전체 보기에서 제공한다.
- 나머지 링크는 폰트·언어·컨테이너의 실제 너비를 측정하여 남는 공간에만 노출한다. 전체 보기에는 기존 23개 링크를 모두 제공한다.
- 전체 보기는 시장·종목, 시장 지도, 투자정보·콘텐츠, 시각화·탐험으로 분류한다. PC 4열, 모바일 2열이며 세로 스크롤을 사용한다.
- 현재 페이지 표시, 키보드 아래 방향키 진입, Escape 닫기와 버튼으로 초점 복귀, 바깥 클릭·초점 이동·페이지 이동 시 닫기를 제공한다.
- 기존 경로, 시세 티커, 선물 지표, API, DB 및 자동 작업은 변경하지 않았다.

## 검증

- `npm run build`: TypeScript 및 배포용 Vite 빌드.
- `node --test tests/editorial.test.mjs tests/us-market-refresh.test.mjs tests/visitor-count.test.mjs`: 기존 회귀 검사 11개.
- `NAV_TEST_URL=http://127.0.0.1:5199 python frontend/scripts/test-site-navigation.py`: DB 및 앱 자동 작업을 시작하지 않는 읽기 전용 프리뷰에 접속한다. 브라우저의 API 변경 요청은 차단한다.
- 한국어·영어, 국내·글로벌, 320–1440px 9개 너비의 36개 조합에서 핵심 링크 노출과 가로 넘침을 검사한다. PC·모바일 및 라이트·다크 패널 8개 조합과 키보드·바깥 클릭·페이지 이동을 확인한다.
- 브라우저는 `--mute-audio`로 실행하며 결과와 캡처는 Git에 포함하지 않는 `tmp/site-navigation/`에 저장한다.
