# 페이지 전환 및 자동 스크롤 개선

사용자 요청: 페이지 전환 후 이전 위치나 푸터로 이동하는 문제를 점검하고 수정·배포한다.
추가 요청: 지도는 실제 맵 면적이 시작하는 위치로 정확히 이동한다.

## 변경

- 새 링크는 화면 상단에서 시작한다. 읽던 위치는 뒤로·앞으로 이동 및 같은 방문의 새로고침에만 복원한다.
- 위치 복원을 Suspense 내부로 옮겨 실제 페이지가 표시된 후 적용한다. replaceState로 조회 조건이 바뀌어도 같은 방문의 위치를 찾는다.
- 복원은 짧은 안정화 뒤 종료하며 휠·터치·포인터·스크롤 키·새 이동이 발생하면 중단한다. 실시간 DOM 갱신이 계속 위치를 되돌리지 않는다.
- 지도 5개 화면은 실제 캔버스 시작점을 표시한다. 새 지도 방문은 이 지점을 고정 메뉴 아래 12px에 맞춘다. 저장된 표 보기는 표의 시작점으로 이동한다.
- 모바일 부동산 지도의 고정 지역 경로도 가림 높이에 포함한다. 지역 선택 뒤 이동 역시 캔버스를 기준으로 한다.
- 종목 목록, 뉴스·토론 페이지, 다음 기사·게시글은 React 반영 후 새 내용의 시작점으로 이동한다. 스크롤 패널 내부에서는 해당 패널만 이동한다.
- 종목 뉴스에서 아직 도착하지 않은 페이지로 이동해 빈 화면을 표시하던 다음 버튼 조건도 수정한다.

## 검증

- TypeScript 및 전체 Vite 프로덕션 빌드.
- `frontend/scripts/test-scroll-navigation.py`: 데스크톱 1280px·모바일 390px, 지연 페이지 로딩·새 방문·재방문·뒤로/앞으로·해시·사용자 입력 취소·뉴스/토론·종목 목록 40개 검사.
- `frontend/scripts/test-map-entry.py`: 실제 App의 코스피·코스닥·S&P500·NASDAQ100·부동산 지도 진입 위치를 두 화면 크기에서 측정한다. 목표와의 오차 3px 미만을 요구한다.
- 테스트의 API는 합성 응답으로 대체하며 기존 DB나 서버를 실행하지 않는다.

최신 운영 main에서 별도 작업 폴더를 만들었다. 원래 작업 폴더의 다른 미완료 변경은 배포에 포함하지 않는다.
DB 직접 명령·삭제·초기화·마이그레이션은 수행하지 않는다. 기존 Render 자동 배포로 반영하며 운영 커밋과 정적 번들 확인 결과는 작업 폴더 QA 로그에 남긴다.
