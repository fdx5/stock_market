# Fold8 드론뷰 계산 비용 개선과 배포 기준

2026-10-18. 기준 운영 커밋은 `5e3a7247`이다. 사용자는 품질과 출력 해상도를 유지한
개선을 요청했고, 최종적으로 “최저 48fps면 개선되었다고 보고 배포해”라고 지시했다.
이 기록은 최저 **1초 구간** 48fps 결과에 따른 배포이며, 지속 50fps 달성 기록이 아니다.

GPU 평균 시간은 약 14.3% 줄었다. 평균 FPS와 프레임 간격의 꼬리는 개선을 확인하지
못했다. 최저 1초 FPS 48은 모든 개별 프레임이 20.83ms 이내라는 뜻이 아니다.
렌더 호출이 실제 프레임 번호를 증가시키고 화면을 표시했는지 확인하며 측정했다.
타이머 자체를 동일하게 고친 기준 빌드와 비교했다.

Chrome, CSS 화면 932×704 가로, DPR 2.625, 기존 3D 렌더 배율 2.00 및 실제 캔버스
1864×1408, high, WebGPU. CPU 2배 제한, RTX 3070 그래픽 클럭 405MHz,
모바일 WebGPU 기능/한도 제한을 적용했다. GPU 메모리 클럭은 부하 시 5001MHz가
관측되어 요청했던 810MHz 고정을 가정하지 않는다. 이 설정은 Fold8 GPU와 동등함을
보장하지 않는다. 원격 데이터 응답 및 브라우저/OS 부하도 실행마다 달라질 수 있다.

실기기의 GPU 58ms 이상이라는 사용자 측정과 이 데스크톱 시뮬레이션은 직접 비교할
수 없다. 58ms가 매 프레임의 GPU 처리 시간이라면 역수는 약 17.2fps다. 이를 50fps로
만들려면 GPU 처리 시간을 약 20ms로 줄여야 하는데, 이번 비교에서 그 규모의 감소를
증명하지 않았다. **실기기 20→50fps 또는 2.5배 향상으로 보고하지 않는다.**

## 품질을 유지하며 줄인 작업

1. **그림자 전용 경로**: 불투명하고 정점 변형이 없는 삼각형은 위치만 출력하는 깊이
   셰이더를 사용한다. 그림자에 필요 없는 법선·UV·색상·월드 위치 출력은 생략한다.
   알파 테스트, 정점 변형, 커스텀 그림자, 굴절 클리핑은 기존 경로를 유지한다.
   공유 나무 지오메트리에 한해 위치가 완전히 같은 정점을 합친 그림자 전용 인덱스를
   캐시한다. 삼각형 수·순서·방향·좌표·그리기 범위는 바꾸지 않는다. 주 화면의
   원래 정점과 재질은 유지하며, GPU 버퍼는 원 지오메트리와 함께 회수한다.
2. **중복 행렬 곱 제거**: 인스턴스의 부모 월드 행렬이 정확한 단위 행렬일 때만
   인스턴스 행렬을 직접 사용한다. 이전 프레임 행렬 계산은 유지한다. 비단위 행렬은
   원래 계산을 사용하며, 상태 변화 시 파이프라인/버퍼 캐시를 올바르게 무효화한다.
3. **맑은 날 불필요한 날씨 계산 생략**: 기존에는 비·눈 강도가 0이어도 표면의 두
   5옥타브 노이즈를 계산했다. 이제 비 또는 눈이 있을 때 해당 계산만 실행한다.
   활성 날씨의 수식·표본·연산 순서는 유지한다. 비·눈 표현을 없애지 않았다.
4. **CPU 작업 분산과 임시 할당 감소**: 교차로 탐색과 차량·바퀴·보행자 메시 생성을
   약 2ms 단위로 양보한다. 각 모델 생성 자체가 2ms 이하라는 보장은 없으며 남은
   긴 작업도 관측됐다. 항적 배열은 직접 기록/재사용하고, 물 높이 샘플링의 임시
   클로저 및 불필요한 지형 조회, 교통 조회의 임시 배열/객체를 줄였다. 지형 경계구는
   워커에서 계산해 전달하고 UI에서 전체 정점을 다시 순회하지 않는다.
5. **계측 수정**: 타임스탬프 쿼리 수를 늘리고 전체 GPU 시간은 첫 시작부터 마지막
   종료까지 측정한다. 패스 합계 외 복사 등도 포함하며, 생략된 패스의 오래된 값은
   감쇠시킨다. 계측 수정 자체를 렌더링 성능 향상으로 계산하지 않는다.

출력 해상도, 품질 프리셋, 수면 효과, 그림자 해상도와 기존 갱신 정책, 나무 밀도 및
주 화면 모델/텍스처 품질을 낮추는 설정은 추가하지 않았다. 기존 블록별 나무 컬링,
120Hz 프레임 페이싱, 랜드마크 텍스처 거리별 처리 등은 기준 운영에 이미 포함되어
있었으므로 이번 변경의 새 효과로 집계하지 않는다.
