# 미국 지수 맵 상단 나스닥100 선물

`/nasdaq100-map`, `/sp500-map`의 ‘오늘의 핫이슈’ 오른쪽에서 기존 코스피200
배지 두 개를 ‘나스닥100 선물’, ‘나스닥100 야간선물’로 교체한다.
기존 네온 배지 스타일·국채 표시·맵 URL·지도 및 종목 기능은 유지한다.
국내 맵과 다른 페이지는 기존 코스피200 배지를 사용한다.

두 배지는 같은 CME NQ 계약의 서로 다른 시간 구간이다. 미국 동부 시간
09:30~16:00 구간의 최근 시세를 첫 칸, 이 구간 밖의 최근 시세를 야간 칸에
표시한다. 휴장일의 거래 여부를 임의로 추정하거나 거래중으로 표시하지 않는다.
각 칸에 실제 공급 시각을 표시하고 툴팁에서 구간·공급 지연·5분봉 여부를 안내한다.

- 정규시간대 등락률: 전회 정규시간대 마지막 시세 대비.
- 야간 등락률: 해당 야간 시세 직전 정규시간대 마지막 시세 대비.
- 과거 구간은 NQ 5분봉, 진행 중인 구간은 기존 공용 시세 피드의 최신 NQ 값을 사용한다.
- 10초마다 두 칸을 한 번에 조회하고 5분봉 수집은 60초 캐시로 공유한다.
- 실패·과거 응답은 원래 시각과 가격을 보존하고 수집 지연으로 표시한다.
- 모든 추가 상태는 프로세스 메모리에만 있다. DB·회원 데이터·마이그레이션 변경은 없다.

검증: Python 36개, Node 12개 테스트와 전체 TypeScript/Vite 빌드 통과.
공개 공급처 실제 조회에서 정규시간대와 야간 시세·각각의 실제 시각을 확인했다.

참조: [CME NQ](https://www.cmegroup.com/markets/equities/nasdaq/e-mini-nasdaq-100.contractSpecs.html),
[Nasdaq 정규시간대 정의](https://listingcenter.nasdaq.com/rulebook/nasdaq/rules/nasdaq-equity-1).
