# 건물 사진 대체 검색 긴급 수정

운영 커밋 `d74892e`에서 실제 이름으로 조회한 5곳 중 더#해운대아델리스와 망미동 한성기린은 사진 0건이었다. 잘못 인코딩된 최초 진단은 근거에서 제외하고 UTF-8로 저장한 진단 스크립트로 재측정했다.

검색 결과가 없을 때 위키 외 사진을 찾기 위해 다음을 수정했다.

- 등록 명칭의 `더#` 등을 검색 명칭으로 정리한다.
- 건물명·지역·전경 검색에 결과가 없으면 전경 조건 없이 건물명·지역으로, 이어서 구별 가능한 건물명으로 검색한다. 일반 명칭은 지역 조건을 유지한다.
- 검색 결과 12개에서 80개로 확대해 상위 블로그 결과에 가려진 비블로그 자료도 검사한다. 카카오 공식 API 범위 안의 값이다: https://developers.kakao.com/docs/ko/daum-search/dev-guide
- 전체 초고층 건물 사진을 제외하던 세로 비율 제한을 완화한다. 블로그 제외·출처 표시·원본/썸네일 실패 대체는 유지한다.
- 검색 재시도는 최대 3회, 각 요청 4초로 제한한다. 새로운 메모리 캐시 키를 사용하며 기존 저장 DB를 변경하지 않는다.

격리된 Python AST 테스트 9개 통과. 실제 운영 사진 보유율과 이미지 파일 로딩은 배포 후 `qa-building-photo-coverage.py`로 다시 검증한다. 이 문서 작성 시점에 운영 효과는 아직 미확인이다.

우선순위: 사진 대체 검색 긴급 배포를 먼저 완료한다. 이후 사용자 요청인 최대 고도 1,000m, 사용자 지정 오토 파일럿 속도(최대 200km/h)를 구현한다. 로딩 3배 개선은 사용자의 중지 요청에 따라 보류 중이다.
