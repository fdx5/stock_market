# 지도·건물뷰에서 시작하는 드론 검색 공통 적용

368fd8f의 검색·워프는 드론 탐험에만 연결되어 있었다. 부동산 지도 → 3D 건물뷰 → 드론플레이에서는 검색 입력이 렌더링되지 않았다. 드론이 켜진 모든 ComplexHologram에 같은 검색 컴포넌트를 제공한다. 지도/건물뷰에서 결과를 선택하고 이동하면 원래 단지를 지도 설정의 기준으로 유지하면서 선택 좌표의 공통 전체화면 드론 탐험으로 이동한다. 출발 시각·목적지명·이전 URL은 단일 메모리 슬롯으로 넘겨 동일한 5초 워프/실제 프레임 대기/취소를 사용한다. 취소하면 이전 지도 URL로 돌아간다. 직접 링크/새로고침에 워프가 반복되지 않는다.

모바일 지도 드론의 고정 canvas가 검색 헤더를 덮던 z-index와 조작 영역 배치를 보완했다. 헤더 실측 높이를 모든 3D 경로에서 관측하며 출력 canvas 해상도/DPR는 유지한다. native 속도·고도 dialog에 data-covers-page를 지정하여 배경 페이지의 content-visibility:hidden 규칙이 내부 입력을 숨기지 않게 했다. 모바일 3D layer의 Escape/Tab 처리는 native 설정 dialog에 양보하고 검색 입력을 포커스 순서에 포함한다. 오래된 '상공 500m' 드론 버튼 설명은 '수동 고도 상한 없음'으로 정정했다.

검증은 음소거 Chrome 154, 독립 브라우저, 운영 API를 호출하지 않는 읽기 전용 공개 GIS/실거래 스냅샷을 사용한다. 실제 부동산 지도에서 단지 상세 → 3D 건물뷰 → 드론 버튼을 클릭하고 PC 1440×1000/모바일 touch 390×844에서 입력·이동·속도 200·자동 고도 1000·native Escape를 확인한다. 강남데시앙은 CDP IME 조합 중, 스페이스 없이 첫 결과 '세곡동 강남데시앙파크'를 확인한다. 이동 뒤 URL/장면 원점/실제 드론 좌표 일치 및 이전 canvas와 세션 종료를 확인한다. 증거는 tmp/drone-map-search/common-search-v5-scoped/report.json 및 스크린샷이다. TypeScript와 V5 production build를 검증했다.

DB·저장 데이터·백엔드는 변경하지 않는다. 이 배포는 지도 경로의 기능 누락/숨김 수정이며 로딩 3배 목표의 완료 배포가 아니다. 영화적인 워프 연출 변경과 로딩 성능은 후속 배포로 분리한다.
