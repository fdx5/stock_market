# 해상도 자동 하향 제거

사용자의 최우선 지시: 허락 없이 출력 해상도를 절대 낮추지 않는다. FPS 개선은 계산·로딩·렌더링·자원 관리로 수행한다.

직전 배포 `601cd83`의 데스크톱 품질 프리셋은 `high`였지만, 프레임 압력에 따라 픽셀 비율을 낮추는 기능이 있었다. 실제 Chrome 측정에서 해운대는 1.17→1.03→0.90, 창동은 0.90→0.80을 기록했다. 이전 8개 구간 최소 50fps 결과는 해상도가 유지된 조건의 성능 달성을 입증하지 않는다. 해당 결과를 동일 품질의 성능 개선 근거로 사용하지 않는다.

이번 수정은 프레임 시간 기반 해상도 제어 함수와 렌더 루프의 호출을 제거한다. 전체 화면/리사이즈 때 GPU 시간으로 픽셀 비율을 낮추는 경로도 제거한다. 첫 유효 크기에서 정한 픽셀 비율을 장면 종료까지 유지한다. 자동 초기값은 실제 디스플레이 DPR 미만으로 낮추지 않으며, 선택적 데스크톱 슈퍼샘플링은 초기 픽셀 예산 안에서 정한다. 이후 비행·로딩·FPS 저하·전체 화면 변경으로 비율을 내리지 않는다. 사용자가 직접 지정하는 기존 `pr` 비교 파라미터는 유지한다.

해안/도로/건물 작업자의 분산, 가까운 순서의 상세 로딩, 실패 재시도, 제한된 동시성, 종료 및 타일 자원 회수, 새 형상 반영 제한은 유지한다. 형상·텍스처·물·열차 품질 프리셋을 이번 수정에서 변경하지 않는다. 해상도를 유지하므로 출력 픽셀 수와 GPU 부하는 직전 자동 하향 버전보다 커질 수 있다. 50fps 미달 시 이를 그대로 보고하며 허락 없이 해상도를 다시 낮추지 않는다.

개발 원칙을 `frontend/AGENTS.md`에 명시했다. 고정 픽셀 비율·전체 화면/복귀·고밀도 화면의 네이티브 DPR 보존·명시적 비교값을 포함한 관련 회귀 32개를 통과했다. Chrome 검증은 FPS와 `pixelRatio`, `quality`를 함께 기록한다.
