# 부동산 지도 로컬 검토

검토 주소: http://127.0.0.1:5173/realestate-map

2026-09-26 로컬 개발. 커밋·PUSH·운영 배포는 수행하지 않았다.

## 적용 내용

- `GET /api/realestate/explore`: 지역의 조회 대상 전체에 검색·필터·정렬을 적용한 뒤 100개씩 탐색한다. 현재 화면의 상위 단지만 검색하는 구조를 제거했다. 검색 범위는 선택한 시·도/구/동이며 전국 주소 검색은 아니다.
- 단지명·동 이름 검색, 가격 범위, 전용면적 범위, 준공연도, 기간 거래 건수, 마지막 거래 시점 조건.
- 가격·상승률·거래량·최근 계약·이름순 정렬 및 페이지 이동. 화면 회전 시 페이지 크기를 유지한다.
- 면적 조건을 지정하면 해당 면적 범위에서 거래가 많은 평형을 선택한다. 대표/선택 평형 가격에 대한 필터이며 모든 평형 중 최저가격 검색은 아니다.
- 거래 없음 / 비교 기준 부족 구분. 실제 거래 단지 수와 등락 비교 가능한 단지 수 분리.
- 기준가에 사용한 거래 건수·날짜·층·가격, 직거래 대체 여부, 기간 내 최초 거래 대비 여부 표시.
- 차트용 최근 40건과 독립된 1년 평형 거래 건수 제공.
- 지역·조건 전환 시 이전 조회 결과가 새 지역 아래에 노출되지 않도록 응답 키 검증·요청 취소·재시도 처리.
- 관심 단지 최대 100개 기기 내 저장, 저장한 평형 복원, 최근 지역 기억. 저장 공간을 사용할 수 없는 경우 안내.
- 최대 3개 단지 비교. 단지별 평형 변경, 기준가격·기준일·표본·거래량·준공연도 비교.
- 상세 URL에 단지·평형·매매/전세/월세 상태 포함, 링크 복사, 지역 탐색 이력 복원.
- 현재 표시 결과의 CSV 내보내기. 한글 인코딩과 스프레드시트 수식 주입 방지 처리.
- 모바일·태블릿에서 표를 카드 목록으로 전환. 필터 접기, 44px 주요 조작 영역, 16px 입력 글자, 안전영역 여백.
- 상세 카드 폭 확대, 중첩 거래목록 스크롤 제거, 키보드 포커스 순환·복귀, Escape 닫기, 기간 라디오 의미 수정.
- 상세 거래 차트에 1년/2년/수집 전체 선택 및 개별 거래 선택 슬라이더. 연속 시세로 오해하지 않도록 개별 거래 점 표시.
- 전세가율의 매매/전세 기준일 병기 및 90일 이상 차이 안내. 전월세 조회 재시도와 자료 미연결 상태 구분.
- 지역 지도와 트리맵의 색상 기준을 ±10%로 통일. 지역 집계와 현재 표시 단지 집계의 차이 안내.
- 3D 지도가 화면 밖이거나 탭이 비활성화되면 애니메이션 루프 중지. 렌더러 생성 실패 시 지역 선택으로 대체.

실제 자료 확인 당시 강남구 조회 대상은 389개였다. 이 숫자는 수집 상태와 기준일에 따라 달라진다. API 지연 시간은 화면 렌더링 성능의 측정값이 아니다.

실제 브라우저/모바일 UI 자동화는 연결 도구의 실패로 수행하지 못했다. 반응형 CSS와 컴포넌트 로직을 적용했지만, 화면별 겹침·터치·키보드의 실기기 검증을 완료한 것으로 간주하면 안 된다.

검토 권장 화면: 360/390px 휴대전화, 768/1024px 태블릿, 1440px 데스크톱. 가로 회전, 글자 확대, 소프트 키보드, 상세 닫기/뒤로가기, 비교 패널을 함께 확인한다.

## 실행 구성

- 기존 프런트엔드: `127.0.0.1:5173`
- 검토용 부동산 API: `127.0.0.1:8002`
- 나머지 기존 API: `127.0.0.1:8000`
- `frontend/.env.local`: `REALESTATE_API_TARGET=http://127.0.0.1:8002` (Git 제외)

검토 API는 기존 저장 자료를 조회하며 전체 사이트의 발행기·스케줄러를 실행하지 않는다. 수집 키도 이 프로세스에서 비활성화한다. 따라서 로컬 화면의 실시간 자료 연결 안내는 의도된 상태이다.

백엔드 폴더에서:

```powershell
.venv\Scripts\python.exe -m scripts.serve_realestate_review
```

프런트엔드 폴더에서:

```powershell
npm run dev -- --host 127.0.0.1 --port 5173
```

일반 개발 서버로 돌아갈 때는 `.env.local`의 `REALESTATE_API_TARGET` 설정을 제거하면 기존 8000번 API로 연결된다. 운영 빌드는 이 개발용 프록시 설정을 사용하지 않는다. 향후 배포 시 새 `/explore` API와 프런트엔드를 함께 배포해야 한다.

테스트:

```powershell
# backend/
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe -m pytest tests/test_realestate_map.py tests/test_realestate_summary.py tests/test_realestate_explore.py tests/test_realestate_rent.py tests/test_realestate_facts.py -q

# frontend/
npm run test:realestate
npm run build
```

## 남은 범위

- 독립적인 전세/월세 지도와 예산 검색은 적용하지 않았다. 현재 지도·필터·비교는 매매 중심이며, 전월세는 단지 상세에서 제공한다.
- 통근·학교·주변 시설·공급면적·현재 매물 자동 수집은 추가 데이터 연결이 필요하다.
- 새 거래 알림·계정 간 관심 단지 동기화는 서버 저장 및 알림 체계가 필요하다.
- 실제 휴대전화/태블릿 접속을 위한 LAN 서버 실행은 자동 승인 검토에서 거부되었고 구체적인 이유는 제공되지 않았다. 이 작업에서는 루프백 주소의 기존 개발 서버를 사용했다.
- 저장 자료가 부족하거나 외부 정보 연결이 없는 단지는 임의로 데이터를 채우지 않고 해당 상태를 표시한다.

기존 작업 디렉터리에 이미 있던 별도 미추적 파일들은 정리하거나 변경하지 않았다. 검토용 로그는 `.local-server/`에 있으며 제품 변경 파일과 구분해 검토한다.
