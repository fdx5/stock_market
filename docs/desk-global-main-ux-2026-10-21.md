# desk / global 메인 요약 개선

두 화면의 기존 신문 지면과 주간판/야간판 색상 체계를 유지하면서 메인 요약의
읽기 순서를 정리했다. 지수 카드의 숫자·등락 배지·실제 시세 시각을 먼저 읽고,
환율/수급/시장 맥락과 개별 종목의 분포를 비교할 수 있다.

- 한국/미국 시장 전환 링크와 시장 지도 진입을 요약 안에 배치했다.
- 수집 시각에는 날짜와 KST를 명시하고, 지수별 제공 시각을 따로 표시한다.
  최근 집계 시각을 지수의 실제 체결 시각으로 표현하지 않는다.
- 상승 종목 수만 보이던 영역에 전체 확인 종목 중 상승 비율을 추가했다.
  코스피 500·코스닥 200 / S&P 500·나스닥 100의 수집 범위를 명시한다.
- 등락률 7개 구간의 종목 수를 표시한다. 막대 선택 시 해당 구간의 등락 폭
  상위 3종목과 상세 링크를 보여 준다. 빈 구간은 빈 상태로 표시한다.
  구간 경계는 스크린리더 이름에 정확히 명시한다.
- 중복 티커는 한 번만 세며, 가격/등락률을 확인할 수 없는 종목은 분모에서도
  제외한다. 전체 시세가 없을 때 0%로 꾸미지 않는다.
- 미국 섹터/빅테크의 시가총액 기반 계산 자료가 없으면 임의의 주도 섹터나
  0.00%를 표시하지 않는다.
- 모바일에서는 분포를 선택적으로 펼친다. 버튼의 펼침 상태, 키보드 선택,
  상세 닫기 후 포커스 복귀를 지원한다. 기본 지수·상승/보합/하락 비중은 계속 보인다.
- 원자재/가상자산 가격, 수급 단위, 구간 설명의 글자 크기와 간격을 조정했다.
  영상 링크도 '20개 더보기' 대신 실제 전체 개수로 표시한다.

계산은 기존 공유 시세 응답에서 수행한다. 새 API, 별도 수집, 사용자 정보 저장,
DB/서버 로직 변경 또는 마이그레이션은 추가하지 않았다. 생성된 시스템 목록의
프런트 파일 수만 빌드 과정에서 갱신된다. 기존 08/16시 영상 배치와 드론 코드는
변경하지 않는다.

## 검증

- 분포 경계, 중복/누락 처리, 상세 정렬, 빈 데이터 및 기존 메인/영상 렌더 계약:
  Node 테스트 11개 통과.
- Windows Chrome / Playwright WebKit에서 320, 390, 768, 1440px의 16개 조합:
  한국어/영어, 밝은/어두운 테마, 넘침, 시장 링크, 펼치기, 키보드 선택, 실제 종목 링크,
  빈 구간, 포커스 복귀, 동작 줄이기 설정을 확인했다.
- 기존 5초 그래프 재생, 값이 바뀔 때만 숫자 전환, 포커스 보존, 화면 밖/백그라운드
  중지, API 일부 실패 시 마지막 정상 값 유지 검사를 통과했다.
- Chrome/WebKit의 12개 글꼴·배율 조합에서 각 9개 애니메이션 시점의 숫자 잘림을
  확인했다. iPad 크기, 1.25배 확대, DPR 2/3 조건을 포함한다.
- 실제 운영 API를 읽는 로컬 프런트에서 두 메인 화면을 시각 확인했다. 테스트는
  로그인하지 않은 새 브라우저 컨텍스트와 독립된 메모리 응답을 사용한다.

이는 Windows에서 실행한 WebKit 검증이다. macOS/iOS 실기 검증이나 전체 페이지의
모든 기기 성능을 보증하는 자료로 사용하지 않는다.

별도 단독 성능 비교는 같은 메모리 응답, Chrome, DPR 1, 높이 960px에서 각 7초씩
실행했다. 1초 구간 최저 FPS는 1440px에서 기존 54 / 변경 56, 390px에서 기존 56 /
변경 56이었다. 변경 화면의 p95 프레임 간격은 두 크기 모두 18.1ms였다. 390px의
최대 간격은 기존 24.2ms / 변경 32.9ms로 단일 멈춤이 더 컸다. 이 측정은 요약 영역의
한정된 fixture 비교이며 전체 메인 페이지나 모든 기기의 성능 보증이 아니다.
