# 궁궐 외곽 조경과 드론 오토 파일럿

경복궁·창경궁·덕수궁의 실제 사적지 필지 경계를 따라 잔디와 꽃을 배치한다.
중앙 흙마당과 출입 축은 유지하며 내부의 원형·동심원 화단은 만들지 않는다.
외곽 조경 폭은 각각 36m, 28m, 22m이고 도로·물·등록 건물에는 식물을 놓지 않는다.
원거리 지면 색상과 근거리 3D 꽃·잔디를 함께 사용한다. 사용자가 요청한 조경 표현이다.

드론 화면 왼쪽에 오토 파일럿 시작·정지 버튼을 추가했다.
이동 중 켜면 누른 순간의 수평 속도로 항속하고, 정지 상태에서 켜면 기본 100km/h로
비행한다. 바라보는 수평 방향으로 전진하며 지상 100~250m 범위에서 완만하게
고도를 바꾸고, 전방 지형과 지붕 높이에 따라 상승·감속한다. 범위 밖에서 시작하면
먼저 고도를 맞춘다. 통과할 수 없는 높은 장애물 앞에서는 대기한다.
화면 드래그와 회전 입력은 방향을 조절하고 이동·고도 입력은 수동 비행으로 전환한다.
기존 앞쪽 타일 로딩 대기와 충돌 처리를 그대로 적용한다. 대기나 장애물로 감속한 뒤에는
켜는 순간에 저장한 항속 속도로 복귀한다. 켤 때 누르고 있던 이동 입력은 해제될 때까지
무시하고, 그 뒤에 새로 하는 이동·고도 조작은 수동 비행으로 전환한다.

검증:

- TypeScript 검사 및 운영 Vite 빌드 통과.
- 조경·오토 파일럿·랜드마크·CDN 회귀 검사 21개 통과.
- 실제 WebGPU 드론 세션에서 PC와 모바일 버튼 시작·정지, 자동 전진, 고도 유지,
  드래그 방향 변경, 수동 전환 검사 통과. 조작 버튼이 HUD·도구·레이더와 겹치지 않음.
- 실제 VWorld 모델과 주변 지형을 다시 로딩하여 궁궐별 모델·텍스처·GPU 준비 상태 확인.
- 사용자의 마지막 요청에 따라 추가 스크린샷 촬영을 중단함.

코드 변경은 프런트엔드와 검증 도구에 한정한다. DB 삭제·마이그레이션 명령을 실행하지
않았다. 기존 운영 서버 시작 시 자동 통계 정리 동작을 사용자에게 설명한 뒤,
사용자가 다시 배포를 지시했다. 운영 자동 정리 정책이나 백엔드 코드는 변경하지 않는다.
