# 아파트 푯말·음악·실제 도면 기준 적용

## 변경

- 드론에서 스트리밍 타일이 제외하는 현재 단지 및 주변 수집 단지 푯말을 클릭 가능한 아파트 레이어에 등록한다. 단지의 실제 ID를 보존하고 상세 팝업의 실거래 조회에 직접 사용한다. 공공시설/AED 푯말 수정이 아니다.
- 특정 음악을 시작곡으로 강제하고 2회 재생하던 규칙을 제거한다. 기존 세션 무작위 재생 순서를 공유하고 한 곡이 끝나면 다음 곡을 재생한다.
- 실제 내부 도면이 없는 아파트 세대 진입을 차단한다. 기존 면적 기반 평면 생성은 로컬 개발 데모에만 허용하며 운영 `interior=demo` 우회를 막는다. 평형 자료가 없을 때 표준 84㎡를 제시하지 않는다. 전용면적은 소수 둘째 자리로 표시한다.
- 도면 신청 경로·제공 범위는 `apartment-drawing-api-2026-10-30.md`에 기록한다. 실제 도면 공급 API 연결 자체는 데이터/계약 확보 전이므로 미완료다.

## 확인

- TypeScript 빌드 및 Vite 운영 빌드 통과.
- Chrome 음소거, 실제 강남데시앙포레 푯말(apt) 클릭/모바일 탭으로 부동산 상세 팝업 확인. 강남데시앙포레 ID와 인접 수서동 삼성 단지 ID로 각각 실거래 요청 확인. 런타임 오류 없음.
- 가짜 YouTube Player로 13개 카탈로그를 한 바퀴 재생: 강제 시작곡·강제 연속 재생 없음, 종료마다 다음 곡, 재진입 시 트랙 초기화 없음.
- 운영 번들에서 실제 도면 미확보 상태의 아파트 진입 차단과 원래 단지 ID/76.79㎡·84.43㎡ 조회 유지 확인. 건축물대장 응답/필지/외곽은 고정 fixture, 단지 찾기·평형 API는 실제 서버를 사용한다.

## 성능 기록과 제한

Chrome 실제 비행, 기존 high 품질 및 출력 설정 유지. 출력 해상도 하향 변경 없음. `tmp/large-floors/drone-card-click/{desktop,mobile}.json`에 원측정 기록. 다른 그래픽 부하와 초기 로딩을 포함하므로 전국·전체 기기의 성능 달성으로 해석하지 않는다.

| 조건 | 비행 10초 rAF 평균 FPS | rAF p95/p99/최대 ms | 장면 전체 렌더 최저 1초 FPS | 장면 전체 렌더 p95/p99/최대 ms |
|---|---|---|---|---|
| 데스크톱 2529×1277, DPR 1, WebGPU high, renderSize 2529×1277 | 46.84 | 33.4 / 49.9 / 50 | 19.8 | 37.8 / 61.6 / 281.4 |
| 모바일 에뮬레이션 390×844, 기기 DPR 2, WebGPU high, 기존 renderSize 624×1350 | 59.66 | 16.8 / 16.9 / 50 | 31.0 | 24.4 / 43.2 / 255.6 |

50 FPS 전 구간 기준은 미달이다. 평균 rAF와 실제 렌더 지표를 구분하며 평균만으로 통과했다고 보고하지 않는다. 미사용 WebGL renderer의 300×150 기본 canvas는 실제 WebGPU 출력이 아니므로 출력 해상도 판정에 사용하지 않는다. 이번 수정은 푯말 등록·조회·재생·진입 정책에 한정하며 기존 그래픽 성능 문제의 해결을 주장하지 않는다.
