# 공통 걷기 공유 주소 — 2026-10-30

건물 공통 주소를 `/walk?at=위도,경도`로 줄였다. 특정 층은 `&f=3`처럼 표시한다.
드론에서 입장할 때 건물 외곽·연결 건물·복귀 주소를 URL에 넣지 않는다.
기존 `enter=1&lat&lon&foot&campus&back` 링크는 그대로 읽고 주소창을 짧은 형식으로 바꾼다.
일반 시설과 이전 건물 엔진의 상단에 링크 복사 버튼을 추가했다.

공유 좌표는 오목한 외곽에서도 실제 건물 안에 놓이도록 정한다. 같은 탭에서는 세션에 둔
공개 건물 형상과 복귀 정보를 재사용한다. 새 브라우저에서는 VWorld GIS 외곽을 조회하며,
주변 건물은 같은 필지와 30m 이내 연결 조건으로 묶는다. VWorld에 외곽이 없는 역·공공건물은
SGIS 전체 외곽으로 복원한다. 둘 다 없으면 다른 건물이나 작은 사각형으로 대신 열지 않고
조회 실패를 표시한다. 단축 링크 DB·회원 저장·스키마 변경은 없다.

드론에서 전달하던 외곽의 60점·주변 건물의 40점 절단도 제거했다. URL 길이 때문에
형상을 줄이지 않는다. 층 이동 뒤에는 공유 주소의 층도 바뀐다. 실외로 복귀하면 이전 주소를 복원한다.
외부 사이트·프로토콜 상대 주소를 복귀 대상으로 허용하지 않는다.

검증: URL 해석·위치 범위·오목한 건물의 내부점·대상 건물 선택·같은 필지 연결과 다른 필지 제외를
기존 `test-facility-features.ts`에 추가했다. 타입 검사와 운영 번들도 확인했다.
삼성서울병원은 저장 정보가 전혀 없는 새 Chrome 컨텍스트에서 짧은 주소로 열었다.
이전 링크는 667자, 로컬 짧은 링크는 50자였다. 1층은 236개 방·16,170㎡가 생성됐고,
3층 링크를 다시 새 컨텍스트에서 열어 층 복원도 확인했다. 기존 전달 형상의 139개 방·12,321㎡와
실시간 공급자 외곽은 차이가 있어 동일 형상이라고 주장하지 않는다.

사용자가 다른 일반 건물의 추가 검증보다 먼저 배포하도록 지시했다. 다른 공급자·건물의 검증은
배포와 함께 계속하며 확인되지 않은 지역 전체의 성공을 주장하지 않는다.
그래픽 해상도·DPR을 낮추지 않았고 실제 Chrome은 음소거했다. 기존 저장 데이터는 변경하지 않았다.
