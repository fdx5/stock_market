# 시장 스캐너 로컬 시안

URL: http://localhost:5194/ — 배포하지 않은 로컬 변경이다.

## 현재 구성

사용자 피드백에 따라 입체 시장 지형·스파크·불꽃을 화면에서 제거하고 상단을 새로 구성했다.

- 세 시장 지수, 실제 최근 추세 그래프, 주요 종목 등락 분포를 작은 상단에 통합했다.
- 모든 종목에 같은 읽기 공간을 준다. 삼성전자·하이닉스가 면적으로 화면 대부분을 차지하지 않는다.
- 1440px 화면에서는 기본 48종목을 여섯 줄로 보여준다. 각 칸에 이름·현재가·등락·시가총액/지수 비중을 표시한다. 모바일은 읽을 수 있는 폭을 확보하며 기본 여덟 종목을 보여준다.
- 전체 60종목 펼치기, 시총순·등락순·거래대금순·업종순 정렬과 업종 필터를 제공한다.
- 색의 방향과 농도는 실제 등락, 막대 길이는 상대 시총/미국 지수 비중 또는 거래대금이다. 데이터 정렬 시 칸의 이동만 보간한다.
- 큰 중복 차트와 옆 상세 패널을 없애고 선택 종목을 한 줄로 표시한다. 데스크톱 자산 시세도 한 줄로 줄였다.
- 기존 전기 펄스와 코스피→코스닥→나스닥100의 전체 너비 지도는 유지했다. 지도는 별도 행과 충분한 높이를 사용한다.
- 전체 종목을 펼친 뒤 화면 아래에서 접으면, React 반영 후 현재 목록의 조작부를 고정 헤더 아래로 정렬한다. 조작부가 이미 보이는 경우에는 스크롤하지 않는다.

미확인 0%를 보합으로 계산하지 않는다. 거래대금 추정치는 별표를 붙이고 산식을 표시한다. 미국 지수 편입 비중과 실제 달러 시총을 혼동하지 않는다. 그래프는 한국 최근 30거래일 일별 종가 / 미국의 제공 추세이며, 버튼 툴팁과 접근성 이름에 기간의 차이를 표시한다.

## 검증

- `npx tsc -b`, `npx vite build`.
- `python frontend/scripts/test-market-scanner.py http://127.0.0.1:5194`.
- 데이터 모델: 중복 제거, 미확인 등락, 거래대금 정렬, 업종 필터, 빈 데이터.
- 1440×1000 DPR1 / 1280×900 DPR1 / 390×844 DPR2: 영역 크기, 종목 수, 동일 크기 셀, 펼치기·접기, 정렬·선택·업종 필터·시장 전환, 가로 넘침, 모션 감소 설정, 스파크 제거 확인.
- 기존 전체 너비 지도 3행과 지도 최소 높이 유지 확인.
- 결과와 화면 캡처: `qa/market-scanner-qa.json`, `qa/market-scanner-*.png`, `.scanner-build.log`.

이 시안은 이전 `MarketTerrain` 시안을 대체한다. 이전 지형 설명·검사 파일은 현재 화면의 검증 기준이 아니다. 현재 진입 컴포넌트는 `NeoAtlasHome → MarketScanner`다.

공개 API의 GET만 읽었고 저장 데이터 및 DB를 변경하지 않았다.

## 추가 그래픽 효과

사용자가 승인한 배치와 크기는 유지했다. 지수 그래프의 선과 면에 발광 깊이를 추가하고, 시장 전환 시 데이터 보드 표면을 한 번 밝히는 광막을 적용했다. 포인터를 움직일 때는 해당 종목 색을 받아 얇은 반사광이 따라간다. 스파크·불꽃·입체 지형은 사용하지 않는다.

실제 데이터 갱신 시 기본 효과에서 최대 6개, 전체 효과에서 최대 8개 타일을 무작위 순서로 부드럽게 점등한다. 가격이 바뀐 종목을 우선하고 직전에 점등한 종목은 가급적 피한다. 점등 지연은 0~850ms, 지속 시간은 1050~1450ms 범위에서 서로 다르게 잡았다. 숫자·좌표·색의 상승/하락 의미를 변경하지 않는다. 정렬이나 단순 선택은 데이터 갱신으로 취급하지 않는다.

성공 응답 횟수는 시세 기준 시각과 별도로 관리하므로, 같은 시세를 다시 확인한 응답도 조용한 점등을 보여준다. 실패·지연 응답에서는 점등하지 않는다. 이를 위해 새 갱신 타이머나 추가 API 호출을 만들지 않았다.

보드가 화면 밖에 있거나 탭이 숨겨진 경우에는 갱신 점등을 시작하지 않는다. 모션 감소나 최소 효과 설정에서는 동적 효과를 끄고, 설정 변경 시 이미 실행 중인 효과도 취소한다. 광원·모션 처리를 위해 해상도를 낮추지 않았다.
