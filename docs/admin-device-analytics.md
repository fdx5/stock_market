# 관리자 접속 디바이스 분석

## 지표와 화면

- 관리자 개요 및 트래픽 탭에 동일한 분석 패널. 오늘 / 7 / 30 / 90 / 365 / 730일 선택.
- 데스크톱·태블릿·모바일·미확인 비중 도넛, 유형별 기기 분포, 전체 OS·브라우저 분포.
- 단위는 **봇을 제외한 page_view 수**. 고유 방문자나 물리적 기기 대수가 아니다. 클릭·hub·stock_view는 포함하지 않는다.
- 미확인도 분모에 포함하며 확인율을 별도 표시한다. 데이터 없음과 집계 미완료를 구분한다.
- UA 및 브라우저 Client Hints만 활용한다. iPad의 데스크톱 UA는 터치 여부로 보완한다. Android 모델 힌트는 최초 조회에서 최대 150ms 비동기 대기하며 UI 렌더링을 막지 않는다.
- iPhone 세부 모델·PC 제조사 등 공개되지 않은 값은 추정하지 않는다. 과거 UA 없는 기록은 미확인, 축약 Android UA는 모델 미공개로 표시한다.

## 저장·조회 경로

1. 기존 `/api/activity/event`에 선택적 `device_info`를 추가했다. 이전 클라이언트도 그대로 호환된다.
2. 신규 로그의 유형·기기명·OS·브라우저를 `page_views`의 4개 컬럼에 정규화한다. 기존 로그를 대량 UPDATE하지 않는다.
3. 앱 시작 시 전용 백그라운드 작업이 최신 완료일부터 역순으로 7일씩 보충한다. 진행 시 10초, 완료 시 5분, 오류 시 1분 간격으로 재시도한다. 빈 날짜도 완료 표시한다.
4. `device_traffic_daily`의 `(KST 날짜, 유형, 기기, OS, 브라우저)` 복합키에 절대 조회수를 upsert한다. 원본은 해당 날짜 범위에서 SQL GROUP BY로만 읽는다.
5. 저장은 100개 그룹씩 단일 SQL로 제한하고, 모든 저장이 성공한 뒤 원본 조회수와 스냅샷 조회수가 여전히 같은 경우에만 `_complete` 마커를 마지막에 기록한다. 불완전한 날짜는 조회에서 제외한다. 중단·재시작·재실행 시 중복 증가하지 않는다.
6. `GET /api/admin/traffic/devices?days=30`은 **어제까지 집계 테이블만**, 오늘은 인덱스 기반 하루 범위만 조회한다. 관리자 인증 필요, 서버 캐시 55초, 화면 갱신 60초(숨겨진 탭 정지).
7. 지연 도착한 과거 page_view는 해당 날짜의 완료 마커만 무효화한다. 작업이 재집계하고 더 이상 유효하지 않은 그룹은 0으로 정리한다.
8. 원본 보존기간 만료 삭제 전에 집계 완료 여부를 확인한다. 초기 보충이 끝나기 전에는 원본을 지우지 않는다. 집계는 원본 삭제 및 재시작 후에도 유지된다.

응답의 `missing_days/history_ready/available_from`으로 초기 집계의 누락 상태를 표시한다. 기기 목록은 유형당 상위 25종 + 기타 합산으로 제한하되 전체 분모와 조회수는 보존한다.

## 운영

백엔드 재시작 시 스키마 추가 및 보충 작업이 자동 실행된다. 배포 직후에는 집계 중 표시가 정상이다. 이미 보존기간이 지나 삭제된 원본의 기기 정보는 복원할 수 없다.

운영자가 과거 원본의 `is_bot` 또는 기기 컬럼을 직접 수정하면 **해당 원본이 남아 있는 날짜만** `device_traffic_daily`의 `_complete` 마커를 제거해야 작업이 재집계한다. 원본 없는 날짜의 마커를 지우면 보존된 집계를 잃을 수 있다. 기존 봇 보정 스크립트는 변경 대상 날짜의 기기 마커도 무효화한다.

검증:

```powershell
cd backend
.\.venv\Scripts\python.exe -m pytest tests/test_device_analytics.py tests/test_bot_exclusion.py tests/test_admin_query_cache.py -q
cd ../frontend
node scripts/test-admin-devices.mjs
npm run build
# Vite 실행 중 브라우저 회귀 검증 (합성 응답만 사용)
../backend/.venv/Scripts/python.exe scripts/test-admin-devices-ui.py
```

SQLite 격리 DB에서 날짜 경계·봇/클릭 제외·과거 UA·집계 재시작·보존·지연 기록·조회 SQL/인덱스·기기 목록 제한을 검증한다. 운영 DB에 테스트 데이터를 쓰지 않는다.
