# 무료 검색·공유 유입과 재방문 개선

## 적용 범위

- 기존 NEO GENESIS 테마·지도·시세 엔진을 사용한다. 테마를 새로 만들거나 교체하지 않는다.
- `/today`: 코스피·코스닥·나스닥 100 지도 표본의 상승/하락/보합, 상승 비율, 상승·하락 상위, 거래 집중, 업종 흐름. 보이는 동안 1분마다 갱신한다.
- `/share-market`: 실제 수치의 1200×630 PNG 카드 다운로드, 시장 링크 공유, 외부 사이트용 iframe 위젯과 복사 기능.
- `/embed/market/{market}`: 스크립트·쿠키 없는 공개 위젯. 종목과 시장 링크를 통해 본 사이트로 연결한다. CSS는 기존 `neo.css`를 그대로 빌드에 포함한다.
- 공용 헤더에 공개 페이지 공유 버튼, 홈과 메뉴에 시장 요약·공유 진입점을 추가한다.
- `/market-feed.xml`: 이미 발행된 장마감 브리핑만 제공하는 RSS. 발행 시각과 안정된 GUID를 사용하며 없는 발행 시각을 현재 시각으로 꾸미지 않는다.
- `/market-check.ics`: 사용자가 직접 가져오는 평일 한국시간 16:30 확인 일정. 휴장일에도 알림이 표시될 수 있음을 안내한다.
- 시장 지도·순위·오늘 시장 HTML에 실제 시세 표와 집계 시각을 제공한다. 종목 HTML은 메모리에 준비된 공개 시세만 추가하고 별도 종목 네트워크 조회를 시작하지 않는다.
- 공유 URL에는 공개 경로와 검증된 시장 값만 담는다. 토큰·이메일·이름·임의 쿼리를 전달하지 않는다.
- 외부 링크는 `free_distribution` 캠페인 및 social/referral 경로로 분류한다. 공유 성공, 링크 복사, 카드 다운로드, 위젯 코드 복사, RSS와 달력 클릭을 기존 활동 통계에 구분한다.

## 데이터와 비용

- 새 DB·회원 정보·자동 정리·유료 API·광고·서버 상품을 추가하지 않는다. 테스트는 메모리 fixture만 사용한다.
- 공개 시장 집계·카드 캐시는 시장별 고정 키로 제한한다. 표본과 시장 전체 지수, 거래규모 근사치와 실제 제공값을 구분한다.
- 이미지와 위젯의 집계 시각은 서로 다를 수 있다. 수치의 집계 시각은 실제 체결 시각을 뜻하지 않는다.
- 검색 노출·10배 방문 증가를 달성했다고 주장하지 않는다. 검색 등록/색인 및 외부 게시 실적은 배포 실적과 구분한다.

## 검증

- Python: `pytest tests/test_public_markets.py tests/test_market_guides.py -q` — 17개 통과. 실제 DB를 시작하거나 연결하지 않는다.
- Node: `node scripts/test-public-links.mjs` — 3개 통과. 공개 URL 화이트리스트, 시장 상태 검증, 비공개 쿼리 제거 확인.
- `npx tsc -b --pretty false` 통과. Vite 빌드 통과(기존 대형 청크 경고 있음).
- Chrome에서 기존 네온 색상, 시장 전환, 카드 1200×630 로딩, 위젯 링크, 복사 성공을 확인했다. 390px 화면에서 한 열 배치와 가로 넘침 없음을 확인했다.

## 효과 판단

- 배포 전 완료된 7일과 배포 후 완료된 7일을 같은 한국시간·봇 제외 기준으로 비교한다. 총 방문자와 검색/social/referral 유입을 따로 본다.
- 목표는 배포 전 일평균 방문자의 10배 이상이다. 공유 클릭/다운로드와 실제 외부 유입은 서로 다른 지표이며 구분해서 판단한다.
- 기존 통계의 재방문 지표와 브리핑/RSS/알림 유입도 함께 확인한다. 사이트 개선만으로 외부 게시·색인 완료·10배 달성을 보고하지 않는다.
- Google 공식 지침에 따라 실제 사용자에게 유용한 데이터와 검색 로봇이 읽을 수 있는 HTML을 제공한다: https://developers.google.com/search/docs/fundamentals/creating-helpful-content , https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics
