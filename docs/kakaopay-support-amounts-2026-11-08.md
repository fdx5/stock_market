# 카카오페이 후원 금액 선택

- 후원 페이지의 첫 탭은 카카오페이이며 첫 진입 기본 금액은 3,000원이다.
- 선택지는 3,000원, 5,000원, 7,000원, 10,000원, 기타다. 버튼 문구·송금 링크·표시 QR을 하나의 선택 상태로 함께 변경한다.
- 기타는 금액을 지정하지 않은 기존 수신 링크와 해당 링크를 담은 QR을 사용하며 카카오페이에서 직접 금액을 입력한다. 정액 선택 후 기타로 전환할 때 이전 금액을 넘기지 않는다.
- 선택 영역 상단에 기존 상품 이미지를 표시한다: 3,000원 메가커피, 5,000원 스타벅스, 7,000원 블루보틀, 10,000원 스타벅스에 ×2 배지. 기타에서는 상품 이미지를 숨긴다.
- 기존 수신 링크 `https://qr.kakaopay.com/Ej7w8lXu2`의 수신자를 유지한다. 타 사이트의 수신 링크를 복사하지 않는다.
- QR 이미지는 로컬 생성하고 각각 디코딩해 버튼 링크와 일치함을 검증했다. 다른 QR 생성 사이트로 방문자 정보나 송금 정보를 보내지 않는다.
- 회원·후원자 정보, 결제 토큰, 결제 기록을 새로 저장하지 않는다. 기존 Buy Me a Coffee 기능은 유지한다.

## 링크 방식과 검증 범위

사용자가 지정한 참고 페이지: https://silverbulletstock.com/donation/buyMeCoffee

참고 페이지의 공개 배포 소스에서 금액이 포함된 QR 송금 링크를 확인했다. 사용자가 확인한 5,000원 링크에는 `9c40` 금액 구간이 있으며 이는 `5000 * 8`의 16진수 표현이다. 동일한 형식으로 기존 수신자에 네 금액의 링크를 구성했다. 마지막 네 자리는 고정 구분값 `0000`을 사용한다.

공식 QR 브리지의 읽기 전용 HTTP 응답으로 기존 수신자 코드와 금액 구간이 카카오톡 앱 링크에 그대로 전달되는지 확인한다. 이것은 카카오페이의 공식 문서화된 금액 고정 API 계약을 확인한 것은 아니다. 앱 버전별 금액 표시와 실제 송금은 휴대폰에서 별도 확인이 필요하다. 사이트에서 다른 앱의 금액 편집을 막거나 실제 송금 완료를 검증할 수 있다고 주장하지 않는다. 사이트에서는 링크 진입을 결제 완료로 기록하지 않는다.
