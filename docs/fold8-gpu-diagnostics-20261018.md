# 실단말 GPU 패스 계측 추가

433156a0 배포 후 사용자 실단말은 GPU 33~42ms가 지속되고 평균 18~20fps이며,
CPU render 최고 9ms 미만이라고 보고했다. 실단말 목표는 미달이다. 이 변경은
원인을 구분하는 진단 배포이며, 성능 목표 달성이나 실단말 60fps 개선 보고가 아니다.

`?hud=1` 화면에 다음을 추가한다. 서버로 진단 데이터나 기기 정보를 전송하지 않는다.

- shadow: 그림자 렌더링 합계
- scene: 고체 장면
- plants: 별도 식생 패스 (이 패스의 하늘 등 포함)
- water: 수면과 그 뒤의 투명 물체
- post: AO·블러·TAA·블룸·최종 출력 합계
- env: 주변 반사 큐브 캡처
- other: 타임스탬프 사이 복사 및 패스 밖 GPU 간격
- canvas: 실제 3D 렌더 캔버스의 픽셀 크기

기존에 첫 패스만 재던 블룸과 한 축만 재던 AO 블러의 나머지 패스도 계측한다.
진단용 쿼리 슬롯은 32쌍이다. 측정/resolve/readback은 7프레임마다 실행해 매 프레임
진단 작업을 하지 않는다. 7은 그림자의 2/3/4/6프레임 주기와 위상을 순환한다.
표시값은 비동기 완료된 표본의 평활값이며, 쿼리가 추가된 프레임 자체의 비용도 포함한다.
새 패스별 값과 과거 계측의 각 패스 값을 같은 범위로 가정하지 않는다.

장면의 셰이더 수식, 지오메트리, 텍스처, 그림자 정책, 렌더 해상도와 품질 설정은
바꾸지 않는다. 별도 브랜치의 수면 노이즈 재사용·나무 박스 컬링·후처리 load 개선 등
검토 중인 성능 변경은 이 배포에 포함하지 않는다.

운영 확인은 공개 health의 커밋, HTML/참조 번들 제공 여부, 새 Chrome 프로필의 음소거
이동 검사를 사용한다. 테스트 활동/추적 요청과 모든 쓰기 요청은 브라우저에서 차단한다.
DB 자격 증명에 접근하거나 별도 데이터 변경/삭제 작업을 실행하지 않는다.
