# 드론뷰 도로·인도·지형 공통 보정

지하철 출입구는 다른 세션의 담당이므로 그 분류·형상·위치 코드를 수정하지 않았다. 최신 main의 공공시설·지하철 작업을 보존해 통합했다. 저장 DB와 기존 저장 데이터를 변경하는 작업은 수행하지 않았다.

## 수정 내용

- 드론 진입 시 복사·절단한 표시용 지형에 늦게 완료된 도로 고도 보정을 반영한다. 원본 격자의 실제 삼각형 높이를 전달하고 이미 낮춘 하천 바닥은 보존한다.
- 초기 지형은 표시 영역과 접속 구간을 덮도록 조회한다. 이동 타일은 초기 영역의 보정 고도를 경계 밖 32m까지 이어받고, 128m 이내에서 원래 DEM으로 부드럽게 복귀한다. 별도 벽체를 만들지 않는다.
- 도로 중심선에 폭과 인도 여유를 더한 범위를 조회·계산하고, 최종 도로·차선·인도·교량 구조 표면은 각 소유 타일 경계에서 정확히 절단한다. 중심선이 옆 타일에 있는 도로도 실제 폭이 들어오는 부분을 표시한다. 초기 영역도 같은 지형 경계에서 표면을 넘긴다.
- 초기 도로 결과에 표면 버전을 추가해 이전 중심선 범위만 보유한 캐시는 다시 조회한다. 기존 결과나 저장 데이터를 삭제하지 않는다.
- 초기 영역과 이동 타일 모두 등록 건물 외곽에 맞춰 일반 도로 폭을 제한하고 도로·인도의 겹친 부분을 정확히 잘라낸다. 교량은 XY 외곽만으로 절단하지 않고 공식 고도 프로필을 유지한다.
- 교차로의 표시용 인도는 도로 외곽을 따라 정밀 절단한다. 보행자·가로수용 경로는 차도를 피하는 기존 구간을 유지한다. 경계석은 보정한 노면을 따르고, 색상·포장 UV·점자블록·도로 층위 속성을 보존한다.
- 이동 타일 및 초기 주변 건물의 상세 모델 교체에도 도로 침범 검사를 전달한다. 상세 모델 검증 실패 시 기존 등록 건물 표시를 유지한다.
- 이동 타일 표면 절단은 전용 작업자 하나로 처리해 초기 도로 작업과 대기열이 경합하지 않게 한다. 작업자·타일 동시 실행과 자료 보유 제한을 유지한다.
- 경계 절단 후에도 아스팔트를 연속 삼각형 표현으로 유지해 WASM 도로 공간검색을 사용할 수 있게 한다. 인도 고도 표본은 한 번의 생성 안에서 재사용하고 생성이 끝나면 메모리 캐시를 비운다. 긴 인도 생성은 프레임 사이에 나누며, 인도 재생성이 완료된 도로의 차량 표시를 기다리게 하지 않는다.

## 검증

형상·도로 연속성·교량·지형·건물 교체·GPU 준비·작업 취소·캐시 갱신·해안 회귀 테스트 203개가 통과했다. 프로덕션 빌드도 통과했다. 넓은 아스팔트의 공유 정점 고도도 생성 중 재사용하며, 다음 생성에는 이전 표본을 가져오지 않는다.

실제 화면 검증은 음소거 Chrome 155.0.8059.80, Ryzen 7 3700X / RTX 3070, 1920×1080 뷰포트, 픽셀 비율 2, 3840×2160 출력, high 품질, WebGPU 조건이다. FPS를 위해 출력 해상도를 낮추지 않았다. 초기 영역·900m 위치 이동 재생·복귀를 검증하고 실제 렌더러 frameNo 증가를 기준으로 프레임을 집계한다. 위치 이동 재생과 별도로 실제 오토파일럿도 검사한다.

도로 위 지형 검사는 실제 표시 지형의 삼각형 높이와 일반 도로의 내부 샘플을 비교한다. 교량은 층위 속성으로 분리하며, 인도 검사는 차도와 높이가 겹치는 수평 표면을 확인한다. 수직 경계석이 도로 경계에 접한 것을 인도 면 침범으로 세지 않는다. 이 검사는 측정 지역·샘플의 결과이며 전국 모든 원자료의 정확성을 보증하지 않는다.

| 검증 지역 | 일반 도로 높이 샘플 | 인도 면 샘플 | 지형 돌출 | 인도 차도 침범 |
| --- | ---: | ---: | ---: | ---: |
| 성남 금토, 초기·900m 이동·복귀 | 338,246 | 80,386 | 0 | 0 |
| 압구정, 초기·실제 자동비행·900m 이동·복귀 | 929,859 | 200,934 | 0 | 0 |

샘플 수에는 같은 지역의 재진입 검사가 포함된다. 두 지역 모두 페이지 오류와 타일 실패가 없었고 WASM 도로 공간검색이 동작했다. 검증 자료는 `tmp/street-surfaces/verified/result.json` 및 `tmp/street-surfaces/final-urban/result.json`에 보관했다.

검증 과정의 압구정 실제 오토파일럿 계측은 180km/h 설정, 20초 동안 805.5m 이동이었다. 평균 21.34fps, 최저 1초 15fps, p95 66.7ms, p99 99.8ms, 최대 프레임 간격 116.7ms였다. 공유 개발 PC에서 빌드 작업과 겹친 측정이며, 이 수치로 전 구간 최소 50fps 목표 달성을 주장하지 않는다. 이후 고도 중복 계산을 줄이는 최종 최적화의 형상 동등성도 테스트했다. 출력 해상도와 high 품질은 유지했다.

운영 반영은 Git의 정상 fast-forward 배포로 진행하고 공개 health의 commit 및 주요 공개 번들과 로컬 빌드의 일치를 확인한다. 운영 확인 결과는 `tmp/street-surfaces/deployment/result.json`에 기록한다.
