# 이미지 스타일과 목록 갱신 개선

- 상단 3종 이미지를 v2로 교체: 자연광, 아이보리 석재, 무광 금속, 청회색/세이지/테라코타. 이미지의 네온 테두리·발광을 제거하고 카드의 보라색 배경 광원과 그림자 효과를 줄였다. 기존 전체 테마 토큰과 선택 표시를 재사용한다.
- 파일 및 내장 image_gen 편집 프롬프트: `community-icon-v2-prompts-2026-11-05.md`.
- 실제 브라우저에서 진입마다 전체 본문 검증을 기다리느라 23.8초간 목록이 안 보이던 현상을 재현했다.
- 확인된 본문이 있는 목록을 먼저 반환하고 갱신은 별도 제한된 실행 풀에서 수행한다. UI는 2초마다 완료 여부를 확인한다. 글을 읽는 중이거나 페이지 이동 중에는 목록을 바꾸지 않고 새 목록 알림을 제공한다.
- 수집 확인이 끝난 본문/이미지만 노출하는 조건은 유지한다. 최초로 시작하여 확인된 목록이 전혀 없는 서버는 초기 수집이 필요하다. 기존 DB 및 저장 데이터 접근/변경 없음.
- 로컬 독립 API를 최신 코드로 재시작하고 세 게시판을 초기 수집했다.
- 실제 데이터, API 모킹 없는 Chromium 음소거 검증: 국내 50개 1.41초, 해외 50개 0.73초, 부동산 50개 0.78초. 전체 본문 로드, v2 자산 로드, 모바일 390×844 및 844×390 가로 넘침 없음, 페이지 오류 없음 확인.
- 단위 테스트 10개 통과. 백그라운드 갱신이 기존 글을 즉시 반환하고 중복 갱신을 합치는 검증 포함. TypeScript 검사 통과.
