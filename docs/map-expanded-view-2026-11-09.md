# 시장 맵 창 전체 확대

코스피(`/map`), 코스닥(`/kosdaq-map`), S&P500(`/sp500-map`), 나스닥100(`/nasdaq100-map`)의 업종 선택 왼쪽에 화면 확대 버튼을 추가했다.

확대하면 조회기간, 하락/상승 색상 기준 안내, 업종 선택, 닫기 버튼을 남기고 나머지 영역을 맵으로 채운다. NeoShell 토큰을 사용하며 모바일 및 높이가 짧은 창에서는 기간 선택을 상단 가로줄로 배치한다. 창 크기 변경은 기존 ResizeObserver로 맵 타일에 반영한다.

기존 맵을 유지한 채 레이아웃만 변경한다. 닫기 및 Esc로 기존 보기, 업종, 기간, 스크롤 위치를 복원한다. 표 보기에서도 확대할 수 있으며 닫으면 표로 돌아온다. 확대 중 배경 컨트롤은 숨기고 inert로 차단하며 키보드 포커스는 확대 영역 안에서 순환한다. 종료 및 페이지 이탈 시 배경 상태와 스크롤 잠금을 해제한다.

검증:

- 프런트엔드 TypeScript 및 프로덕션 빌드 성공.
- Chrome `--mute-audio`, 합성 API 응답으로 4개 경로 × 1440×900, 390×844, 844×390, 320×568의 16개 시나리오 통과. 실제 저장소나 DB를 사용하지 않음.
- 확대/닫기/Esc, 설정 및 스크롤 유지, 표 보기 복귀, 창 크기 변경, 맵 영역의 실제 클릭 대상, 화면 밖 컨트롤 유무, 포커스와 inert 복구 및 브라우저 런타임 오류 검사.
- `node --test tests/market-map-freshness.test.mjs tests/us-market-refresh.test.mjs`: 11개 통과.
- 데스크톱·모바일 확대 스크린샷 시각 확인.

재현: 빌드 후 `vite preview` 실행, `python frontend/scripts/test-map-expanded.py http://127.0.0.1:5201`.

운영 배포 및 배포 후 검증은 Render 배포 상태와 실제 사이트에서 별도로 확인한다.

## 2026-11-09 기본 확대

사용자 요청으로 네 맵 경로는 진입(직접 접속·앱 내 이동) 시 확대 상태로 연다. 닫기 또는 Esc로 기존 페이지 배치로 돌아가며, 다시 화면 확대 버튼으로 열 수 있다. `test-map-expanded.py`는 진입 직후 확대 상태(창 전체, 타일 24개, 헤더 숨김)를 먼저 확인한 뒤 닫고 기존 시나리오를 그대로 검증한다. 16개 시나리오 통과, 앱 내 이동 진입 후 뒤로가기 시 inert·스크롤 잠금·숨김 스타일 잔존 없음.
