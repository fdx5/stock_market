# 의정부 경전철 로컬 검토

후속 통합 검토: [철도·역사·도로 공통 렌더링 개선](rail-road-rendering-review-2026-10-10.md). 현재 실제 앱 검토 주소는 `http://127.0.0.1:5173/drone-explore`이고, 사용 데이터는 v7이다. 아래 내용은 v6 단계의 검증 이력으로 보존한다.

로컬 검토 주소: http://127.0.0.1:5281/rail-review.html?place=10

## 확인한 문제와 수정

- 노선명 뒤의 목적지 `의정부`가 포함된 수도권 1호선도 의정부 경전철 ID로 분류되었다. 그 결과 경전철의 차량 프로필이 1호선의 중전철 프로필로 덮어써졌다. 노선 구분은 목적지를 제외한 노선명으로 판단하도록 고쳤다.
- 의정부는 운영사 자료에서 Siemens VAL208, 고무바퀴, 2량 1편성, 측방 안내 방식으로 확인된다. 차량 설정을 별도로 분리했다.
- 콘크리트 주행면, 좌우 측면 가이드레일, 가장자리 턱과 수평 안내 바퀴를 추가했다. 의정부 차량의 단축 방식에 맞추어 각 주행장치에 좌우 주행 바퀴를 배치했다. 고무차륜 AGT에는 일반 철도 침목을 만들지 않는다.
- 로컬 검토 목록에 의정부중앙역을 추가했다. 기존 열 곳의 선택 순서는 유지하며, 직접 접속 주소에서도 의정부를 선택할 수 있다.
- 공개 OSM 원본에 포함된 본선 양방향 경로와 본선 역 이름 15개를 유지한다. 차량기지 임시승강장 등 원본에서 정차 위치를 확인할 수 없는 시설의 역 정차 정보는 추가하지 않았다.
- 정적 선로 데이터는 새 버전 `20261010-v6`으로 생성했다. 기존 데이터 버전은 보존한다. 앱 DB와 운영 배포는 사용하지 않는다.

## 정확도 범위

공식 운영사 자료로 차량 방식과 기본 편성을 확인했다. 선로 평면 위치는 공개 OSM 데이터이며 실측 도면이 아니다. VAL208 공급사의 Siemens 도면을 참고한 폭 2.08 m, 차체 길이 약 12.70 m, 주행 바퀴 간격 1.62 m를 표현에 사용했다. 차체 및 연결부, 안내궤도 단면, 주행면 폭, 교각 간격과 고가 높이는 단순화한 표현이며 현장 실측값으로 검증하지 않았다. 차량 외형도 원본 3D 모델이 아닌 직접 만든 대표 모델이다. 운행은 시뮬레이션이다.

## 자료

- [VAL208 주행장치 공급사 Schaeffler 자료](https://www.schaeffler.com/remotemedien/media/_shared_media/08_media_library/01_publications/schaeffler_2/publication/downloads_18/wl_07540_de_en.pdf): Siemens 제공 도면 및 고무 주행 바퀴·안내 바퀴 구조.
- [OSM 이용 조건](https://www.openstreetmap.org/copyright): 선로 데이터의 출처와 ODbL 이용 조건.

## 검증

의정부행 1호선과 의정부 경전철의 분류 충돌, 의정부 2량 편성 및 안내궤도 단면 회귀 검사를 추가했다. 가져오기 검사 7개와 선로·운행 검사 15개가 통과했다. 전국 경로 전체의 좌표, 생성 형상, 차량 위치가 유한한 값인지와 기존 접합부 높이 일치를 함께 확인했다. TypeScript 컴파일이 통과했다.

새 브라우저에서 의정부 직접 접속 주소를 열어 양방향 경로가 AGT/VAL208/2량으로 처리됨을 확인했다. 런타임 오류와 실패한 HTTP 응답은 모두 0건이었다. 전체 및 차량 확대 화면을 살펴 궤도와 차량 표시를 확인했다. 결과는 로컬 `tmp/surface-rail-review-20261010/qa-uijeongbu-v6` 폴더의 JSON 및 PNG에 기록했다. 전체 서비스 장면의 통합 검증은 별도로 필요하다.
