# 드론 검색·워프 이동 1차 배포 (2026-10-11)

## 동작

- 자동 버튼 오른쪽에서 아파트·지역·학교·도로명·지번주소를 검색한다. Windows IME의 마지막 완성 음절이 조합 중이어도 300ms 입력 중단 후 검색하며, 미완성 자음/모음은 기다린다. 추가 스페이스가 필요하지 않다.
- 주소의 실제 동/읍/면을 단지명 앞에 한 칸 띄워 표시한다. 같은 검색어에서는 본 단지를 입구·경로당·중개사무소보다 우선한다. 결과 선택 후 이동 버튼을 눌러야 좌표가 변경된다.
- 검색 이동 즉시 목적지 장면을 로딩하면서 최소 5초간 워프를 표시한다. 실제 목적지 렌더 프레임이 준비되어야 화면을 공개한다. 5초를 넘으면 준비 중 표시를 유지한다. 실패·120초 무응답은 재시도/이동 취소를 제공한다. Escape 취소는 이전 지역으로 돌아간다.
- 페이지의 워프 상태를 유지하면서 목적지 3D 세션은 다시 만든다. 연속 이동·복귀에서 이전 canvas/session이 종료되는지 확인했다.
- 레이더 버튼 가운데 정렬, 오토파일럿 글자/패딩, 모바일 설정·상승 버튼 겹침을 수정했다. 설정은 기존 native dialog를 유지한다.
- 차량의 공통 도로 연결을 접선 연속 곡선과 호 길이 이동으로 연결한다. 평행 차선은 가까운 차선을 유지하고 실제 합류 시 완만하게 변경한다. 굽은 길 속도 제한·대기·교량 고도 연결을 유지하며 같은 프레임의 중복 이동을 막는다.

## 자원·데이터 범위

검색은 기존 도메인 제한 공개 VWorld 브라우저 설정을 사용한다. 동시 검색 2개, 요청 기한 6초, 성공 검색 메모리 캐시 24개, 좌표 건물 메모리 캐시 8개로 제한한다. 취소한 JSONP 응답은 다음 검색 결과를 덮어쓰지 않고 DOM script/handler/timer를 회수한다.

검색 좌표에 대한 두 saveBuildings 경로를 실행하지 않는다. 새로운 영구 검색 저장은 추가하지 않았다. 기존 URL 공유·브라우저 방문 기록·페이지 읽기 도구의 동작은 그대로 존재한다. DB·백엔드·마이그레이션은 변경하지 않았고 운영 DB를 테스트하지 않았다. QA API는 읽기 전용 공개 스냅샷으로 연결하고 비 GET 요청은 차단하거나 메모리 fixture로 응답했다.

- Chrome 154.0.8037.98, 음소거, 새 브라우저 컨텍스트. 1440×1000 DPR1, 390×844 및 844×390; touch DPR2도 검증한다. 렌더 해상도·품질 프리셋을 낮추지 않았다.
- 실제 VWorld 검색 6종: 강남데시앙(CDP IME 조합 유지, 스페이스 없음), 한성기린, 수영구, 망미초등학교, 마린시티2로 33, 부산 수영구 망미동 209-4. 좌표 이동/재방문/뒤로/앞으로 6회 및 이전 장면 회수 확인. 망미동 목적지 좌표 35.174325, 129.118767 확인.

## 후속 배포

이번 배포는 검색·워프·조작 UI·차선 연결 기능 배포다. 최소 3배의 초기/이동 타일 로딩 목표 및 전 구간 50fps 목표 달성으로 보고하지 않는다. 로딩 성능은 동일 해상도에서 실제 이동을 측정한 후 별도 커밋·배포로 진행한다.
