# 국내·미국 시장 요약 숫자 변경 효과와 그래프 재생

`/desk`의 오늘의 국내 시장, `/global`의 지금의 미국 시장에 공통 적용한다.
지수·등락률·상승/보합/하락 종목 수·환율·수급·빅테크 수치·자산 가격과
등락률·조회시각은 표시 값이 바뀔 때만 해당 항목이 한 번 회전해 새 수치로 멈춘다.
최초 표시와 미확인 값에서 첫 정상 값으로 바뀔 때는 회전하지 않는다.
같은 값의 재수신이나 그래프의 5초 재생 주기는 숫자를 다시 회전시키지 않는다.
실제 값은 기존 API 응답으로만 정한다. 효과 시계는 데이터를 요청하지 않는다.

미국 지수와 교차 자산에는 기존 ticker의 실제 points를 사용한다.
코스피·코스닥에는 기존 지수 이력 API의 최근 60개 종가로 작은 그래프를 추가한다.
선 그래프는 5초마다 왼쪽부터 다시 그려지고, 시장 폭 막대는 실제 비중까지 차오른다.
이력은 두 지수별 공유 요청으로 읽으며 매 5초 다시 조회하지 않는다.

화면 밖·숨겨진 탭·움직임 줄이기 설정에서는 반복 시계를 정지한다.
이때의 숫자 변경은 효과를 예약하지 않고 즉시 새 값으로 표시한다.
회전 상태는 종료 후 정리하며, 화면 복귀나 설정 해제 때 이전 회전을 재생하지 않는다.
접근성용 실제 텍스트와 링크는 유지하고 장식용 숫자만 회전하므로
스크린리더에 중간 숫자를 읽히거나 키보드 포커스를 재생성하지 않는다.
인쇄에는 회전 효과 없이 실제 텍스트만 출력한다.

검증은 독립적인 새 메모리 fixture로만 수행하며 운영 DB·기존 저장 데이터를
테스트 대상으로 사용하지 않는다. 모든 Chrome 실행은 `--mute-audio`를 사용한다.

- 전체 TypeScript/Vite 빌드 통과.
- 기존 editorial 렌더링 테스트 6개 통과.
- Chrome 1440×960, 390×960, DPR 1에서 국내/미국, 밝음/어두움 화면을 확인했다.
  각 23개 숫자 중 변경한 가격 하나만 회전하고 같은 값은 정지함을 확인했다.
  7개 선 그래프와 시장 폭 막대의 5초 반복, 실제 값 유지,
  화면 밖/백그라운드 정지, reduced-motion, 키보드 포커스 유지를 검증했다.
- 같은 해상도를 유지한 최종 7초 애니메이션 샘플에서 최소 1초 FPS는 데스크톱 60,
  모바일 에뮬레이션 59였다. p95는 모두 약 16.8ms, p99는 각각 16.8/16.9ms,
  최대 프레임 시간은 각각 17.1/33.4ms였다.
  이는 해당 Chrome fixture 측정이며 실제 모바일 기기 전체 성능을 뜻하지 않는다.

테스트 서버: `npm exec vite -- --config tests/vite.overview.config.ts`

Chrome 검증: `python scripts/test-overview-motion.py`

화면·측정 기록: 작업 폴더의 `qa/overview-motion/`.
기존 저장 데이터·DB 삭제, 마이그레이션, 인증 변경 없음.
