# 아파트 룸투어·실내 배치 개선

상세 팝업에서 `3D 건물뷰` 바로 오른쪽의 `룸투어(임장)`으로 선택 단지·전용면적을 유지한 원본 도면 선택 화면에 진입한다. PC·모바일에서 두 버튼을 같은 줄로 묶고 기존 Neo 토큰으로 빛남 효과를 적용했다. 동작 줄이기 설정에서는 애니메이션을 끈다. 외부 지도 키·건축물대장 조회 실패가 룸투어의 선행 조건이 되지 않는다. 복귀 주소를 보존한다.

## 실내 공통 동작

- 욕실 ID에 의존하던 생성과 욕조가 있으면 샤워기를 생략하던 분기를 제거했다. 욕실·부부욕실마다 변기와 벽부형 샤워기를 먼저 배치한다. 원본의 같은 욕실 영역을 이루는 구획도 함께 탐색한다. 욕조·세면대·수납은 필수 설비 다음에 배치하고 좁은 욕실에 독립 부스 기둥을 만들지 않는다.
- 원본의 좁은 문을 이유로 이동을 잠그던 검토 모드와 안내를 제거했다. 시점의 연속 이동 경로를 검사해 틈은 통과하고 실제 벽·가구·닫힌 문을 가로지르지 않도록 한다. 카메라도 같은 경로 검사를 사용하며 출력 해상도를 유지한다.
- 마스터룸 화장대와 거울 장롱 문을 실제 평면 반사로 연결했다. 거실의 환경광 프로브를 다른 방 거울의 영상으로 쓰지 않는다. 거울마다 위치·방향을 적용하고 가려진 거울 및 거울끼리의 재귀 렌더링을 제한한다.
- 침대는 매트리스뿐 아니라 프레임·헤드보드의 실제 외곽 크기를 반영한다. 일반 프레임·낮은 프레임, 방향, 소형 규격과 50~60cm의 사용 공간을 탐색한다. 같은 원본 방의 L자 구획에서는 실제 바닥으로 완전히 덮인 직사각형만 사용한다. 빈 모서리를 새 바닥으로 채우지 않는다.
- 소파는 1.4~2.9m 폭과 0.88/0.98m 깊이, 장롱은 0.8~1.8m 폭과 0.45/0.60m 깊이, 책상은 0.8~1.2m 폭을 탐색한다. 접근 경로를 확보한 뒤 보조 가구를 배치한다. 통로와 가구 앞 사용 공간은 공유할 수 있지만 가구 본체는 보호한 경로에 놓지 않는다. 식탁·의자 전체 점유 공간과 소형 식탁도 고려한다.
- 문틀은 원본 벽체의 끝면과 마감면을 3mm 분리하고, 측면 몰딩과 상부 몰딩의 중복 면을 없앴다. 수직 벽과 만나는 모서리에는 문틀 재질의 작은 깊이 보정을 적용했다.

`가구·가전 구성 바꾸기 · 1/64`는 완성된 모델 64개를 저장한 기능이 아니다. 구성 번호를 포함한 결정적 선택 값으로 모델·규격 조합을 바꾸며 위 배치 검사를 공통 사용한다. 원본 벽·방·개구부는 바꾸지 않는다.

## 검증

- 원본 분석 자료 19개: 욕실 필수 설비 28곳, 침대 배치·원본 바닥 범위·접근 경로 50곳, 주방 필수 설비 검사 통과.
- 불투명 벽 레이 2,786개, 문틀 마감 깊이/보정 검사 170개, 벽체 연결·외곽 봉합·슬라이딩 문 회귀 검사 통과.
- 64개 구성 선택 값에 대해 소형 침대·접근 경로·후속 장롱 배치 검사, 일반 침대 9개 모델의 실제 형상/점유 범위 검사 통과.
- 이동 단위 검사: 45cm부터 1mm까지 5개 틈 통과, 벽·닫힌 문·가구 관통 방지, 모서리·벽 따라 이동·카메라 여유 검사 통과. 1mm는 제어된 기하 테스트이며 실제 도면 치수 정확도를 뜻하지 않는다.
- 실제 Chrome의 부동산 지도 상세 팝업에서 선택 전용 84.48㎡를 보존해 수서 삼익 115형 도면으로 진입. PC·모바일 버튼 위치/동작 줄이기, 욕실 설비와 물 내리기/샤워 작동, 이동, 원본 검토 안내 부재, 마스터룸의 실제 반사 카메라 검사 통과.
- `npx tsc -b` 및 Vite 운영 빌드 검사. 운영 배포와 배포 후 결과는 후속 검증 기록으로 남긴다.

Chrome는 음소거, RTX 3070/ANGLE D3D11, DPR 1에서 검사한다. PC 뷰포트 1440×1000/출력 1425×1000, 모바일 뷰포트 390×844/출력 375×844. 단기 구간의 FPS 수치는 운영 검증 JSON에 기록하며 전체 지역·기기 또는 최초 로딩 전 구간의 성능으로 일반화하지 않는다. 기존 저장 데이터와 DB는 수정하지 않는다.
