# 전국 상업시설·시장·특색 거리 표시

작업 브랜치: `fix/nationwide-commercial-pois-20261018`.
운영 기준: `c685525b`. 모바일과 PC의 공통 DroneWorld/DroneSigns 경로에 적용한다.

## 변경 내용

- 기존 푯말 분류에서 빠져 있던 백화점·스타필드·아울렛·코스트코·홈플러스·이마트·트레이더스 등 상업시설, 시장, 특색 거리 분류를 추가했다. 저층 상업시설도 건축물 등록 이름과 용도로 분류한다.
- 전국 OSM 자료를 빌드 시 수집·정제한 정적 셀로 제공한다. 최종 `places-20261018-v2`는 상업시설 1,382곳, 시장 1,019곳, 특색 거리·구역 74곳, 합계 2,475곳이다. 625개 셀, 건물 부품 1,029개, 약 1.2MB다. 원시 기여자·계정 정보는 포함하지 않는다.
- 입점 점포, 정류장, 충전소, 주차장 이름에 포함된 대형 시설명은 별도의 대형 상업시설로 만들지 않는다. 기존 등록 건물 푯말과 장소 푯말은 가까운 동일 시설일 때 정보를 합친다. 서로 다른 지도 장소 ID를 가진 지점끼리는 합치지 않는다.
- 기존 건물을 숨기지 않는다. 기존 등록 윤곽이 있는 부분에는 중복 건물을 만들지 않고, 스트리밍된 등록 모델은 GPU 준비를 확인한 후 보완 모델을 대체한다. 지도에 건물/건물 부분으로 등록된 형상만 보완 모델을 만든다. 단순 점·토지이용 구역·거리에는 임의 건물을 만들지 않는다.
- 의정부 신세계백화점의 다중 건물 부품(69m 본체, 40m/하부 10m 부품 등)과 시장 캐노피의 `min_height`를 보존한다. 마당의 구멍도 보존한다. 미등록 높이는 층수 기반 추정이며 자료에 `estimated`를 명시한다. 일반 건물에 사진 외벽을 추가하지 않는다.
- 푯말의 정보 카드에 알려진 주소·분류·브랜드·공개 연락처·등록 영업시간·홈페이지·지도 자료 출처를 제공한다. 현재 영업 여부를 단정하지 않는다.
- 장면별 정적 셀은 최대 16개, 다운로드 동시 실행 2개, 응답 본문 포함 10초 기한과 실패 재시도, 보완 형상은 한 번에 2개씩 생성한다. 먼 형상·셀 및 종료된 장면의 재질·형상·등록 윤곽을 회수한다. 새 DB 접근이나 마이그레이션은 없다.

- TypeScript와 전체 Vite 빌드를 통과했다.

## 범위와 남은 사항

전국에 공통으로 동작하는 경로와 현재 지도에 등록된 자료를 추가한 것이다. 전국 모든 시설의 원천 데이터 완전성이나 건축물의 실측 정밀도를 보증하지 않는다. 원천 지도에 이름/형상이 없으면 기존 건축물 등록 자료가 우선하며, 이름만 있는 곳은 푯말을 제공한다.

출력 해상도를 낮추는 코드는 이번 변경에 추가하지 않았다. 기반 운영 커밋에 있던 모바일 동적 배율·이동 중 후처리 조절은 이번 기능 변경 대상이 아니다. 기존 고정 해상도 최소 50fps/목표 60fps의 실단말 전 구간 달성 여부는 별도로 검증해야 한다.
