# ETF 마켓 국내·해외 분리 및 탐색 화면 개편

## 화면과 경로

- 국내 ETF: `/etf/kr`, 해외 ETF: `/etf/us`.
- 기존 `/etf`는 국내 전용 화면으로, `/etf?region=US`는 해외 전용 화면으로 연결한다. 기존 검색·카테고리·정렬·카드 보기 옵션을 유지한다.
- 왼쪽 공통 메뉴에 ETF 마켓 그룹을 만들고 국내·해외 메뉴를 각각 노출한다. 상단 메뉴·하단 서비스 링크·공유 링크·검색 메타데이터·페이지 통계 이름을 함께 연결한다.
- 해외 데이터 범위는 현재 API가 제공하는 미국 상장 ETF이며, 다른 해외 거래소를 포함한다고 표시하지 않는다.
- 프리마켓 분봉 거래량이 모두 0인 경우에도 제공처 메타데이터의 최근 정규장 거래량을 우선 사용한다. 기존 일괄 시세와 같은 기준이며, 가격과 거래량의 세션 기준 차이를 해외 화면에 안내한다.

## UI와 기능

- 기존 `NeoShell`, `HoloPanel`, NEO 토큰·아이콘·로고를 사용한다. 기존 공통 테마를 변경하거나 새 테마를 추가하지 않는다.
- 시장 요약: 수집 종목 수, 표본 총 거래대금, 상승·하락, 거래 집중 테마.
- 상승·보합·하락은 도넛형 파이 그래프로 표시하며 각 종목 수와 비중을 함께 제공한다. 데이터가 없는 경우 비율을 생성하지 않는다. 320px 화면의 범례 잘림과 가로 넘침 없음 확인.
- 인기 ETF: 수집 목록의 거래대금 또는 거래량 상위 4개. 현재 목록의 검색·필터와 독립적으로 표시하며 인기 순위의 기준을 노출한다.
- 기본 조밀한 시세표, 카드 보기, 검색, 테마 필터, 상승·하락 및 레버리지·인버스 포함/제외 필터.
- 현재가, 등락률, 거래대금, 20·60·120거래일 및 YTD 가격 수익률, 거래량, 평균 대비 거래배수, 가격 추이, 52주 위치.
- 정렬 방향 전환과 열 제목 정렬, 가로 스크롤 시 종목명 고정. 모바일 기본 목록은 간결한 카드형 행으로 표시한다.
- 최대 4개 ETF 비교, 종목 상세·차트·토론·3D 탐험 진입. 비교창의 Escape 닫기, Tab 포커스 제한, 닫은 뒤 포커스 복귀.
- 10초 갱신을 유지하고 중복 요청을 제한한다. 해당 시장만 조회하며, 토론은 사용자가 열 때 불러온다.
- 최초 실패는 미확인 지표, 갱신 실패는 마지막 정상 시세와 지연 안내, 성공했으나 빈 목록인 상태는 별도 메시지로 표시한다.
- 없는 수익률·거래배수·52주 자료는 `—`로 표시한다. 미제공 수익률은 오름차순에서도 뒤에 둔다.
- 국내 원화와 미국 달러를 구분하고 거래대금 추정 여부, 수집 범위, 수익률 기준을 명시한다. 보수·분배금·총수익률을 임의로 생성하지 않는다.

## 검증

- TypeScript 검사 및 Vite 운영 빌드 통과.
- ETF 선택·복합 필터·누락 수익률 정렬·활동 순위·표본 합계·URL 옵션 검사 통과.
- 공개 공유 링크 검사 3개, 독립 카탈로그 기반 SEO 검사 10개 통과. 신규 전용 URL과 기존 해외 링크의 canonical 확인.
- 운영의 공개 ETF API 응답을 별도 임시 디렉터리에 읽기 전용 스냅샷으로 받아, 로컬 프런트 검증에 사용했다. 국내·미국 각각 20개 종목 응답 확인.
- 로컬 미리보기는 독립 HTTP 스냅샷 서버를 사용했다. 앱 백엔드나 DB를 시작하거나 기존 DB를 테스트하지 않았다.
- 브라우저: 1440px 데스크톱, 1024px 태블릿, 390px 및 320px 모바일의 가로 넘침 없음 확인.
- 검색과 인기 영역의 독립 동작, 시장 간 이동, 테마 선택, 수익률 오름차순, 4개 비교 제한, 비교창 키보드 닫기, 기존 해외 링크 옵션 유지 확인.
- 로컬 응답을 실패·빈 결과로 전환해 마지막 데이터 유지, 최초 실패 시 미확인 표시, 정상 빈 결과 구분, 정상 응답 복구 확인.
- 확인 화면: `tmp/etf-renewal-20261027/kr-desktop.png`, `us-desktop.png`, `kr-mobile-full.png`.

이 문서는 배포 전 구현·검증 기록이다. 운영 반영 결과는 별도 배포 기록에 남긴다. DB 스키마·저장 데이터·인증 설정은 변경하지 않았다.
