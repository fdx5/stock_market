# 증시 전광판 (/pulse-board) · 펄스 바다 · 컨테이너선 (2026-11-09)

## 페이지
- 메뉴: 미국 증시 와 종목 탐색 사이 `증시 전광판` (N 배지). 이 페이지만 사이트 공통 배경과 푸터를 끈다.
- KOSPI / KOSDAQ / NASDAQ 100 탭, 시가총액 상위 100종목 셀(관제 홈 스캐너와 같은 셀), 기본 50개 + 더보기.
- 데이터: 선택한 시장 하나만 20초마다(숨은 탭에서는 쉼) `limit=100`으로 조회한다.

## 펄스 바다 (pulseHorizonRenderer)
- 색: 선택한 지수(종목을 고르면 그 종목) 등락 ≤ −1% 푸른 바다, −1~+1% 보라, ≥ +1% 레드·골드. 1.5초에 걸쳐 전환.
- 지평선을 낮춰(`horizon=-.22`) 셀과 겹침을 줄였다. 평균 변동폭이 클수록 너울이 높아지되 상한을 낮게 잡았다.
- 첫 진입 상위 4개 급등락, 갱신 때 시세가 바뀐 종목(최대 6)이 자기 셀 아래에서 파동을 일으킨다. 마우스 오버는 잔물결.
- `sampleSwell()`은 셰이더의 지형·심박 파동을 CPU에서 같은 식으로 계산해 배의 출렁임에 쓴다.

## 컨테이너선 (Blender → GLB → three.js)
- 모델: `frontend/scripts/blender/pulse_container_ship.py` (Blender 5.2, `blender -b -P ... -- out.glb [preview.png]`) → `frontend/public/3d/pulse-ship.glb` (1.17 MB).
- 상위 20종목 로고 컨테이너(LogoPlate_NN, 자체발광 플래카드), 선체 측면 이름판(HullName)에 로고+시장명. 종목을 고르면 20개 컨테이너와 선체 이름이 모두 그 종목으로 바뀐다.
- 좌하단 근거리에서 우상단 원거리로 항해, 화면 밖으로 나가면 다시 왼쪽에서 진입. 파도 높이·기울기·횡방향 차이로 상하·피치·롤(스프링 감쇠, ±2.5°/±3° 이내).
- 선미 항적(프로펠러 와류·켈빈 V·횡파)과 선수파, 물결선 반사, 레이더 회전, 항해등.
- 컨테이너 클릭 = 셀 클릭과 동일(선택/해제). 종목 선택 상태에서 배의 나머지 부분 클릭 = 종목 상세.
- three.js는 지연 로드되며 이 페이지에서만 받는다.
