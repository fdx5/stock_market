# 홈 커뮤니티 제목 롤링 및 시장심리 축약

- 운영 기준 커밋: `2c352a7ca785b9c946e144c8fa9da820bb28877d`.
- 홈의 시장심리 영역 바로 위에 국내·해외·부동산 최신 제목을 각 10건 표시한다.
- 각 게시판의 제목을 1초 간격으로 아래에서 위로 교체하고, 10건 후 반복한다. 원문 링크는 새 탭으로 열린다.
- 제목은 기존 `/api/community/{board}` 공개 목록을 재사용한다. 60초마다 확인하며 초기 수집 중 목록이 부족한 경우 5초 후 다시 확인한다. 실패 시 최근 정상 목록과 지연 상태를 표시한다.
- 제목 전환은 이동·원근 회전·흐림을 조합하고 1초 진행선을 표시한다. 마우스 올림·키보드 포커스·터치 중에는 정지한다. 수동 정지·재생·다음 글을 제공한다.
- 화면 밖이나 숨긴 탭에서는 롤링을 멈춘다. 동작 줄이기 환경은 자동 롤링을 정지한 상태로 시작하고 이동 효과를 제거한다.
- 시장심리 계산 모델은 유지한다. 큰 게이지를 시장명·점수·심리 상태·작은 막대로 축약한다. 계산 설명과 시장지도 링크는 유지한다.
- 기존 운영 화면과 동일한 가상 시세 입력으로 비교한 높이: PC 1440px에서 754.67→141px(18.7%), 모바일 390px에서 1938→245.5px(12.7%).
