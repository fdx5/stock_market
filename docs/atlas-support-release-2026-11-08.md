# 후원 페이지 및 시스템 아틀라스 통합 변경

## 아틀라스 구조 조회 500 수정

`/api/realestate/cctv/gateway`는 FastAPI의 WebSocket 경로다. 기존 아틀라스는 HTTP methods가 없는 경로의 기본값 `[]`에서 집합 `{'HEAD', 'OPTIONS'}`를 빼면서 `TypeError: unsupported operand type(s) for -: 'list' and 'set'`를 발생시켰다. 구조 조회를 호출하는 실시간 스냅샷도 같은 예외의 영향을 받는다.

WebSocketRoute를 구분하여 `WEBSOCKET` 방식과 `websocket` 전송 유형으로 표시한다. HTTP methods는 집합으로 정규화한다. WebSocket 경로가 존재하는 테스트 앱에서 관리자 구조 조회와 스냅샷이 모두 200을 반환하고, 선언된 WebSocket을 HTTP 요청 건수로 만들지 않는 회귀 검사를 추가했다. 기존 관리자 인증은 유지한다.

구조 조회는 소스와 라우트 정보를 읽으며 이 수정은 저장 데이터나 DB 스키마를 변경하지 않는다.

## 화면 구성

- 기존 NeoShell, HoloPanel, NeoIcon과 공통 색상·서체 토큰을 사용한다.
- 후원 페이지는 넓은 화면에서 소개와 후원 카드를 나란히 표시한다. 1,100px 이하에서는 후원 카드를 먼저 배치하고, 640px 이하에서는 소개도 한 열로 정리한다.
- 상품 이미지와 선택 금액을 한 행으로 묶는다. 카카오페이의 정액/기타 선택, 상품 이미지, ×2 배지, Buy Me a Coffee, 후원자 표시와 응원 메시지는 유지한다.
- QR은 900px 이상에서 기본 펼침, 더 작은 화면에서는 기본 접힘이다. 사용자가 직접 펼치거나 접을 수 있고 화면이 기준 너비를 넘으면 기본 배치를 맞춘다. 버튼은 하단 고정 내비게이션 위에 겹치지 않는다.
- 아틀라스의 기존 남색 패널·탭·구조도·글자를 현재 네온 테마 토큰으로 연결한다. 서비스별 색상과 정상/경고/오류 구분은 유지한다. 관리자 콘텐츠 폭에 맞춘 배치 규칙을 추가한다.

## 검증

- 후원 금액 선택 회귀 검사 4개 통과.
- 시스템 아틀라스 검사 12개 통과. 앱 전체를 import하는 별도 컨텍스트 관측 검사는 실행하지 않았다.
- 테스트 앱과 실제 소스 목록을 사용한 구조 조회: 19개 노드, 205개 모듈, WebSocket 구분 정상.
- 새 QR 표시 크기에서 3,000원/기타 코드를 디코딩해 링크 보존 확인.
- TypeScript 및 `npm run build` 통과. 기존 대용량 청크 경고는 남아 있다.
- 브라우저 연결 호스트를 사용할 수 없어 실제 데스크톱/모바일 화면과 GPU FPS를 검증했다고 보고하지 않는다.

운영 배포와 배포 후 확인은 별도 상태로 추적한다.
