# 미국 MAP·종목 시세와 지수 선물 갱신 점검

## 확인 결과

미국 지수 선물과 개별 주식의 시간외 시세는 별개다. 기존 MAP은 개별 종목의
정규장·프리장·애프터장 가격을 표시했으며 ES=F(S&P500 선물),
NQ=F(나스닥100 선물)를 조회하거나 표시하지 않았다. 선물 등락률을 개별
종목의 등락률로 대입하는 계산도 없었다.

운영 시세가 전부 고정됐다는 주장은 확인되지 않았다. 2026-10-20 07:54 KST와
08:03 KST의 읽기 전용 조회에서 나스닥 MAP의 AAPL은 342.92 → 342.80,
NVDA는 217.4293 → 217.6205로 바뀌었다. 최초 동일 시점의 AAPL 상세·테이프는
343.09, MAP은 342.92였다. 서로 다른 캐시와 공급 경로를 사용하므로 이 차이만으로
갱신 중단을 판정할 수는 없다.

코드와 독립 메모리 fixture로 다음 결함은 확인했다.

- MAP의 v7 배치 실패·부분 응답에는 v8 복구 경로가 없어 정규장 스냅샷으로
  돌아갔다. 다른 경로로 확인한 최신 가격도 공유하지 않았다.
- PRE/PREPRE에서 새 프리장 가격이 없을 때 과거 포스트장 가격을 선택할 수 있었다.
  포스트장 가격의 시각이 현재 정규장 가격보다 오래됐는지도 검사하지 않았다.
- 글로벌 TOP100의 정상 배치와 chart 대체 조회 모두 정규장 가격만 읽었다.
  1일 수익률 표도 야간 스냅샷 값을 그대로 사용했다.
- 미국 MAP은 상위 20개/50개/전체를 10/30/60초로 나누어 갱신했다.
- 현재 종목 상세의 동일 업종 비교표, S&P500·미국 ETF 검색 랜딩은 초기 조회만 했다.
  나스닥 증시궤도도 초기 조회만 했다.
- 미국 지수 위젯의 숫자는 일봉 이력 캐시에서 읽었다.

## 수정 범위

- 공통 헤더와 기존 시세 테이프에 실제 ES·NQ 선물을 별도 표시한다. 선물 표시에는
  실제 체결 시각(KST)과 공급자 지연 가능성을 표시한다. 주식 가격/등락률은 해당
  주식의 거래 시세를 계속 사용한다.
- MAP의 전체 구성 종목, 타일·표·툴팁·업종 평균은 한 번의 전체 조회를 10초마다
  적용한다. 미국 마켓 펄스·주목 종목·순위의 공유 스냅샷도 10초 갱신한다.
- 배치 누락 종목은 DB를 사용하지 않는 공통 복구 큐에서 chart로 조회한다. 최대
  8개 동시 요청, 종목별 60초 재시도 간격, 중복 요청 합류로 복구 비용을 제한한다.
  대규모 복구를 HTTP 요청 안에서 기다리지 않고 완료된 종목부터 다음 화면 조회에
  반영한다. MAP·상세가 최근 성공 시세를 공유하고 오래된 체결로 되돌리지 않는다.
- TOP100의 배치/대체 경로에서 시간외 가격과 정규장/시간외 등락 구분을 함께 읽는다.
  응답의 1일 수익률도 최신 일간 등락률을 사용한다. 과거 저장 스냅샷을 변경하지 않는다.
- 미국 동일 업종 비교표·소형 업종맵·S&P500/미국 ETF 검색 랜딩을 10초 갱신한다.
- 나스닥 증시궤도의 가격과 선택 종목도 10초 갱신한다. 시세만 바뀌면 기존 WebGL
  오브젝트와 라벨을 갱신하여 카메라/시점이 초기화되지 않게 한다.
- 미국 지수 위젯의 현재 숫자를 공통 시세로 덮고 일봉 이력은 차트용으로 유지한다.
- 부분 응답/실패 시 기존 정상값을 보존하고, 느린 공유 요청의 중첩을 막는다.
  한 지수의 오류가 다른 지수의 갱신을 막지 않는다.

공통 constituent 경로를 쓰는 미국 MAP, 나스닥 TOP100, 버블, 증시궤도,
종목 목록, 마켓 펄스·순위·주목 종목에 복구가 적용된다. 개별 미국 종목 상세,
동일 업종 비교, 글로벌 TOP100, 미국 지수 위젯의 별도 경로도 수정했다.

## 갱신과 실시간의 한계

10초 화면 조회는 거래소의 무지연 시세를 뜻하지 않는다. 정상 배치 캐시는 15초,
누락 종목 chart 복구는 종목별 60초이며 네트워크 지연도 더해질 수 있다.
2026-10-20 08:03:21 KST 실제 Yahoo chart 조회에서 ES=F 7744.25 / +0.13%,
NQ=F 29777.50 / +0.19%를 수신했지만 두 체결 시각은 07:53:17 KST였다.
약 10분 지연이 관측됐다. 따라서 화면에는 자동 갱신과 실제 체결 시각을 표시하며
무지연 실시간이라고 보장하지 않는다. 장 마감·휴장에는 체결 시각이 오래된 것이
자동 갱신 실패를 뜻하지도 않는다.

## 검증

- Python 관련 회귀 테스트 47개 통과. DB 접근 없이 메모리 fixture와 독립 로컬
  HTTP 서버만 사용했다. 장전/장후 기준가, 시간 비교, 동일 종목 중복 복구,
  500종목 비동기 큐, 최대 8개 요청, 실패 보존, TOP100/위젯을 검증했다.
- Node 실제 공통 훅/가시성 스케줄러 테스트 4개 통과. 다중 구독자의 단일 조회,
  누락·이전 응답 보존, 느린 요청 중첩 방지, 숨김/복귀, 지수별 실패 격리를 검증했다.
- TypeScript `tsc -b --pretty false` 통과.
- Vite production build 통과. 최종 출력: `tmp/us-quotes-final-build-20261020`.
- ES/NQ 실제 외부 읽기 조회 성공. 운영 MAP도 두 시점에 읽기 전용으로 비교했다.
- 브라우저 도구의 사용 가능한 브라우저 목록이 비어 있어 시각적 UI 검증은
  수행하지 못했다. 메모리 전용 UI fixture는 `tmp/us-quotes-fixture/vite.config.mjs`에 있다.

실행 명령:

```powershell
cd backend
.\.venv\Scripts\python.exe -m pytest tests/test_us_live_quotes.py tests/test_yahoo_bulk_quote_crumb.py tests/test_yahoo_batch_transport.py tests/test_global_top100_resilience.py tests/test_etf_quote_fallback.py -q
cd ../frontend
node --test tests/us-market-refresh.test.mjs
node node_modules/typescript/bin/tsc -b --pretty false
node node_modules/vite/bin/vite.js build --outDir ../tmp/us-quotes-final-build-20261020
```

기존 작업 변경분을 유지했다. DB 스키마·정리·삭제 로직은 수정/실행하지 않았고,
운영 앱 재시작·배포·커밋은 수행하지 않았다. 현재 결과는 로컬 수정 및 검증 완료 상태다.
