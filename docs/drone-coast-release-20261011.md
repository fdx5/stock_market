# 드론 회전·해안 지형·교량·건물 사진 배포 검증

2026-10-11. 기준 커밋 `68d9159f5d2ec938828beca265fc09d53d6805da`에서 별도 배포 작업 폴더를 만들고 요청 범위의 변경만 반영했다. 기존 작업 폴더의 다른 수정과 스테이징은 보존했다.

## 반영 내용

- 상승·하강 아래의 360도 회전 버튼. 위치와 기울기를 유지하며 반복 회전하고, 재클릭·수동 입력·착륙으로 종료한다.
- GIS 다운로드의 취소된 요청이 실행 슬롯을 잡지 않도록 개선하고, 기존 도로 준비 작업을 중복 시작하지 않는다. 동시 다운로드 6개, 메모리 캐시 32MiB/512개 제한은 유지한다.
- 실제 해안 경계와 섬 경계에 따라 지형 삼각형을 분할해 바다의 지형만 수면 아래로 내린다. 근거리·외곽·이동 타일에 같은 로직을 적용하며 작업자로 계산한다. 바다와 겹치는 조석 하천 수면은 잘라내고 내륙 하천은 유지한다.
- 공인 교량 링크의 끝점이 강바닥에 있는 경우 링크 방향을 따라 유효한 육지 DEM 지지점을 찾는다. 원래 좌표와 링크 프로필을 유지하며 포장·차선·보행로·차량에 같은 높이를 적용한다. 물 인접만으로 일반 도로를 교량으로 승격하지 않는다. 지지점 계산은 수면 변경 단위로 재사용한다.
- 바다와 겹치는 하천의 배와 항적도 확인된 바다 수위를 사용한다. 내륙 하천의 기존 수위는 유지한다.
- 건물 상세 사진은 확인된 위키백과 대표 사진, 건물명 기반 Commons 사진, 건물명·지역·전경 검색의 비블로그 사진 순서로 표시한다. 주변 지역 사진과 블로그 페이지·이미지 CDN·리다이렉트는 제외한다. 전체 건물 사진은 잘리지 않도록 `contain`으로 표시하며 원본 실패 시 썸네일, 이어서 다음 사진을 사용한다. 검색 결과의 모든 사진이 실제 건물과 일치한다고 보장하지는 않는다.

## 검증

- 관련 프런트엔드 Node 테스트 136개 통과. Python AST로 추출한 건물 사진 소스 테스트 5개 통과. 서버 앱·환경 파일·DB에 연결하지 않았다.
- TypeScript 검사와 새 출력 폴더를 사용하는 운영 Vite 빌드 통과. 기존 출력 폴더나 저장 데이터는 정리하지 않았다.
- 실제 Chrome, 음소거, 저장용 IndexedDB 비활성화, 읽기 전용 로컬 스냅샷 API로 검증했다.
- 마린시티 해안·외해, 해운대, 광안리 4개 시점: 확인된 바다 위로 남은 지형 삼각형 0개, 바다와 중복되는 조석 하천 삼각형 0개.
- 부산 수영구 망미동 209-4 한성기린 중심과 주변 교량 3개 시점: 위 지형·수면 오류 0개. 확인된 바다와 겹치는 공식 교량 포장 정점 3,333개 및 차선 정점에서 침수 0개. 강 위 링크 `1430026200` 포함. 높이는 DEM 기반 표시 보정이며 실제 교량의 측량 높이 주장과는 다르다.
- 회전 94초 검증, 수동 전환·정지·착륙 및 모바일 세로·가로 버튼 배치 검증은 앞선 동일 회전 구현에서 통과했다. 상세 결과는 `drone-resume-loading-20261011.md`를 참조한다.
- 최종 V6 빌드의 실제 상세 위젯에서 위키 우선, 원본 실패 시 썸네일, 위키 사진 실패 시 비블로그 사진, 위키가 없을 때 비블로그 사진의 4가지 상호작용 검증을 통과했다. 블로그 제외와 전체 사진 표시도 확인했고 브라우저 오류는 0개였다. 건물 API와 이미지는 격리된 fixture를 사용했다.

로컬 근거: `surface-rail-20261010/tmp/coast-review-20261010/marine-green-after-v5-20261011/report.json`, `mangmi-bridge-after-v5-20261011/report.json`, `building-photo-widget-v6b-20261011/report.json`. 마지막 배·항적 수위 변경은 별도의 순수 테스트로 검증했다. 최종 배포 빌드는 새 폴더 `tmp/drone-release-build-20261011-v3`에 생성했다.

## 성능의 범위

출력 해상도·픽셀 비율·품질 프리셋을 낮추지 않았다. 앞선 단독 Chrome 회전 검증은 2520×1750 / 1.75 / high에서 최저 1초 56.98fps, p95/p99 16.8/16.8ms, 최대 33.4ms였다. 이동·복귀 검증 중 복귀 최저는 47.72fps로 50fps 목표에 미달했다. 전체 최초 화면은 전후 약 3.9초로 전체 로딩 개선율을 주장하지 않는다. 취소된 다운로드가 신규 요청을 지연하는 통제 실험은 약 250ms에서 1ms 미만으로 개선됐다.

해안 4곳과 망미동 4곳의 최종 지형 검증은 두 Chrome을 동시에 실행했으므로 그 결과의 FPS는 독립된 성능 합격 자료로 사용하지 않는다. 일부 도심의 성능 미달과 장시간 비행·전국·모든 장비 검증은 남아 있다.

## 배포

사용자의 명시적 배포 승인 및 이번 배포의 기존 재시작 동작에 대한 일회성 예외 승인을 적용한다. 수동 DB 삭제·초기화·마이그레이션·관리자 데이터 작업은 실행하지 않는다. 운영 확인은 공개 health의 배포 커밋과 HTML·정적 파일 해시로 수행한다. 이 문서 생성 시점에는 push 및 운영 반영 확인 전이다. 실제 결과는 새 `check-rendering-release.py` 보고서로 확인한다.
