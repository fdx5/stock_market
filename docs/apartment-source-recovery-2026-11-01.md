# 원본 도면 검색·판독 및 노트북 화면 조작 개선

## 변경 내용

- 단지 검색에 숫자 차수 표기와 법정동 접두어, I-PARK/아이파크, 중립적인 `(주상복합)` 표기 차이를 공통 적용한다. `신도6`은 `신도6차`를 찾으며 `신도6-1차`, `신도61차`, 명시적인 1차/1단지 및 임대/분양을 섞지 않는다. 기존 동 번호 제거·지역 검증을 유지한다.
- 여러 검색 후보 중 한 원본 목록의 연결 실패가 다른 후보까지 차단하지 않도록 한다. 단지 검색 캐시에서도 하이픈 차수를 보존한다. 3D/입체 이미지는 원본 2D 평면도 후보에서 제외한다.
- 판독 엔진 `orthogonal-area-9`: 띄어 쓴 방 이름, 영어 표기와 실제 OCR에서 관측한 `참실` 오독을 처리하고 누락된 방 용도만 같은 이미지로 재판독한다. `거실겸 침실`은 별도 침실이 없는 실제 원룸 구조로 처리하고 침대를 배치한다.
- 얕은 개방형 주방은 같은 원본 주방 영역의 연속 직사각형 바닥 안에서 소형 냉장고와 조리대를 배치한다. 실제 문은 개방형 구획으로 취급하지 않으며 조리대의 등은 실제 벽을 향한다. 원본 벽·방 외곽은 바꾸지 않는다.
- 분석 실패 시 **같은 단지·같은 주택형·같은 전용면적**의 다른 원본 이미지만 자동 확인한다. 다른 A/B형이나 단지로 바꾸지 않는다. 실패 응답을 브라우저 세션 내 영구 재사용하지 않는다.
- 노트북 게임과 조작 버튼을 같은 전체화면 요소에 넣는다. 모바일 세로·가로에서 상단 `축소`, `닫기`를 유지하고 네이티브 전체화면 미지원/거절 시 화면 전체 배치로 동작한다. 축소 시 iframe과 게임 상태를 보존한다. 노트북 조작 키가 실내 이동 키로 처리되지 않도록 한다.

## 검증 범위

- DB를 열지 않는 원본 서비스·기하 테스트 57개 통과, TypeScript 및 운영 Vite 빌드 통과.
- 호원동 원본 공급자에서 신도6차 4개 주택형(81B/81A/108/154), 신도6-1차 2개(91/109), 신도4차 108, 신도7차 79를 확인했다. 신도6/6-1을 별도 단지로 유지한다.
- 실제 원본 이미지로 신도6 81B와 신일엘리시움 41A3의 인테리어·욕실 설비·3D 진입을 확인했다. 41A3은 기존 엔진의 방 용도 판독 실패에서 개선 후 진입 가능으로 바뀌었다.
- Chrome에서 390×844, 844×390, 1440×1000의 네이티브/거절/미지원 전체화면 9개 조합 검증. 조작 버튼의 44px 이상 터치 영역, 화면 내 위치, 클릭 도달, 축소 상태 보존, 닫기·전체화면 해제를 확인했다.
- 동일 주택형 다른 원본 성공, 다른 주택형 자동 선택 차단, 전체 원본 실패 후 반복 중단, 목록/분석 실패 후 재시도 등 5개 브라우저 검증 통과.
- 소형 주방은 원본 바닥 내 배치·냉장고/조리대 비중첩·벽 방향·실제 문 보존을 별도 검사한다.

이 표본은 모든 아파트의 판독 성공이나 95%의 독립적인 판독 정확도를 뜻하지 않는다. 추가 조사한 호원아이파크 98형은 기존부터 존재하는 욕실 문/구획 판독과 설비 배치 실패가 남아 있으며 이번 변경으로 해결됐다고 계산하지 않는다. 원본이 해석되지 않을 때 평균 도면으로 대체하거나 실패를 성공으로 표시하지 않는다.

DB·저장 데이터는 직접 변경하지 않았다. Chrome는 음소거로 실행하며 출력 해상도를 낮추지 않는다. 3D 통합 검증은 원본 API/이미지를 실제 사용하고 건축물 메타데이터 및 대장 실패를 고정한다. 운영 검증에서 별도의 실제 API 진입도 확인한다. 모바일은 Windows Chrome의 터치/뷰포트 검증이며 실제 iOS Safari 검증은 아니다.
