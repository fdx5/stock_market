## 도면 공급사 문의 문안

> kospimap.com에서 아파트의 실제 평면도를 기반으로 웹 3D 내부 탐험 및 가상 인테리어 서비스를 구현하려고 합니다. 강남데시앙포레(서울 강남구 수서동 795)를 포함한 전국 아파트의 단지별·주택형별 도면 제공을 문의드립니다. 단지/동/라인 매칭 정보, 전용면적 및 A/B형 구분, 확장/비확장·좌우 반전 구분, 벽·문·창문 좌표와 치수/단위, 천장 높이 보유 여부, 2D/3D 데이터 형식, API 명세 및 샘플, 원도면 출처와 검수 기준, 웹 3D 렌더링·가공·캐시·이용자 제공 허용 범위, 전국 보유 범위 및 갱신 주기, 비용과 호출 한도를 알려주세요.

주택형 도면은 특정 세대의 리모델링 후 실측 결과와 같다고 보장할 수 없다. 출처·버전·검증 범위를 함께 기록하고 확인된 구조만 렌더링한다. 문·창문 위치나 치수를 알 수 없는 부분을 추정으로 채워 실제 도면이라고 표시하지 않는다.
