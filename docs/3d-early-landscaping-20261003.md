# 조경 로딩 순서 수정

사용자가 요청한 조경 로딩 변경만 배포한다. 기준은 운영 `2893fa4`이며, 미배포 steel 최적화와 다른 작업 폴더의 미커밋 변경은 포함하지 않는다.

기존 조경 생성은 수변 준비, 보도, 보행자, 토지이용 조회, 수변 전체 응답(최대 25초), 수면 및 보트 생성 뒤에 있었다. 이제 건물 최초 표시 콜백에서 이미 준비된 ground plan의 단지 조경을 바로 생성한다. 수목 모델·수량·텍스처·detail band·seed·high 설정은 원래 builder를 그대로 사용한다.

상세 토지이용과 수변 준비가 끝나면 원래 경로의 완전한 planting으로 교체한다. 가로수, 학교 경계, 수면 제외 처리는 유지한다. 늦게 완료된 초기 결과가 최종 결과를 덮지 않으며, 교체/종료된 forest는 해제한다. 분리된 wrapper로 늦은 WebGL compile이 폐기된 조경을 장면에 재부착하지 못하게 했다.

## 검증

- 제품 빌드 통과.
- 기존 GPU/자원/프레임/복구 검사 27개, 조경 비동기 수명 검사 4개, 부동산 회귀 12개 통과.
- production preview의 실제 단지에서 WebGPU high 및 원래 2x sharp 확인.
- 수변 API를 테스트에서 응답하지 않도록 유지해도 초기 조경 생성 완료. 이 실행에서 건물 표시 후 7,598ms에 조경이 준비됐고, 건물 표시 후 109ms에 준비가 시작됐다. 자산 다운로드/전체 모델 준비 시간까지 없어졌다는 의미가 아니다.
- 수변 응답을 해제한 뒤 최종 조경 갱신, 마우스 조작, 닫기/재진입 통과. 페이지 오류 없음.

전체 성능의 3배 개선 또는 모든 프레임 드랍 제거를 판정하는 배포가 아니다. 조경의 불필요한 외부 데이터·장식 대기 경로를 제거하는 변경이다.
