# 세계 지수 갱신 긴급 수정

운영 `/api/global/indices`에서 2026-11-17 08시 KST 조사 당시 니케이·상하이·항셍·대만의
현재가와 차트가 11월 13일에 머물렀다. 이들 현재가는 `price_fetcher`의 6시간 일봉
캐시를 사용했고 실제 체결 시각도 제공하지 않았다. 미국 지수 현재가와 일봉 차트의
마지막 값도 서로 달랐다.

## 변경

- 기존 URL·위젯 코드·네온 화면 구성은 유지한다.
- 미국 4개 항목과 아시아·유럽 5개 지표 모두 명시적인 공급처 심볼로 조회한다.
  상하이 `000001.SS`의 점을 미국 주식 클래스 구분 기호로 변환하지 않는다.
- 현재가는 10초 캐시의 분봉 응답에서 가격·전일 종가·실제 시세 시각을 읽는다.
  3개월 일봉은 5분 캐시로 분리하고 마지막 정규장 시세로 누락된 최근 날짜를 보완한다.
  시간외 ETF 가격은 기존처럼 현재가에 반영하고 차트 마지막 일봉은 정규장 가격이다.
- 지표별 병렬 조회, 네트워크 시간 제한, 두 호스트 재시도로 한 지표 장애를 격리한다.
- 실패·과거 응답은 마지막 정상 가격과 원래 시세 시각을 유지하고 지연 표시를 한다.
  일봉만 남은 경우 실제 시세 시각을 만들어 내지 않는다. HTTP 응답은 `no-store`다.

## 검증과 데이터 보존

- 새 메모리 캐시와 공개 시세 fixture만 사용한 Python 회귀 테스트 33개 통과.
- 프런트 구독 공유·10초 갱신·과거 응답 방지·수집 지연 등 Node 테스트 8개 통과.
- 전체 TypeScript 및 Vite 프로덕션 빌드 통과.
- 수정 코드의 공개 공급처 실제 조회에서 9개 항목 모두 유효한 시세 시각과
  11월 16일 차트 마지막 날짜를 확인했다.
- DB·회원 저장·마이그레이션 변경과 기존 저장 데이터의 직접 수정·삭제는 없다.
  기존 서버 작업의 재시작은 사용자가 허용한 정상 배포 범위에 해당한다.

10초는 사이트의 조회 주기다. 공급처의 시장별 시세 지연 및 장 마감 시각은 별개이며,
화면에는 공급처가 반환한 실제 시세 시각을 표시한다.
