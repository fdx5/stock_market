# 원본 평면도 기본 렌더링과 벽체 공통 보강

2026-11-01 사용자 지시: 평균 추정 평면을 표시하지 않으며 실제 원본 도면을 기본으로
렌더링한다. 프레임만 남은 벽, 임의 개구부, 접합부의 틈을 만들지 않는다.

## 원본 확보와 판독

- 네이버 공개 검색에서 단지명·법정동·지역코드를 대조한 단지 ID를 찾고 공개
  `groundPlanGallery.naver`의 주택형 ID·전용면적·기본형/확장형을 구분한다.
  선택한 원본 한 장만 요청하는 기존 경로를 유지한다. 계정·쿠키·유료 AI 호출이 없다.
- 수서동 신동아는 단지 ID `671`, 주택형 `49 / 55 / 60 / 69`, 전용면적
  `33.18 / 39.51 / 39.53 / 49.96㎡`이다.
  [원본 갤러리](https://land.naver.com/info/groundPlanGallery.naver?rletNo=671&newComplex=Y)
- 치수가 없는 경우 실제 공간 영역에서 면적과 가로·세로 비율로 축척을 환산한다.
  방 이름 바로 아래의 `9.09`, `8.10` 같은 단위 생략 소수 면적과 분리된 ㎡ 표기를
  인식하고 방별 면적을 교차 검증한다. 발코니·공용계단을 전용 실내로 늘리지 않는다.
- 여러 줄의 ‘주방 및 식당’, ‘거실 및 침실’, 흐린 글자와 흑백 도면을 보완했다.
  같은 열린 공간의 주방/식당 중복 앵커를 합치고 방 ID를 유일하게 유지한다.
- 원본 벽·방을 템플릿, 무작위 반전, 외곽 늘리기로 대체하지 않는다. 작은 문도
  표준 폭으로 늘리지 않고 원본 픽셀에서 환산한 개구부를 보존한다.

## 렌더링과 벽체

- 운영 아파트 선택은 검증된 이미지 분석 결과만 렌더링한다. 평균 평면 자동 대체와
  일반 아파트 화면의 가상 구조 선택을 제거했다. 원본 미확보·판독 실패·잘못된 구조는
  진입 버튼을 비활성화한다. 가상 평면 생성은 명시적인 로컬 데모에만 남긴다.
- 방 분할 조각마다 별도 벽을 겹치던 방식 대신 벽의 입체 합집합 바깥 면만 만든다.
  겹친 내부 면을 없애고 모서리·T자 접합부를 채운다. 벽 양쪽의 마감과 조명 영역을
  보존하며 벽 두께도 원본 선에서 환산한다. 벽은 불투명한 면·측면·상하단을 가진다.
- 개구부는 실제 맞닿은 반대쪽 방이 있는 구간만 자른다. 같은 공간 이름이 붙었다는
  이유로 외벽이나 비어 있는 바닥 구간까지 문을 확장하지 않는다. 사적인 방의 불확실한
  전체 높이 개방과 외벽의 분할선 개방을 허용하지 않는다.
- 미닫이문은 닫힌 불투명 문짝과 실제 이동 패널을 가진다. 프레임만 만들거나 일반
  여닫이문으로 잘못 처리하지 않는다. 실제 창에는 유리·하부 벽·상부 벽이 남는다.
- 좁은 문 때문에 사람 반경 0.24m의 보행을 확보할 수 없으면 원본을 바꾸지 않고
  **원본 3D 도면 검토** 모드로 표시한다. 방 선택으로 각각의 실내를 볼 수 있으며
  보행은 비활성화한다. 원본 구조의 유효성과 아바타의 통행 가능성을 구분한다.
- 보행 가능한 도면은 동일한 벽·가구·사람 반경에서 작은 문 주변만 세밀한 격자로
  재검사한다. 배치가 실패하면 원본을 보존하고 가구 구성 변경으로 재검토할 수 있다.

## 검증 범위와 수치

로컬 OCR은 배포와 같은 언어 모델을 사용하는 Tesseract.js WASM이다. 운영 Linux의
네이티브 Tesseract 결과와 배포 상태는 배포 후 별도로 확인한다.

| 신동아 주택형 | 전용면적 | 세대 벽 경계 F1 | 원본 바닥 영역 반영 |
|---|---:|---:|---:|
| 49 | 33.18㎡ | 95.27% | 100% |
| 55 | 39.51㎡ | 96.09% | 100% |
| 60 | 39.53㎡ | 95.42% | 100% |
| 69 | 49.96㎡ | 98.25% | 100% |

이 수치는 **원본에서 검출한 세대 벽 중심선과 재구축 경계의 일치도**다. 공용계단은
비교에서 제외하되 원본 바닥 영역의 누락을 별도로 검사한다. 방 용도·실측 치수·시공
가능성의 95% 정확도 인증이 아니다. 주택형 네 개나 편의 표본 14개로 전국 정확도를
주장하지 않는다. 다른 원본에는 95% 미달 사례가 남으며 화면에 미달을 표시한다.

- 기존 원본 10종 + 신동아 4종의 자동 구조 검증: 이전 10/14 → 개선 14/14.
- 기존 원본 10종의 외부 치수 영역만 가린 재현: 이전 8/10 → 개선 10/10.
  이는 같은 원본을 가공한 실험이며 새로운 실제 도면 10종으로 집계하지 않는다.
- 백엔드 독립 검사 39개: 면적·비율, L자 공간, 흑백/흐린 도면, 잘못된 면적,
  작은 문 폭 보존, 방 ID 유일성, 소스 식별, 임의 호스트 거부 등.
- 벽 입체의 모든 모서리 변이 정확히 두 삼각형과 만나는 폐쇄성 검사와 외벽/모서리/
  T자 접합부 광선 검사를 통과했다. 바닥이 없는 구간으로 개구부가 번지지 않는지,
  닫힌 미닫이문이 불투명 문짝을 가지는지도 검사했다.
- 원본 14종의 인테리어 변환·주방 필수 설비 배치와 **2,278개 불투명 벽 광선** 검사 통과.
- 실제 Chrome에서 신동아 4종의 원본 겹쳐 보기와 3D 진입, 공간별 카메라 이동을 확인했다.
  49/55/69형은 원본 문 폭을 보존한 검토 모드이며, 60형은 주요 방 보행 연결을 확인했다.
  원본 없음·판독 실패·잘못된 구조 3조건에서 평균 도면이 생성되지 않고 진입이 차단됐다.
- 테스트 Chrome만 `--mute-audio`. 뷰포트 1440×1000, 실제 출력 1425×1000, DPR 1을
  유지했다. 각 5초 검사에서 평균 약 59.98fps, 최저 1초 59.74~59.97fps,
  p95 16.8ms, p99 최대 16.9ms, 최대 프레임 20.6ms였다. 방 검토/제한된 이동 조건이며
  전국·모든 장비·장시간 보행 성능 보장은 아니다.

재현: `scripts/benchmark_floorplans.py`, `backend/tests/test_floorplan_area_geometry.py`,
`frontend/scripts/test-wall-topology.ts`, `frontend/scripts/test-floorplan-sources.ts`.
원본 해시와 결과: `floorplan-source-benchmark-2026-11-01.json`.
로컬 화면·브라우저 상세: `tmp/floorplan-upgrade-20261101/browser/`.

## 데이터 보존과 배포

DB·회원 데이터·백업을 읽거나 변경하지 않았으며 테스트는 이미지와 메모리만 사용했다.
DB 마이그레이션·삭제·초기화·신규 자동 정리 작업이 없다. 기존 서비스의 main 자동
배포를 사용하며 배포 후 live 상태와 `/api/health` 커밋, 신동아 원본 분석을 확인한다.

최초 원본 전용 렌더링 개선 커밋 `61648c162dcb972cf12b5c0dd227e34ceeddc3b5`는
Render 배포 `dep-dbj9qd6q1p3s73aidccg`에서 live가 되었고, 운영 health 커밋과
신동아 4종의 native Tesseract 분석·원본 이미지 해시·실제 운영 JS 진입을 확인했다.
운영 Chrome 검사에서는 외부 지도/세대 API만 고정 fixture로 격리하고 실제 운영
렌더러와 운영에서 받은 분석을 사용했다. 전체 위치 검색 여정의 검증과 구분한다.

## 단독 기둥 공통 수정

판독된 벽 입체의 연결성을 문 상인방 아래 높이에서 먼저 검사한다. 같은 직선의
분할 조각은 합쳐 판정하고, 실제 벽체에 붙지 않은 높은 짧은 조각과 독립 문틀형
조각을 렌더링에서 제외한다. 상부 가로대만 닿는 것은 벽체 연결로 인정하지 않는다.
바닥 경계에 걸친 외벽·창 아래 벽과 연결된 벽체는 유지한다. 원본 저장 정보는
변경하지 않고 렌더링 입체·문선·걸레받이·보행 충돌을 함께 정리한다.

14종 재검사에서 루체하임 114A의 약 0.52m 고립 조각, 신도브래뉴 81B의
약 0.46×0.43m 독립 조각, 신동아 55형 등의 반올림 잔여 조각을 확인했다.
이들은 구조 기둥으로 확인된 관측값이 아니며 사용자의 단독 기둥 제외 지시를
공통 적용한다. 평면도 자체를 평균 도면으로 바꾸거나 방 좌표를 변형하지 않는다.
원본 매칭 점수는 분석 단계의 지표이며 이 렌더링 정리 이후의 실측 정확도를
인증하는 점수가 아니다.

수정 후 14종의 남은 벽 광선 2,262개, 제외 지점의 충돌 부재와 주변 바닥의
연속성, 외벽 경계 보호 검사를 통과했다. 실제 Chrome에서 신동아 4형의 진입과
검토/보행 및 평균 도면 차단 3조건을 재검사했다. RTX 3070/D3D11,
1440×1000 viewport, 실제 출력 1425×1000, DPR 1에서 각 5초 안정 구간은
평균 59.98fps, 최저 1초 59.96~59.97fps, p95/p99 16.8ms였다.
별도 공간 전환·초기 준비 기록에는 최대 317ms 프레임이 있어 전 구간 50fps 달성으로
보고하지 않는다. 출력 해상도는 낮추지 않았다.
