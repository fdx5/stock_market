# 네이버 연결 종료와 부동산 이전 지역 코드 호환

네이버 `marketValue/KOSDAQ?page=2`의 RemoteDisconnected는 원격이 HTTP 응답
전에 연결을 끊었다는 뜻이다. 로그만으로 유휴 연결 만료인지 공급자 차단인지는
단정할 수 없다. 기존 HTTPAdapter의 자동 재시도 1회가 같은 요청을 즉시 재전송하며
urllib3 `Retrying (Retry(total=0...))` 경고를 만들었다.

시총 페이지 전용 자동 재시도를 끄고, 감싼 예외의 RemoteDisconnected를 확인한
경우에만 별도 새 세션/연결로 한 번 복구한다. 읽기 시간초과와 다른 오류는 즉시
중복 요청하지 않는다. 코스피·코스닥 합계 동시 요청을 4개로 제한하고, 반복 실패는
30초부터 최대 15분 대기, 429는 최소 15분과 Retry-After를 준수한다.
복구 확인은 한 요청만 허용하며 이전 동시 요청의 성공이 새 장애를 해제하지 않는다.
시장·페이지별 마지막 정상값은 복사하여 반환하고 잘못된 응답으로 덮지 않는다.
대체값도 없는 첫 요청은 기존 상위 서비스의 KRX 대체 경로를 유지한다.

부동산 운영 `/api/realestate/regions`에는 신규 `12` 전남광주통합특별시가 있으나
이전 `46` 전남, `29` 광주가 빠져 있었다. 최신 행정구역으로 메모리 목록 전체를
교체하면서 이전 목록에서 만든 재생성 대기열, 저장 지도 키, 주소 링크,
브라우저 지역 선택값을 유효하지 않은 코드로 취급했다.

행정안전부의 2026.7.1 시행 변경 내역과 일치한다:
https://mois.go.kr/frt/bbs/type001/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000052&nttId=127039

새 목록을 원자적으로 적용할 때 기존/기본 목록의 이전 시도·시군구 코드를
중복 없이 보충한다. 새 코드와 명칭은 최신 응답이 우선한다. 이전 코드 지역은
기존 코드에 속한 자료를 계속 조회하며, 새 지역으로 임의 변환/합산하지 않는다.
이전 지도/단지 ID와 대기열은 계속 유효하다. 부분 페이지 응답은 목록 교체에 사용하지 않는다.
이 호환 목록에는 이전 지역과 새 통합 지역이 함께 포함될 수 있다.

DB 스키마·저장·삭제·정리 로직은 변경하지 않았다. 검증은 독립 로컬 HTTP 서버와
메모리 fixture만 사용했다. 실제 소켓 연결 종료 후 새 연결 1회 복구, 지속 장애 시
마지막 정상 페이지 보존, 호스트 동시성/대기/단일 복구 확인, 잘못된 응답,
행정구역 교체 뒤 `46` 지도 재생성과 저장 지도 제공을 검증했다.
